01. Intuition & Concept Contrast

Why can't we use linear regression for classification? Linear regression predicts unbounded real numbers $z \in (-\infty, +\infty)$. Probabilities must strictly obey the Kolmogorov axioms: $P(Y=1 \mid \mathbf{x}) \in [0, 1]$.

Function Mapping

Linear Output vs Probability Sigmoid

Linear Output ($z = \mathbf{w}^T\mathbf{x} + b$): Can predict $-4.2$ or $+15.8$. Meaningless as a probability; sensitive to extreme outliers that skew the decision boundary.

Sigmoid Function ($\sigma(z) = \frac{1}{1 + e^{-z}}$): Smooth S-shaped squashing curve that asymptotically maps $(-\infty, +\infty)$ strictly into $[0, 1]$. Thresholded at $0.5$ ($z=0$) to classify binary decisions.

Evaluation Metric Contrast

Accuracy vs Precision/Recall

Accuracy ($\frac{TP+TN}{N}$): Misleading under class imbalance. In a $0.5\%$ fraud dataset, predicting 100% legitimate gives $99.5\%$ accuracy while missing every fraud case.

Precision & Recall: Precision ($\frac{TP}{TP+FP}$) measures alarm trustworthiness; Recall ($\frac{TP}{TP+FN}$) measures event coverage. Harmonic balance via $F_1$ or recall-weighted $F_2$.

Curve Evaluation

ROC-AUC vs PR-AUC

ROC-AUC ($\text{TPR}$ vs $\text{FPR}$): The $\text{FPR} = \frac{FP}{TN + FP}$ denominator contains the enormous majority class ($TN$). A flood of false positives barely moves $\text{FPR}$, artificially inflating ROC-AUC.

PR-AUC (Precision vs Recall): Focuses exclusively on the positive minority class ($TP, FP, FN$). Excludes $TN$ entirely, exposing poor models on rare events.

Validation Strategy

Random K-Fold vs Stratified K-Fold

Standard Random K-Fold: Can produce validation folds containing zero positive churn/fraud instances due to random sampling.

Stratified K-Fold: Strictly preserves class proportion across every training and validation fold (e.g., exactly $15\%$ churners in each fold).

02. Derivation of Logistic Regression from Linear Regression

Guaranteed University Question (8-10 Marks). Deriving the Sigmoid formula step-by-step from the linear log-odds (logit).

The Governing Logistic Form
$$P(Y = 1 \mid \mathbf{x}) = p = \sigma(z) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x} + b)}}$$ Where $z = \ln\left(\frac{p}{1-p}\right)$ is the Log-Odds (Logit).

Step-by-Step Derivation Protocol:

Step 1: The Probability Dilemma
Let $p = P(Y = 1 \mid \mathbf{x})$ denote the posterior probability of class 1. A linear equation $z = \mathbf{w}^T\mathbf{x} + b$ produces outputs $z \in (-\infty, +\infty)$, whereas probabilities must be bounded $p \in [0, 1]$.

Step 2: Odds Ratio Formulation
Define the Odds of an event as the ratio of probability of occurrence to probability of non-occurrence:

$$\text{Odds} = \frac{p}{1 - p} \in [0, +\infty)$$

Step 3: The Log-Odds (Logit Transformation)
Taking the natural logarithm of the odds maps the range to the full real line $(-\infty, +\infty)$, matching the linear regression hypothesis:

$$\ln\left(\frac{p}{1 - p}\right) = z = \mathbf{w}^T\mathbf{x} + b \in (-\infty, +\infty)$$

Step 4: Algebraic Inversion to Recover Probability ($p$)
Exponentiate both sides:

$$\frac{p}{1 - p} = e^z$$ $$p = e^z (1 - p) = e^z - p e^z$$ $$p + p e^z = e^z \implies p(1 + e^z) = e^z$$ $$p = \frac{e^z}{1 + e^z}$$

Divide numerator and denominator by $e^z$:

$$\mathbf{p = \sigma(z) = \frac{1}{1 + e^{-z}}} \quad \text{Q.E.D.}$$
Binary Cross-Entropy Loss (Log-Loss):
$$\mathcal{L}(\mathbf{w}, b) = -\frac{1}{n}\sum_{i=1}^n \left[ y_i \ln(\hat{p}_i) + (1 - y_i)\ln(1 - \hat{p}_i) \right]$$ Unlike MSE which is non-convex when combined with sigmoid, Cross-Entropy ensures a smooth, convex bowl with a guaranteed global minimum.

03. Adapting to Multi-Class Classification (OvR vs Softmax)

Exam questions often ask how to classify customers into 3 categories: "low", "moderate", and "high spender".

Heuristic Decomposition

1. One-vs-Rest (OvR / One-vs-All)

  • Trains $K$ independent binary logistic classifiers for $K$ classes.
  • Classifier 1: High Spender vs. [Low + Moderate]
  • Classifier 2: Moderate Spender vs. [Low + High]
  • Classifier 3: Low Spender vs. [Moderate + High]
  • Inference Rule: Assign sample to class with highest posterior: $$\hat{y} = \arg\max_{k \in \{1, \dots, K\}} \sigma(\mathbf{w}_k^T\mathbf{x} + b_k)$$
True Multinomial Model

2. Softmax Regression (Multinomial Logistic)

  • Directly models joint categorical distribution across all $K$ classes simultaneously.
  • Computes linear score $z_k = \mathbf{w}_k^T\mathbf{x} + b_k$ for each class, then normalizes using the Softmax operator: $$P(Y = k \mid \mathbf{x}) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}$$
  • Guarantees all probabilities are positive and strictly sum to $1.0$: $\sum_{k=1}^K P(Y=k \mid \mathbf{x}) = 1$.

05. The Accuracy Paradox & Extreme Imbalance Remediation

Jan 2025 & Nov 2025 Recurring Question (20 Marks). Why $99.5\%$ accuracy fails and how to engineer robust solutions.

The Accuracy Paradox Mathematical Proof:
Suppose a network dataset has $N = 10,000$ packets where only $0.5\%$ ($50$ packets) are malicious intrusions, and $9,950$ are benign.
A dumb Null Model that classifies every single packet as benign ($\hat{Y} = 0$) achieves: $$TP = 0, \quad FN = 50, \quad FP = 0, \quad TN = 9,950$$ $$\text{Accuracy} = \frac{0 + 9,950}{10,000} = \mathbf{99.50\%}, \qquad \text{Recall} = \frac{0}{0 + 50} = \mathbf{0.00\%}$$ Conclusion: The model has $99.5\%$ accuracy while missing $100\%$ of security attacks. Accuracy is completely useless here.
Strategy 1: Algorithm-Level

Cost-Sensitive Balanced Class Weights

Modify the binary cross-entropy loss to weight minority errors inversely proportional to frequency:

$$\mathcal{L} = -\sum_{i=1}^n \left[ w_1 y_i \ln \hat{p}_i + w_0 (1 - y_i)\ln(1 - \hat{p}_i) \right]$$ $$w_1 = \frac{N}{2 \times N_1} = \frac{10,000}{2 \times 50} = \mathbf{100}, \quad w_0 = \frac{10,000}{2 \times 9,950} \approx \mathbf{0.5025}$$

Missing a single intrusion is penalized $200\times$ more heavily than a false alarm.

Strategy 2: Data-Level

SMOTE Combined with Tomek Links

SMOTE (Synthetic Minority Over-sampling): Generates synthetic minority examples along feature-space line segments connecting $k$-nearest minority neighbors: $$\mathbf{x}_{\text{synthetic}} = \mathbf{x}_i + \lambda (\mathbf{x}_{zi} - \mathbf{x}_i), \quad \lambda \sim \mathcal{U}(0, 1)$$

Tomek Links: Identifies mutually nearest pairs from opposite classes and cleans borderline majority points, creating crisp decision separation.

07. Repeatable Step-by-Step Solving Protocol

Execute this 5-step protocol for confusion matrix numerical problems:

Step 1: Extract Given Counts & Total ($N$)

Identify Total Instances ($N$), Total Actual Positives ($P$), and Total Actual Negatives ($N_0 = N - P$).

Step 2: Solve the 4 Fundamental Quadrants $$\begin{aligned} TP &= \text{Correctly predicted positives} \\[2pt] FN &= P - TP \quad (\text{Actual positives missed}) \\[2pt] FP &= \text{False alarms flagged by model} \\[2pt] TN &= N_0 - FP \quad (\text{Actual negatives cleared}) \end{aligned}$$
Step 3: Compute Basic Rates (Accuracy, Precision, Recall) $$\text{Acc} = \frac{TP + TN}{N}, \quad \text{Prec} = \frac{TP}{TP + FP}, \quad \text{Rec} = \frac{TP}{TP + FN}$$
Step 4: Compute Harmonic Means ($F_1$ and $F_2$) $$F_1 = \frac{2 \cdot \text{Prec} \cdot \text{Rec}}{\text{Prec} + \text{Rec}}, \quad F_2 = \frac{5 \cdot \text{Prec} \cdot \text{Rec}}{4\text{Prec} + \text{Rec}}$$
Step 5: Write Contextual Justification

Explain why Recall / $F_2$ is preferred over Accuracy (cost of missed defects $FN$ exceeds cost of false alarms $FP$).

08. 6 Deadly Exam Traps & Common Student Mistakes

Trap 01: Swapping FP and FN

Confusing Type I Error with Type II Error

$\text{False Positive} = \text{Type I}$ (False alarm: healthy called sick). $\text{False Negative} = \text{Type II}$ (Dangerous miss: sick called healthy). Swapping these ruins both Precision and Recall.

Trap 02: Arithmetic Inversion

Writing $\sigma(z) = \frac{1}{1 - e^{-z}}$

The denominator MUST have a plus sign: $\frac{1}{1 + e^{-z}}$. Writing a minus sign causes division by zero at $z=0$ ($\frac{1}{1-1}$) and completely invalidates the derivation.

Trap 03: Recommending ROC-AUC on Imbalanced Data

Ignoring FPR Denominator Dilution

Students recommend ROC-AUC for fraud/intrusion. Examiners deduct marks! You must state that ROC-AUC is artificially inflated by large $TN$ in the FPR denominator, and PR-AUC is mandatory.

Trap 04: Denominator Flips in Metrics

Putting Total $N$ in Precision Denominator

Precision denominator is $(TP + FP)$ (all positive predictions). Recall denominator is $(TP + FN)$ (all actual ground-truth positives). Never divide Precision by $N$.

Trap 05: Data Leakage in Cross-Validation

Scaling Data Before Splitting into Folds

If you compute mean and standard deviation on the entire dataset before $K$-fold split, test fold statistics leak into training. Preprocessing must be fitted ONLY inside the training folds.

Trap 06: Multi-Class Probability Sums

Assuming OvR Output Sums to 1.0

One-vs-Rest trains independent binary classifiers; their sigmoid outputs do not sum to $1.0$. Only Softmax regression enforces $\sum P(Y=k) = 1.0$.

Nov 2025 · Question 2 Manufacturing Rare Event Metric Calculations (20 Marks)
Question Statement:
A company predicts a rare event in manufacturing with a test set of $1,000$ points where only $10$ are positive events. Model correctly identifies $7$ of the $10$ positive events, and incorrectly flags $25$ negative events as positive.
1. Calculate $TP, TN, FP, FN$ (15 Marks)
2. Calculate Accuracy, Precision, Recall, F1-score.
3. Analyze which metric is most suitable and explain why. (5 Marks)

Solution:

1. Derivation of Confusion Matrix Parameters (15 Marks)
  • Total Test Instances ($N$): $1,000$
  • Actual Positives ($P$): $10$
  • Actual Negatives ($N_0$): $1000 - 10 = 990$
  • True Positives ($TP$): $7$ (correctly identified positive events)
  • False Negatives ($FN$): $P - TP = 10 - 7 = \mathbf{3}$ (missed positive events)
  • False Positives ($FP$): $\mathbf{25}$ (negative events incorrectly flagged as positive)
  • True Negatives ($TN$): $N_0 - FP = 990 - 25 = \mathbf{965}$ (correctly cleared negative events)
Metric Calculations:
$$\begin{aligned} \text{Accuracy} &= \frac{TP + TN}{N} = \frac{7 + 965}{1,000} = \frac{972}{1,000} = \mathbf{97.20\%} \\[8pt] \text{Precision} &= \frac{TP}{TP + FP} = \frac{7}{7 + 25} = \frac{7}{32} = \mathbf{0.21875 \quad (21.88\%)} \\[8pt] \text{Recall} &= \frac{TP}{TP + FN} = \frac{7}{7 + 3} = \frac{7}{10} = \mathbf{0.7000 \quad (70.00\%)} \\[8pt] F_1\text{-score} &= 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = 2 \times \frac{0.21875 \times 0.70}{0.21875 + 0.70} \\[4pt] &= 2 \times \frac{0.153125}{0.91875} = \frac{0.30625}{0.91875} = \mathbf{0.3333 \quad (33.33\%)} \end{aligned}$$
2. Metric Suitability Analysis (5 Marks)

Accuracy ($97.20\%$) is completely misleading because a useless null model predicting all parts as negative would achieve $99.0\%$ accuracy while catching zero defects.

Most Suitable Metric: Recall (or $F_2$-Score)

  • In manufacturing, a **False Negative** means releasing a defective component to customers, causing warranty recalls, safety hazards, and massive brand damage.
  • A **False Positive** merely triggers secondary manual reinspection of a good part, incurring minor operational labor cost.
  • Therefore, **Recall ($70.0\%$)** or the **$F_2$-score ($48.61\%$)** (which places twice the emphasis on Recall over Precision) is the optimal metric.
Jan 2025 · Question 2 Customer Spending Tiers via Logistic & Multi-Class Softmax (20 Marks)
Question Statement:
A retail analytics company classifies customers into 3 categories: "low spender", "moderate spender", "high spender" using monthly income, purchases, average purchase value. Explain how Logistic Regression estimates probability of "high spender". Describe converting linear equation into sigmoid and interpreting probability. Explain adapting for multi-class via OvR and Softmax Regression. (20 Marks)

Solution:

1. High Spender Estimation & Linear to Sigmoid Conversion (10 Marks)

Let $\mathbf{x} = [x_{\text{income}}, x_{\text{purchases}}, x_{\text{value}}]^T$. Formulate binary target $Y = 1$ if High Spender, $0$ otherwise.

Compute linear combination $z = w_1 x_{\text{income}} + w_2 x_{\text{purchases}} + w_3 x_{\text{value}} + b$.

Apply Sigmoid mapping:

$$P(Y=1 \mid \mathbf{x}) = \sigma(z) = \frac{1}{1 + e^{-z}}$$

Interpretation: If $\sigma(z) = 0.85$, the model predicts an $85\%$ chance of being a High Spender. At standard decision threshold $\tau = 0.5$, any customer with $z > 0$ is classified as High Spender.

2. Multi-Class Adaptation: OvR vs Softmax (10 Marks)

A. One-vs-Rest (OvR): Train 3 independent binary models:

  1. $P(\text{High} \mid \mathbf{x}) = \sigma(\mathbf{w}_{\text{high}}^T\mathbf{x} + b_{\text{high}})$
  2. $P(\text{Moderate} \mid \mathbf{x}) = \sigma(\mathbf{w}_{\text{mod}}^T\mathbf{x} + b_{\text{mod}})$
  3. $P(\text{Low} \mid \mathbf{x}) = \sigma(\mathbf{w}_{\text{low}}^T\mathbf{x} + b_{\text{low}})$

Assign customer to category with highest probability: $\hat{y} = \arg\max_{k} P(C_k \mid \mathbf{x})$.

B. Softmax Regression (Multinomial): Preferred approach. Directly normalizes scores so that probabilities sum to $1.0$:

$$P(Y = k \mid \mathbf{x}) = \frac{e^{\mathbf{w}_k^T\mathbf{x} + b_k}}{\sum_{j \in \{\text{low}, \text{mod}, \text{high}\}} e^{\mathbf{w}_j^T\mathbf{x} + b_j}}$$

Softmax accounts for mutual exclusivity among customer tiers and prevents uncalibrated probability drift.

Nov 2025 · Question 6 Network Intrusion 99.5% Accuracy Paradox & SMOTE (20 Marks)
Question Statement:
A cybersecurity model has 99.5% accuracy but misses nearly all 0.5% intrusion events.
i) Evaluate misleading nature of accuracy. (6 Marks)
ii) Recommend two alternative metrics and justify. (6 Marks)
iii) Suggest two strategies to handle class imbalance. (8 Marks)

Solution:

(i) Misleading Nature of Accuracy (6 Marks)

The Accuracy Paradox occurs because the majority benign class ($99.5\%$) swamps the metric. A trivial classifier predicting zero intrusions scores $99.5\%$ accuracy while achieving zero security value.

(ii) Two Recommended Alternative Metrics (6 Marks)
  1. PR-AUC (Precision-Recall AUC): Excludes True Negatives from the calculation entirely, evaluating performance strictly on True Positives and False Alarms. ROC-AUC is misleading due to $TN$ dilution in $\text{FPR} = \frac{FP}{TN + FP}$.
  2. $F_2$-Score: Penalizes missed intrusions twice as heavily as false alarms via $\beta = 2$, ensuring high sensitivity to attacks.
(iii) Two Strategies to Handle Imbalance (8 Marks)
  1. Cost-Sensitive Balanced Weights: Weight cross-entropy loss by inverse class frequencies ($w_{\text{intrusion}} = \frac{10000}{2 \times 50} = 100$). A missed attack is penalized $200\times$ more than a false alarm.
  2. SMOTE with Tomek Links: Synthesize new minority intrusions in feature space via neighbor interpolation, then remove ambiguous boundary points using Tomek links.
Jan 2025 · Question 3 Cross-Validation Architecture & Generalization in Churn (20 Marks)
Question Statement:
A telecom company builds a model to predict churn. Explain how cross-validation assesses performance, prevents overfitting, and improves model generalization to unseen data. (20 Marks)

Solution:

1. Purpose of Cross-Validation (6 Marks)

Standard holdout splits suffer from high estimator variance (metrics depend on which specific samples fall into test set). CV rotates data systematically across $K$ folds, ensuring every sample serves as a test instance exactly once, yielding an unbiased estimate of generalization error.

2. Stratified K-Fold CV Protocol (8 Marks)

In customer churn (e.g., $15\%$ churn, $85\%$ retain), standard random $K$-fold can produce test folds with zero churners. Stratified K-Fold enforces identical $15:85$ proportions in every single fold.

3. Preventing Data Leakage in Preprocessing (6 Marks)

All feature normalization, imputation, and encoding must be fit strictly on the $K-1$ training folds and only applied to the $k$-th validation fold. Fitting scalers on the entire dataset before splitting causes data leakage, providing overly optimistic validation scores.

11. Active Recall Self-Test Quiz

Answer the questions below to evaluate progress (0/4 answered).
1. Why does standard linear regression fail for classification tasks?
Correct: (a) Linear regression produces unbounded values, whereas probabilities must be strictly bounded in $[0, 1]$.
2. In a rare fraud detection problem with 10 positive cases out of 1,000, a model detects 7 positives and triggers 25 false alarms. What is its Precision?
Correct: (b) $\text{Precision} = \frac{TP}{TP + FP} = \frac{7}{7 + 25} = \frac{7}{32} = \mathbf{21.875\%}$.
3. Why is PR-AUC preferred over ROC-AUC in extreme class imbalance?
Correct: (c) $\text{FPR} = \frac{FP}{TN + FP}$. When $TN$ is tens of thousands, large false alarms create tiny FPRs, falsely inflating ROC-AUC. PR-AUC excludes $TN$ entirely.
4. How does Softmax regression differ from One-vs-Rest (OvR) in multi-class classification?
Correct: (a) Softmax normalizes exponents via $\frac{e^{z_k}}{\sum e^{z_j}}$, guaranteeing a valid probability distribution summing to $1.0$.
