ii) NumPy Arrays & 1D Series in Data Analysis (10 Marks)​

a. Concept and Distinction from Python Lists (2 Marks)​

In scientific Python, a 1D NumPy array (often referred to conceptually alongside Pandas Series) is a contiguous, homogeneous memory buffer.

  • Homogeneity: NumPy arrays enforce a single data type (dtype), eliminating Python pointer overhead.
  • Memory Contiguity: Stored in cache-friendly C-contiguous blocks, enabling SIMD vectorization.
  • Vectorized Broadcasting: Arithmetic operations execute element-wise without explicit Python for loops.

Solution 4 (20 Marks)​

1. Theoretical Foundation of Alpha-Beta Pruning (5 Marks)​

In two-player, zero-sum, perfect-information deterministic games (e.g., Chess, Checkers), the Minimax algorithm searches O(bd)O(b^d)O(bd) nodes. Alpha-Beta Pruning computes the exact same optimal decision while cutting off subtrees that cannot influence the final root decision.

Governing Bounding Parameters​
  • α\alphaα: The utility of the best (highest-value) choice found so far along the search path for player MAX (initialized to −∞-\infty−∞).
  • β\betaβ: The utility of the best (lowest-value) choice found so far along the search path for player MIN (initialized to +∞+\infty+∞).
The Universal Pruning Condition​

If α≥β,PRUNE remaining children.\mathbf{\text{If } \alpha \ge \beta, \quad \text{PRUNE remaining children.}}If α≥β,PRUNE remaining children.

  • α\alphaα-Cutoff: Occurs at a MIN node when a child yields a value ≤α\le \alpha≤α. Because MAX already has an option yielding α\alphaα elsewhere, MAX will never choose this branch.
  • β\betaβ-Cutoff: Occurs at a MAX node when a child yields a value ≥β\ge \beta≥β. MIN will avoid this branch.
