A* Search: Concept Mastery & Exam Questions

Course - Fundamentals of Artificial Intelligence (21CSC569J & 21CSC206T)
Topic Classification - Informed (Heuristic) Search & Shortest Path Algorithms
Exam Priority - Rank 2 (Appears in 80% of All Semester Examination Papers)

1. Executive Summary & Why A∗A^*A∗ Matters​

In state-space problem solving, classical uninformed algorithms (such as Breadth-First Search and Uniform Cost Search) explore nodes blindly in all directions like expanding spherical waves. Because they lack directional guidance, their time and memory footprints grow exponentially with search depth:

O(b1+⌊C∗/ϵ⌋)\mathcal{O}\left(b^{1 + \lfloor C^* / \epsilon \rfloor}\right)O(b1+⌊C∗/ϵ⌋)

The Core Philosophy of A∗A^*A∗ Search​

A∗A^*A∗ Search is a best-first heuristic search algorithm that guides exploration directly toward the goal state. It evaluates candidate nodes using an additive evaluation function that balances the path cost already spent with the estimated cost remaining:

f(n)=g(n)+h(n)f(n) = g(n) + h(n)f(n)=g(n)+h(n)

  • g(n)g(n)g(n) (Backward Cost): The exact, cumulative path cost incurred to reach node nnn from the start state SSS.
  • h(n)h(n)h(n) (Forward Heuristic Cost): An estimated cost of the cheapest path from node nnn to the nearest goal state GGG.
  • f(n)f(n)f(n) (Total Estimated Path Cost): The estimated total cost of the cheapest solution path passing through node nnn.

By maintaining a minimum-priority queue ordered strictly by f(n)f(n)f(n), A∗A^*A∗ achieves optimal efficiency: no other optimal search algorithm expanding the same heuristic can expand fewer nodes than A∗A^*A∗ (up to tie-breaking).

2. First-Principles Conceptual Understanding & Proofs​

University examinations routinely ask students to state and prove the mathematical conditions under which A∗A^*A∗ is guaranteed to find an optimal solution.

Condition 1: Admissibility (h(n)≤h∗(n)h(n) \le h^*(n)h(n)≤h∗(n))​

A heuristic function h(n)h(n)h(n) is admissible if it never overestimates the true minimal cost to reach the goal:

0≤h(n)≤h∗(n)∀n0 \le h(n) \le h^*(n) \quad \forall n0≤h(n)≤h∗(n)∀n

where h∗(n)h^*(n)h∗(n) is the true, optimal cost from node nnn to the nearest goal state GGG. At any goal state, h(G)=0h(G) = 0h(G)=0.

Theorem: A∗A^*A∗ Tree Search is Optimal if h(n)h(n)h(n) is Admissible​

Proof by Contradiction:

  1. Let C∗C^*C∗ be the true cost of an optimal solution path, and let G1G_1G1​ be an optimal goal node (g(G1)=C∗g(G_1) = C^*g(G1​)=C∗).
  2. Suppose A∗A^*A∗ terminates by selecting a suboptimal goal node G2G_2G2​ from the priority queue, where g(G2)>C∗g(G_2) > C^*g(G2​)>C∗.
  3. Because G2G_2G2​ is a goal node, h(G2)=0h(G_2) = 0h(G2​)=0, so its total evaluation is: f(G2)=g(G2)+h(G2)=g(G2)>C∗f(G_2) = g(G_2) + h(G_2) = g(G_2) > C^*f(G2​)=g(G2​)+h(G2​)=g(G2​)>C∗
  4. Now consider the optimal path to G1G_1G1​. Since G1G_1G1​ has not yet been selected, there must exist at least one unexpanded frontier node nnn on the optimal path.
  5. By admissibility, h(n)≤h∗(n)h(n) \le h^*(n)h(n)≤h∗(n). Therefore, the evaluation of node nnn satisfies: f(n)=g(n)+h(n)≤g(n)+h∗(n)=C∗f(n) = g(n) + h(n) \le g(n) + h^*(n) = C^*f(n)=g(n)+h(n)≤g(n)+h∗(n)=C∗
  6. Combining our inequalities: f(n)≤C∗<f(G2)  ⟹  f(n)<f(G2)f(n) \le C^* < f(G_2) \implies f(n) < f(G_2)f(n)≤C∗<f(G2​)⟹f(n)<f(G2​)
  7. Because f(n)<f(G2)f(n) < f(G_2)f(n)<f(G2​), the priority queue must dequeue node nnn before G2G_2G2​.
  8. This contradicts the assumption that G2G_2G2​ was dequeued. Therefore, A∗A^*A∗ can never select a suboptimal goal, proving tree-search optimality. ■\blacksquare■

Condition 2: Consistency / Monotonicity (Triangle Inequality)​

In graph search (where repeated states and cycles exist), admissibility alone is insufficient unless closed nodes are allowed to reopen. Consistency (also called monotonicity) guarantees optimality in graph search without reopening any node.

A heuristic function h(n)h(n)h(n) is consistent if, for every node nnn and every successor n′n'n′ generated by action aaa:

h(n)≤c(n,a,n′)+h(n′)h(n) \le c(n, a, n') + h(n')h(n)≤c(n,a,n′)+h(n′)

where c(n,a,n′)c(n, a, n')c(n,a,n′) is the step cost of transitioning from nnn to n′n'n′.

Monotonicity of f(n)f(n)f(n) Along Paths​

If h(n)h(n)h(n) is consistent, then f(n)f(n)f(n) is non-decreasing along any path:

f(n′)=g(n′)+h(n′)=g(n)+c(n,a,n′)+h(n′)≥g(n)+h(n)=f(n)f(n') = g(n') + h(n') = g(n) + c(n, a, n') + h(n') \ge g(n) + h(n) = f(n)f(n′)=g(n′)+h(n′)=g(n)+c(n,a,n′)+h(n′)≥g(n)+h(n)=f(n)

f(n′)≥f(n)\mathbf{f(n') \ge f(n)}f(n′)≥f(n)

Theorem: A∗A^*A∗ Graph Search with Consistent Heuristics​

When h(n)h(n)h(n) is consistent:

  1. The sequence of nodes dequeued by A∗A^*A∗ has non-decreasing values of f(n)f(n)f(n).
  2. Whenever A∗A^*A∗ selects a node nnn for expansion, the optimal path to nnn has already been found (g(n)=g∗(n)g(n) = g^*(n)g(n)=g∗(n)).
  3. Closed nodes never need to be reopened, ensuring worst-case space and time bounds.

Condition 3: Heuristic Dominance​

Given two admissible heuristic functions h1(n)h_1(n)h1​(n) and h2(n)h_2(n)h2​(n):

If h2(n)≥h1(n)∀n,then h2 dominates h1.\mathbf{\text{If } h_2(n) \ge h_1(n) \quad \forall n, \quad \text{then } h_2 \text{ dominates } h_1.}If h2​(n)≥h1​(n)∀n,then h2​ dominates h1​.

  • Dominance Theorem: A∗A^*A∗ using h2h_2h2​ will expand strictly fewer or equal nodes than A∗A^*A∗ using h1h_1h1​.
  • Intuition: A higher admissible heuristic provides a tighter lower bound, pruning more of the search space.

Sliding 8 numbered tiles on a 3×33 \times 33×3 grid to reach the goal configuration.

  1. h1(n)h_1(n)h1​(n) — Misplaced Tiles: Count of numbered tiles (excluding the blank) whose current coordinate differs from their goal coordinate.
  2. h2(n)h_2(n)h2​(n) — Sum of Manhattan Distances: Sum of the horizontal and vertical distances of each tile from its goal position: h2(n)=∑i=18(∣xi−xigoal∣+∣yi−yigoal∣)h_2(n) = \sum_{i=1}^{8} \left( \lvert x_i - x_i^{\text{goal}} \rvert + \lvert y_i - y_i^{\text{goal}} \rvert \right)h2​(n)=∑i=18​(∣xi​−xigoal​∣+∣yi​−yigoal​∣)

Because h2(n)≥h1(n)h_2(n) \ge h_1(n)h2​(n)≥h1​(n) for all configurations, h2h_2h2​ strictly dominates h1h_1h1​. 5. Algorithmic Formulation & Memory-Bounded Variants​

Python Implementation​

import heapq

def a_star_search(graph, start, goal, heuristic):
    # Priority Queue stores: (f_score, g_score, current_node, path)
    frontier = []
    heapq.heappush(frontier, (heuristic[start], 0, start, [start]))
    
    # Explored map: tracks minimal g_score found for each node
    explored = {}
    
    while frontier:
        f, g, current, path = heapq.heappop(frontier)
        
        # Goal Test MUST occur when dequeuing from priority queue
        if current == goal:
            return path, g
            
        if current in explored and explored[current] <= g:
            continue
        explored[current] = g
        
        for neighbor, weight in graph.get(current, []):
            new_g = g + weight
            new_f = new_g + heuristic[neighbor]
            if neighbor not in explored or new_g < explored[neighbor]:
                heapq.heappush(frontier, (new_f, new_g, neighbor, path + [neighbor]))
                
    return None, float('inf')

Memory-Bounded A∗A^*A∗ Alternatives​

When state spaces exceed available RAM, three algorithmic adaptations are used:

  1. IDA (Iterative Deepening A*):* Uses f(n)f(n)f(n) cutoffs rather than depth cutoffs, reducing memory consumption to linear O(bd)\mathcal{O}(bd)O(bd).
  2. RBFS (Recursive Best-First Search): Linear-space best-first search that tracks alternative path fff-values using recursion backpointers.
  3. SMA (Simplified Memory-Bounded A*):* Operates within a fixed memory buffer, discarding the worst leaf node when memory fills.

6. Examiner's Grading Rubric & Common Traps​

warning

Top 4 Exam Pitfalls Where Students Lose Marks

  1. Early Goal Termination Trap:
    WRONG: Terminating the search as soon as a goal node is generated as a successor.
    CORRECT: A∗A^*A∗ must only terminate when the goal node is DEQUEUED (popped) from the priority queue. A goal generated along a suboptimal path may have an fff-value higher than an unexpanded node.
  2. Counting the Blank Tile in 8-Puzzle:
    WRONG: Adding the blank space into the misplaced tiles count or Manhattan distance sum.
    CORRECT: Heuristic evaluations must only count numbered tiles {1,…,8}\{1, \dots, 8\}{1,…,8}.
  3. Confusing Admissibility and Consistency:
    Admissibility requires h(n)≤h∗(n)h(n) \le h^*(n)h(n)≤h∗(n) (underestimating true goal cost). Consistency requires h(n)≤c(n,a,n′)+h(n′)h(n) \le c(n, a, n') + h(n')h(n)≤c(n,a,n′)+h(n′) (triangle inequality). Consistency implies admissibility, but not vice-versa.
  4. Omitting Queue State in Trace Tables:
    Failing to show the updated contents of the frontier priority queue at each step typically results in a 3-mark to 5-mark deduction.
