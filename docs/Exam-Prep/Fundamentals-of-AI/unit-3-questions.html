Question 1: AI Definitions, Turing Test & System Approaches​

info

Question Statement

  1. Explain the four approaches to AI: thinking humanly, thinking rationally, acting humanly and acting rationally. Give one definition of AI that fits each.
  2. Describe the Turing Test and list the capabilities a machine needs to pass it. How does the Total Turing Test extend it?
  3. Place each system in the approach it best fits and justify your choice:
    • A customer-support chatbot
    • An automated theorem prover
    • A self-driving car
    • A cognitive model of human problem solving

Model Answer​

1. Four Approaches to AI​

AI is defined along two axes: Human vs. Rational and Thought vs. Behavior.

ApproachFocusCore ConceptStandard Definition
Thinking HumanlyThought ProcessCognitive modeling"The automation of activities that we associate with human thinking, activities such as decision-making, problem solving, learning..." (Bellman, 1978)
Acting HumanlyObservable BehaviorBehavioral mimicry"The art of creating machines that perform functions that require intelligence when performed by people." (Kurzweil, 1990)
Thinking RationallyThought ProcessFormal logic"The study of mental faculties through the use of computational models." (Charniak & McDermott, 1985)
Acting RationallyObservable BehaviorExpected utility"Computational Intelligence is the study of the design of intelligent agents." (Poole et al., 1998)

2. Turing Test & Total Turing Test​

  • Turing Test Setup: A human interrogator communicates via text terminal with an unseen human and machine. If the interrogator cannot tell machine from human after 5 minutes, the machine passes.
  • Four Capabilities Needed to Pass:
    1. Natural Language Processing (NLP): To communicate fluently in natural human language.
    2. Knowledge Representation (KR): To store facts and relationships heard or known.
    3. Automated Reasoning: To answer queries and draw deductions from stored facts.
    4. Machine Learning (ML): To detect patterns and adapt to new situations.
  • Total Turing Test Extension: Adds physical interaction with real-world objects.
  • Two Additional Physical Disciplines: 5. Computer Vision: To perceive and inspect objects visually. 6. Robotics: To manipulate physical objects and navigate real space.

3. Classification of AI Systems​

SystemBest-Fit ApproachJustification
Customer-support chatbotActing HumanlySimulates human dialogue, tone, and empathy in conversational interactions.
Automated theorem proverThinking RationallyOperates strictly via formal mathematical logic to prove theorems deductively.
Self-driving carActing RationallyOperates as an autonomous agent selecting actions that maximize transit safety and efficiency under uncertainty.
Cognitive model of human problem solvingThinking HumanlySimulates human psychological processes, working memory limits, and reaction times.

Question 3: Missionaries and Cannibals Problem​

info

Question Statement

Three missionaries and three cannibals must cross a river in a boat that holds at most two people. Cannibals must never outnumber missionaries on either bank, unless no missionaries are on that bank.

  1. Define the state representation, initial state, goal state, actions and path cost.
  2. List the legal operators and the condition that makes a state unsafe.
  3. Draw the state space for the first four levels, marking unsafe states, and give a complete solution path.
  4. Why is breadth-first search a sensible choice for this problem?

Model Answer​

1. Problem Formulation​

  • State Representation: (ML,CL,B)(M_L, C_L, B)(ML​,CL​,B)
    • ML,CL∈{0,1,2,3}M_L, C_L \in \{0, 1, 2, 3\}ML​,CL​∈{0,1,2,3}: Missionaries and Cannibals on left bank.
    • B∈{L,R}B \in \{L, R\}B∈{L,R}: Current boat position.
      (Right bank is implicit: MR=3−MLM_R = 3 - M_LMR​=3−ML​, CR=3−CLC_R = 3 - C_LCR​=3−CL​.)
  • Initial State: s0=(3,3,L)s_0 = (3, 3, L)s0​=(3,3,L)
  • Goal State: sgoal=(0,0,R)s_{\text{goal}} = (0, 0, R)sgoal​=(0,0,R)
  • Actions: Boat carries (m,c)(m, c)(m,c) passengers where 1≤m+c≤21 \le m + c \le 21≤m+c≤2: {(1,0),(2,0),(0,1),(0,2),(1,1)}\{(1, 0), (2, 0), (0, 1), (0, 2), (1, 1)\}{(1,0),(2,0),(0,1),(0,2),(1,1)}
  • Path Cost: 111 per river crossing (total crossings).

2. Legal Operators & Unsafe Condition​

  • Unsafe Condition: A state is unsafe if cannibals outnumber missionaries on either bank: Unsafe  ⟺  (ML>0∧CL>ML)∨(MR>0∧CR>MR)\text{Unsafe} \iff (M_L > 0 \land C_L > M_L) \quad \lor \quad (M_R > 0 \land C_R > M_R)Unsafe⟺(ML​>0∧CL​>ML​)∨(MR​>0∧CR​>MR​) Safety Invariant: A state is valid if and only if M=0∨M=3∨M=CM = 0 \lor M = 3 \lor M = CM=0∨M=3∨M=C.
  • Legal Operators:
    • Left to Right (B=LB = LB=L): (ML−m,CL−c,R)(M_L - m, C_L - c, R)(ML​−m,CL​−c,R)
    • Right to Left (B=RB = RB=R): (ML+m,CL+c,L)(M_L + m, C_L + c, L)(ML​+m,CL​+c,L)
    • Must satisfy: 0≤ML,CL≤30 \le M_L, C_L \le 30≤ML​,CL​≤3 and preserve the safety invariant.

4. Why BFS is a Sensible Choice​

  1. Guarantees Shortest Path: Step costs are uniform (c=1c = 1c=1). BFS is mathematically guaranteed to find the minimal number of river crossings (111111 steps).
  2. Prevents Infinite Loops: State space has cycles. DFS can loop indefinitely, whereas BFS explores level-by-level and terminates at the shallowest solution.
  3. Low Memory Impact: Total state space has only 323232 configurations (161616 safe). BFS's exponential space complexity O(bd)O(b^d)O(bd) is negligible here.

2. BFS Comparison​

  • BFS Path: S→B→G\mathbf{S \to B \to G}S→B→G (2 hops).
  • BFS Cost: c(S−B)+c(B−G)=4+6=10c(S-B) + c(B-G) = 4 + 6 = \mathbf{10}c(S−B)+c(B−G)=4+6=10.
  • Why it differs:
    • BFS minimizes edge count (treats all costs as 111). It selects S→B→GS \to B \to GS→B→G because it has only 2 edges.
    • UCS minimizes cumulative cost (∑c\sum c∑c). It selects S→A→B→C→GS \to A \to B \to C \to GS→A→B→C→G because its total cost is lower (7<107 < 107<10).

3. Bidirectional Search​

  • Concept: Runs two concurrent searches: forward from start SSS and backward from goal GGG, stopping when their frontiers meet.
  • Time Complexity: O(bd/2)\mathbf{O(b^{d/2})}O(bd/2) (compared to O(bd)O(b^d)O(bd) for BFS, providing an exponential speedup).
  • Two Conditions Needed:
    1. Reversible Operators: A predecessor function PREDECESSORS(s)\text{PREDECESSORS}(s)PREDECESSORS(s) must exist to generate parent nodes backwards from GGG.
    2. Explicit Goal State: The goal state must be known explicitly (not an abstract property like "checkmate").

Question 5: Smart City AI Systems (Agent Architectures)​

info

Question Statement

A smart city is deploying the five AI systems below:

System Descriptions:

System IDDescription
S1A street light that switches on when its light sensor reads "dark" and off when it reads "bright".
S2A robot vacuum that keeps an internal map of which rooms it has already cleaned, because it cannot see the whole house at once.
S3A GPS navigator that plans a route to the destination the user types in.
S4A ride-hailing app that picks a route weighing travel time, fuel cost and passenger comfort.
S5A spam filter that improves its accuracy each time a user marks a mail as "spam" or "not spam".

Sub-questions:

  1. Identify the agent type of each system (S1-S5) and justify each answer in one line.
  2. Draw the schematic diagram of a learning agent. Label its four components and explain the role of each, using S5 as the example.
  3. S1 works well, but S2 could not be built as a simple reflex agent. Explain why, using the idea of a partially observable environment.

Model Answer​

1. System Classification​

SystemAgent TypeOne-Line Justification
S1Simple Reflex AgentMaps current sensor input directly to action (dark →\to→ ON) without history.
S2Model-Based Reflex AgentKeeps an internal map to track unobservable state in a partially observable world.
S3Goal-Based AgentPerforms path planning to achieve a specified goal destination.
S4Utility-Based AgentEvaluates tradeoffs between conflicting goals (time, fuel, comfort) using a utility function.
S5Learning AgentDynamically adapts classification parameters based on user feedback to improve accuracy.

2. Learning Agent Diagram & 4 Components (Applied to S5)​

  1. Critic: Compares the filter's prediction against user labels ("spam" / "not spam") and generates an error signal.
  2. Learning Element: Updates word probabilities and classification weights based on feedback from the critic.
  3. Performance Element: The active classifier that scores incoming emails and routes them to Inbox or Spam.
  4. Problem Generator: Identifies ambiguous emails near the decision boundary to request user verification.

3. Reflex Agent Viability: S1 vs. S2​

  • S1 is Fully Observable: The current light sensor reading contains all necessary information to decide action (P→AP \to AP→A).
  • S2 is Partially Observable: The vacuum only senses its current room, not the status of other rooms. A simple reflex vacuum cannot tell if a clean-looking room was cleaned recently or needs cleaning, causing infinite loops and incomplete coverage. S2 requires an internal state (map) to function correctly.
