Question Statement

Describe the independent and dependent variable with example? (2 Marks)

Solution 1 (2 Marks)​

  • Independent Variable (XXX): The input, predictor, or controlled feature manipulated or observed to evaluate its effect on the system. It is assumed to be exogenous.
  • Dependent Variable (YYY): The outcome, response, or target variable whose variation is modeled and predicted as a function of XXX: Y=f(X)+ϵY = f(X) + \epsilonY=f(X)+ϵ
  • Concrete Example: In housing price prediction, the living area in square feet (XXX) is the independent variable, while the final selling price in dollars (YYY) is the dependent variable.

Solution 3 (2 Marks)​

For an estimator f^(x)\hat{f}(x)f^​(x) predicting true target f(x)f(x)f(x) across training sets D\mathcal{D}D:

  • Bias (Underfitting Error): The systematic deviation of the model's expected prediction from the ground truth: Bias⁡[f^(x)]=E[f^(x)]−f(x)\operatorname{Bias}[\hat{f}(x)] = \mathbb{E}[\hat{f}(x)] - f(x)Bias[f^​(x)]=E[f^​(x)]−f(x) High bias stems from overly simplistic assumptions, causing the model to miss underlying trends.

Explain the ROC curve with neat diagram? (2 Marks)

Solution 4 (2 Marks)​

  • Definition: The Receiver Operating Characteristic (ROC) curve evaluates classifier discrimination by plotting the True Positive Rate (TPR) against the False Positive Rate (FPR) across all decision thresholds τ∈[0,1]\tau \in [0, 1]τ∈[0,1].
  • Coordinate Axes:
    • Y-Axis: TPR=Recall=TPTP+FN\text{TPR} = \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}TPR=Recall=TP+FNTP​
    • X-Axis: FPR=1−Specificity=FPFP+TN\text{FPR} = 1 - \text{Specificity} = \frac{\text{FP}}{\text{FP} + \text{TN}}FPR=1−Specificity=FP+TNFP​
  • Area Under the Curve (AUC): An AUC=1.0\text{AUC} = 1.0AUC=1.0 indicates perfect separability; AUC=0.5\text{AUC} = 0.5AUC=0.5 represents random guessing.

Question 7 (2 Marks)​

info

Question Statement

Signify the importance of non-linear machine learning models used in supervised classification. (2 Marks)

Solution 7 (2 Marks)​

  • Overcoming Linear Inseparability: Real-world datasets (e.g., XOR patterns, concentric circles, complex fraud topologies) cannot be separated by an affine hyperplane (wTx+b=0\mathbf{w}^T \mathbf{x} + b = 0wTx+b=0). Linear models suffer from severe high bias (underfitting) on such tasks.
  • Automated Feature Interactions: Non-linear models (Decision Trees, Kernel SVMs, Neural Networks, Ensembles) learn curved, multi-modal boundaries without requiring manual polynomial feature engineering.

What cost function is used for evaluating the loss of the logistic regression model? (2 Marks)

Solution 12 (2 Marks)​

  • Cost Function: The Binary Cross-Entropy Loss (Log Loss), derived via Maximum Likelihood Estimation (MLE): J(w,b)=−1N∑i=1N[yiln⁡(p^i)+(1−yi)ln⁡(1−p^i)]J(\mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \right]J(w,b)=−N1​∑i=1N​[yi​ln(p^​i​)+(1−yi​)ln(1−p^​i​)] where p^i=σ(wTxi+b)\hat{p}_i = \sigma(\mathbf{w}^T \mathbf{x}_i + b)p^​i​=σ(wTxi​+b) and yi∈{0,1}y_i \in \{0, 1\}yi​∈{0,1}.

Question 13 (2 Marks)​

info

Question Statement

What is Overfitting and Underfitting? (2 Marks)

Solution 13 (2 Marks)​

  • Underfitting (High Bias, Low Variance):
    • Symptom: High training error and high test error (Etrain≫0,Etest≫0E_{\text{train}} \gg 0, E_{\text{test}} \gg 0Etrain​≫0,Etest​≫0).
    • Cause: Model is too simple to capture the underlying pattern (e.g., fitting a straight line to quadratic data).
  • Overfitting (Low Bias, High Variance):
    • Symptom: Near-zero training error but high test error (Etrain≈0,Etest≫0E_{\text{train}} \approx 0, E_{\text{test}} \gg 0Etrain​≈0,Etest​≫0).
    • Cause: Model is overly complex and memorizes localized noise and outliers instead of generalizable trends.

  • Parameters:

Question 15 (2 Marks)​

info

Question Statement

Define Up Sampling and Down Sampling? (2 Marks)

Solution 15 (2 Marks)​

Data-level resampling techniques used to resolve class imbalance:

  • Up-Sampling (Over-sampling): Increases the minority class count to match the majority class. Modern approaches use SMOTE (Synthetic Minority Over-sampling Technique) to interpolate synthetic feature vectors between kkk-nearest minority neighbors.
  • Down-Sampling (Under-sampling): Decreases majority class instances to match minority frequency by randomly removing or strategically filtering majority samples (e.g., NearMiss, Tomek Links).

How decision tree handles the overfitting? (2 Marks)

Solution 16 (2 Marks)​

Decision trees control overfitting through two primary mechanisms:

  1. Pre-Pruning (Early Stopping): Stops tree expansion during construction if stopping constraints are reached:
    • Setting max_depth, min_samples_split, min_samples_leaf, or max_leaf_nodes.
  2. Post-Pruning (Cost-Complexity Pruning): Grows the tree to maximum depth, then collapses non-critical subtrees bottom-up using a complexity penalty: Rα(T)=R(T)+α∣T∣R_\alpha(T) = R(T) + \alpha \lvert T \rvertRα​(T)=R(T)+α∣T∣ where R(T)R(T)R(T) is classification error and ∣T∣\lvert T \rvert∣T∣ is leaf count.

Question 17 (2 Marks)​

info

Question Statement

What is ensemble learning and write the types? (2 Marks)

Solution 17 (2 Marks)​

  • Definition: Ensemble learning combines predictions from multiple base models (weak learners) to produce a unified model with lower variance, lower bias, and superior generalization.
  • Four Primary Types:
    1. Bagging (Bootstrap Aggregating): Parallel training on resampled subsets (e.g., Random Forest).
    2. Boosting: Sequential adaptive training correcting previous errors (e.g., AdaBoost, XGBoost).
    3. Stacking: Training a meta-model on predictions from heterogeneous base models.
    4. Voting: Aggregating predictions via hard (majority) or soft (probability average) voting.

Question 18 (2 Marks)​

info

Question Statement

Signify the advantages of random forest technique. (2 Marks)

Solution 18 (2 Marks)​

  1. Variance Reduction Without Overfitting: Adding more trees monotonically stabilizes variance without increasing test error.
  2. Tree Decorrelation: Random feature subspacing (m=pm = \sqrt{p}m=p​) prevents dominant features from dictating every tree split, driving pairwise correlation ρ→0\rho \to 0ρ→0.
  3. Built-in Out-of-Bag (OOB) Validation: Provides an unbiased error estimate during training without requiring a separate holdout set.
  4. Native Feature Importance: Computes feature contributions automatically via Mean Decrease in Impurity (MDI).

Question 23 (2 Marks)​

info

Question Statement

What is Data imbalance and how it affects the model performance? (2 Marks)

Solution 23 (2 Marks)​

  • Definition: Severe disparity in class frequencies where majority instances vastly outnumber minority instances (e.g., 99%99\%99% legitimate, 1%1\%1% fraud).
  • Adverse Impacts:
    1. The Accuracy Paradox: A model predicting the majority class exclusively achieves 99%99\%99% accuracy while detecting 0%0\%0% of minority targets.
    2. Decision Boundary Drift: Standard loss functions treat all errors equally, causing decision boundaries to collapse toward the minority class.

Solution 25 (2 Marks)​

  • Definition: Bayes' Theorem calculates the posterior probability of a hypothesis HHH given observed evidence EEE by inverting likelihood probabilities.
  • Mathematical Formula: P(H∣E)=P(E∣H)P(H)P(E)P(H \mid E) = \frac{P(E \mid H) P(H)}{P(E)}P(H∣E)=P(E)P(E∣H)P(H)​

Question 26 (2 Marks)​

info

Question Statement

What are the various steps involved in building a machine learning model? (2 Marks)

Solution 26 (2 Marks)​

  1. Problem Definition: Specify the business target, problem type (classification/regression), and evaluation metric.
  2. Data Collection & Cleaning: Ingest raw data; resolve missing values, corrupt records, and outliers.
  3. Exploratory Data Analysis (EDA): Assess feature distributions, skewness, correlations, and class balance.
  4. Feature Engineering & Preprocessing: Encode categorical variables, scale numerical features, split into train/val/test sets.
  5. Model Training: Fit candidate baseline and ensemble algorithms.
  6. Hyperparameter Tuning: Optimize model parameters via stratified cross-validation.
  7. Evaluation & Deployment: Audit performance on held-out test data; deploy via REST API with performance drift monitoring.
