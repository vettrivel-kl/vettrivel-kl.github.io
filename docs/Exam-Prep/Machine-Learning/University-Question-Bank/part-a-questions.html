Question 1 (2 Marks)​

info

Question Statement

Describe the independent and dependent variable with example? (2 Marks)

Solution 1 (2 Marks)​

  • Independent Variable (XXX): The input, predictor, or explanatory feature manipulated or observed to measure its effect. It is assumed to be exogenous and error-free.
  • Dependent Variable (YYY): The outcome, response, or target variable whose variation is modeled and predicted as a function of XXX.
  • Mathematical Model: Y=f(X)+ϵY = f(X) + \epsilonY=f(X)+ϵ.
  • Example: In house price prediction, the living area in square feet (XXX) is the independent variable, while the selling price in dollars (YYY) is the dependent variable.

Question Statement

Define Variance and Bias? (2 Marks)

Solution 3 (2 Marks)​

Given an estimator f^(x)\hat{f}(x)f^​(x) trained on dataset D\mathcal{D}D predicting true target f(x)f(x)f(x):

  • Bias: The systematic error caused by overly simplistic assumptions in the model, measuring how far the average prediction deviates from the true target: Bias⁡[f^(x)]=E[f^(x)]−f(x)\operatorname{Bias}[\hat{f}(x)] = \mathbb{E}[\hat{f}(x)] - f(x)Bias[f^​(x)]=E[f^​(x)]−f(x) (High bias leads to Underfitting).
  • Variance: The sensitivity of the model to fluctuations in the training dataset, measuring how much predictions scatter around their mean across different training draws: Var⁡[f^(x)]=E[(f^(x)−E[f^(x)])2]\operatorname{Var}[\hat{f}(x)] = \mathbb{E}\left[ \left(\hat{f}(x) - \mathbb{E}[\hat{f}(x)]\right)^2 \right]Var[f^​(x)]=E[(f^​(x)−E[f^​(x)])2] (High variance leads to Overfitting).

Question Statement

Explain the ROC curve with neat diagram? (2 Marks)

Solution 4 (2 Marks)​

The Receiver Operating Characteristic (ROC) curve evaluates classifier performance across all decision thresholds τ∈[0,1]\tau \in [0, 1]τ∈[0,1]:

  • Y-Axis: True Positive Rate (TPR=Recall=TPTP+FN\text{TPR} = \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}TPR=Recall=TP+FNTP​).
  • X-Axis: False Positive Rate (FPR=1−Specificity=FPFP+TN\text{FPR} = 1 - \text{Specificity} = \frac{\text{FP}}{\text{FP} + \text{TN}}FPR=1−Specificity=FP+TNFP​).
  • Area Under the Curve (AUC): Measures threshold-independent ranking capability. An AUC=1.0\text{AUC} = 1.0AUC=1.0 represents a flawless classifier, while AUC=0.5\text{AUC} = 0.5AUC=0.5 represents random coin-toss guessing.

Question 7 (2 Marks)​

info

Question Statement

Signify the importance of non-linear machine learning models used in supervised classification. (2 Marks)

Solution 7 (2 Marks)​

  • Failure of Linear Separability: Real-world datasets (e.g., XOR patterns, concentric distributions, gene expression profiles) cannot be separated by an affine hyperplane (wTx+b=0\mathbf{w}^T \mathbf{x} + b = 0wTx+b=0). Linear models suffer from severe high bias (underfitting) on such data.
  • Expressive Capacity: Non-linear models (Decision Trees, Kernel Support Vector Machines, Random Forests, Multi-Layer Perceptrons) learn complex, curved, multi-modal decision boundaries without requiring manual polynomial feature expansion, capturing intricate feature interactions automatically.

Solution 11 (2 Marks)​

Question Statement

What cost function is used for evaluating the loss of the logistic regression model? (2 Marks)

Solution 12 (2 Marks)​

The cost function used in Logistic Regression is the Binary Cross-Entropy Loss (Log Loss), derived via Maximum Likelihood Estimation (MLE):

J(w,b)=−1N∑i=1N[yiln⁡(p^i)+(1−yi)ln⁡(1−p^i)]J(\mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \right]J(w,b)=−N1​i=1∑N​[yi​ln(p^​i​)+(1−yi​)ln(1−p^​i​)]

where p^i=σ(wTxi+b)\hat{p}_i = \sigma(\mathbf{w}^T \mathbf{x}_i + b)p^​i​=σ(wTxi​+b) and yi∈{0,1}y_i \in \{0, 1\}yi​∈{0,1}.

  • Why not Mean Squared Error (MSE)? When combined with the non-linear sigmoid function, MSE generates a non-convex surface plagued by multiple suboptimal local minima. Cross-entropy guarantees a strictly convex surface with a unique global minimum.

Question 13 (2 Marks)​

info

Question Statement

What is Overfitting and Underfitting? (2 Marks)

Solution 13 (2 Marks)​

  • Underfitting (High Bias, Low Variance): The model is overly simplistic and incapable of capturing the underlying data structure. It exhibits high training error and high validation error (Etrain≫0,Eval≫0E_{\text{train}} \gg 0, E_{\text{val}} \gg 0Etrain​≫0,Eval​≫0).
  • Overfitting (Low Bias, High Variance): The model is overly complex and memorizes noise, outliers, and idiosyncratic artifacts of the training set. It exhibits near-zero training error but high validation error (Etrain≈0,Eval≫0E_{\text{train}} \approx 0, E_{\text{val}} \gg 0Etrain​≈0,Eval​≫0).

Solution 14 (2 Marks)​

Cohen's Kappa (κ\kappaκ) measures inter-rater or model-to-ground-truth agreement for categorical items, correcting for agreement that occurs purely by chance:

κ=po−pe1−pe\kappa = \frac{p_o - p_e}{1 - p_e}κ=1−pe​po​−pe​​

where:

  • pop_opo​: Observed accuracy (proportion of agreed instances, TP+TNN\frac{\text{TP} + \text{TN}}{N}NTP+TN​).
  • pep_epe​: Expected hypothetical probability of chance agreement based on marginal totals.
  • Interpretation: κ≤0\kappa \le 0κ≤0 indicates chance agreement; 0.61−0.800.61 - 0.800.61−0.80 indicates substantial agreement; 0.81−1.000.81 - 1.000.81−1.00 indicates near-perfect agreement. It is vastly superior to raw accuracy on imbalanced datasets.

Question 15 (2 Marks)​

info

Question Statement

Define Up Sampling and Down Sampling? (2 Marks)

Solution 15 (2 Marks)​

Data-level resampling techniques to rectify class imbalance:

  • Up-Sampling (Over-sampling): Increases the number of minority class instances to match the majority class. Techniques include random duplication or synthetic feature interpolation using SMOTE (Synthetic Minority Over-sampling Technique).
  • Down-Sampling (Under-sampling): Decreases the number of majority class instances by randomly or deterministically removing instances (e.g., NearMiss, Tomek Links) to match the minority count.

How decision tree handles the overfitting? (2 Marks)

Solution 16 (2 Marks)​

Decision trees control overfitting via two mechanisms:

  1. Pre-Pruning (Early Stopping): Stops tree growth during training if constraint thresholds are reached (e.g., setting max_depth, min_samples_split, min_samples_leaf, or max_leaf_nodes).
  2. Post-Pruning (Cost-Complexity Pruning): Grows the tree to full depth, then collapses non-critical branches bottom-up using a complexity penalty: Rα(T)=R(T)+α∣T∣R_\alpha(T) = R(T) + \alpha \lvert T \rvertRα​(T)=R(T)+α∣T∣

Question 17 (2 Marks)​

info

Question Statement

What is ensemble learning and write the types? (2 Marks)

Solution 17 (2 Marks)​

  • Ensemble Learning: An algorithmic meta-paradigm that combines predictions from multiple diverse base models (weak learners) to produce a unified model with superior predictive accuracy and generalization.
  • Primary Types:
    1. Bagging (Bootstrap Aggregation): Parallel independent training (e.g., Random Forest).
    2. Boosting: Sequential adaptive error correction (e.g., AdaBoost, XGBoost, LightGBM).
    3. Stacking (Stacked Generalization): Training a meta-model on predictions of diverse base classifiers.
    4. Voting: Aggregating outputs via hard (majority) or soft (average probability) voting.

Question 18 (2 Marks)​

info

Question Statement

Signify the advantages of random forest technique. (2 Marks)

Solution 18 (2 Marks)​

  1. Immunity to Overfitting: Adding more trees monotonically stabilizes variance without increasing generalization error.
  2. Decorrelation of Trees: Random feature subspacing (m=pm = \sqrt{p}m=p​) ensures individual trees do not split on the same dominant features, driving variance down.
  3. Built-in Out-of-Bag (OOB) Validation: Provides an unbiased internal error estimate without requiring a separate validation holdout split.
  4. Automatic Feature Importance: Quantifies variable contribution via Mean Decrease in Impurity (MDI).

Question 23 (2 Marks)​

info

Question Statement

What is Data imbalance and how it affects the model performance? (2 Marks)

Solution 23 (2 Marks)​

  • Definition: A severe disparity in class frequencies where the majority class vastly outnumbers the minority class (e.g., 99%99\%99% healthy, 1%1\%1% diseased).
  • Adverse Impacts:
    1. Accuracy Paradox: A trivial classifier predicting the majority class for all instances achieves 99%99\%99% accuracy while detecting 0%0\%0% of minority targets.
    2. Decision Boundary Drift: Cost functions treat all errors equally, causing decision boundaries to collapse toward the minority class.

Define Bayes Theorem (2 Marks)

Solution 25 (2 Marks)​

Bayes' Theorem mathematically inverts conditional probabilities to update prior belief upon observing evidence:

P(A∣B)=P(B∣A)P(A)P(B)P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)}P(A∣B)=P(B)P(B∣A)P(A)​

where:

  • P(A∣B)P(A \mid B)P(A∣B): Posterior probability (hypothesis AAA given evidence BBB).
  • P(B∣A)P(B \mid A)P(B∣A): Likelihood of observing evidence BBB given hypothesis AAA.
  • P(A)P(A)P(A): Prior probability of hypothesis AAA.
  • P(B)=∑iP(B∣Ai)P(Ai)P(B) = \sum_i P(B \mid A_i)P(A_i)P(B)=∑i​P(B∣Ai​)P(Ai​): Marginal probability of evidence (normalization constant).

Question 26 (2 Marks)​

info

Question Statement

What are the various steps involved in building a machine learning model? (2 Marks)

Solution 26 (2 Marks)​

  1. Problem Formulation: Define business objectives, prediction target, and evaluation metric.
  2. Data Ingestion & Cleaning: Handle missing values, outliers, and duplicates.
  3. Exploratory Data Analysis (EDA): Assess distributions, skewness, and correlations.
  4. Feature Engineering & Preprocessing: Encode categorical variables, scale numerical features, train/test split.
  5. Model Selection & Training: Fit candidate baseline and ensemble models.
  6. Hyperparameter Optimization & Validation: Tune parameters via stratified cross-validation.
  7. Model Evaluation & Deployment: Audit on out-of-sample test set; deploy via API with continuous monitoring.
