Solution 3: Splitting Criteria & Hyperparameters (Main Option)​

(i) Splitting Criteria: Gini Index vs. Information Gain​
  • Gini Impurity (CART): Measures probability of misclassifying a randomly chosen element: IG(S)=1−∑i=1Cpi2I_G(S) = 1 - \sum_{i=1}^C p_i^2IG​(S)=1−∑i=1C​pi2​ Range: [0,0.5][0, 0.5][0,0.5] for binary splits. Minimizes computation by avoiding logarithms.
  • Information Gain (ID3 / C4.5): Measures reduction in Shannon Entropy: H(S)=−∑i=1Cpilog⁡2(pi),Gain⁡(S,A)=H(S)−∑v∈Values⁡(A)∣Sv∣∣S∣H(Sv)H(S) = - \sum_{i=1}^C p_i \log_2(p_i), \quad \operatorname{Gain}(S, A) = H(S) - \sum_{v \in \operatorname{Values}(A)} \frac{\lvert S_v \rvert}{\lvert S \rvert} H(S_v)H(S)=−∑i=1C​pi​log2​(pi​),Gain(S,A)=H(S)−∑v∈Values(A)​∣S∣∣Sv​∣​H(Sv​)
(ii) Decision Tree Hyperparameters​
  1. max_depth: Limits maximum vertical depth to stop learning sample-specific noise.
  2. min_samples_split: Minimum samples required to attempt a split at an internal node.
  3. min_samples_leaf: Minimum samples mandated in every terminal leaf.
  4. max_features: Number of candidate features evaluated at each split (m=pm = \sqrt{p}m=p​).

Solution 4: Bagging, Stacking & Voting (Main Option)​

  1. Bagging (Bootstrap Aggregation):
    • Resampling: Draws BBB independent samples of size NNN with replacement. Each tree sees ≈63.2%\approx 63.2\%≈63.2% unique rows, leaving e−1≈36.8%e^{-1} \approx 36.8\%e−1≈36.8% as Out-of-Bag (OOB) validation samples.
    • Aggregation: Consolidated via plurality vote: Y^=arg⁡max⁡c∑b=1BI(y^b=c)\hat{Y} = \arg\max_c \sum_{b=1}^B \mathbb{I}(\hat{y}_b = c)Y^=argmaxc​∑b=1B​I(y^​b​=c).
  2. Voting Classifiers:
    • Hard Voting: Plurality vote among base model predictions (mode(y^1,…,y^M)\text{mode}(\hat{y}_1, \dots, \hat{y}_M)mode(y^​1​,…,y^​M​)).
    • Soft Voting: Averages predicted probabilities: y^=arg⁡max⁡c1M∑Pm(Y=c∣x)\hat{y} = \arg\max_c \frac{1}{M}\sum P_m(Y = c \mid \mathbf{x})y^​=argmaxc​M1​∑Pm​(Y=c∣x).
  3. Stacking (Stacked Generalization):
    • Heterogeneous base estimators (SVM, Random Forest, XGBoost) generate cross-validated predictions.
    • A Meta-Learner (Logistic Regression / ElasticNet) trains on these predictions to assign optimal regional weights.

Solution 3 (OR): Class Imbalance & Decision Tree Algorithm​

  1. Class Imbalance Impact & Remediation: Accuracy paradox; solved via SMOTE oversampling, NearMiss undersampling, and Cost-Sensitive loss reweighting.
  2. Decision Tree Algorithm (ID3 / CART):
    • Evaluate all features; compute Information Gain / Gini reduction.
    • Split node on attribute maximizing gain; recurse on subsets until pure or stopping criteria met.
  3. Entropy Method for Feature Importance: Features that yield the largest cumulative reductions in entropy across all tree splits hold the highest feature importance.
