Question Statement

Explain in detail about different types of learning methods in machine learning with examples. (16 Marks)

Solution 1 (16 Marks)​

Machine learning paradigms are categorized based on the nature of learning signals, presence of ground truth annotations, and environmental interaction protocols:

1. Supervised Learning​

  • Mathematical Formalism: Given a training dataset D={(xi,yi)}i=1N\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^ND={(xi​,yi​)}i=1N​ drawn i.i.d. from unknown joint distribution P(X,Y)P(\mathbf{X}, Y)P(X,Y), find a hypothesis function f^∈H\hat{f} \in \mathcal{H}f^​∈H minimizing empirical risk: f^=arg⁡min⁡f∈H1N∑i=1NL(f(xi),yi)+λΩ(f)\hat{f} = \arg\min_{f \in \mathcal{H}} \frac{1}{N} \sum_{i=1}^N \mathcal{L}(f(\mathbf{x}_i), y_i) + \lambda \Omega(f)f^​=argminf∈H​N1​∑i=1N​L(f(xi​),yi​)+λΩ(f)
  • Sub-Types:
    • Regression: Continuous target y∈Ry \in \mathbb{R}y∈R (e.g., Linear Regression, Ridge, SVR predicting house prices).
    • Classification: Discrete target y∈{C1,…,CK}y \in \{C_1, \dots, C_K\}y∈{C1​,…,CK​} (e.g., Logistic Regression, Random Forest predicting loan default).

2. Unsupervised Learning​

  • Mathematical Formalism: Given unlabelled feature vectors D={xi}i=1N\mathcal{D} = \{\mathbf{x}_i\}_{i=1}^ND={xi​}i=1N​, discover intrinsic geometric structure, cluster assignments cic_ici​, or a lower-dimensional latent representation zi∈Rk\mathbf{z}_i \in \mathbb{R}^kzi​∈Rk (k≪dk \ll dk≪d).
  • Sub-Types:
    • Clustering: Partitioning observations into cohesive groups maximizing inter-cluster separation (e.g., KKK-Means, DBSCAN).
    • Dimensionality Reduction: Projecting data while preserving maximum variance or pairwise geodesics (e.g., PCA, t-SNE, UMAP).
    • Density Estimation: Modeling probability density function p(x)p(\mathbf{x})p(x) (e.g., Gaussian Mixture Models, Isolation Forest).

3. Semi-Supervised Learning​

  • Mathematical Formalism: Employs a small labelled dataset DL={(xi,yi)}i=1l\mathcal{D}_L = \{(\mathbf{x}_i, y_i)\}_{i=1}^lDL​={(xi​,yi​)}i=1l​ alongside a substantially larger unlabelled dataset DU={xj}j=l+1l+u\mathcal{D}_U = \{\mathbf{x}_j\}_{j=l+1}^{l+u}DU​={xj​}j=l+1l+u​ (u≫lu \gg lu≫l).
  • Core Assumption (Cluster / Manifold Assumption): Points sharing the same high-density cluster or low-dimensional manifold belong to the same class.
  • Techniques & Example: Pseudo-labeling, Label Propagation. In medical imaging, a radiologist labels 200 MRI scans, while 50,000 unlabelled scans guide feature representations via contrastive learning.

4. Reinforcement Learning (RL)​

  • Mathematical Formalism: Formulated as a Markov Decision Process (MDP) defined by tuple ⟨S,A,P,R,γ⟩\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle⟨S,A,P,R,γ⟩. An agent in state st∈Ss_t \in \mathcal{S}st​∈S selects action at∈Aa_t \in \mathcal{A}at​∈A under policy π(at∣st)\pi(a_t \mid s_t)π(at​∣st​), receiving scalar reward rtr_trt​ and transitioning to state st+1s_{t+1}st+1​: π∗=arg⁡max⁡πE[∑t=0∞γtrt]\pi^* = \arg\max_\pi \mathbb{E}\left[ \sum_{t=0}^\infty \gamma^t r_t \right]π∗=argmaxπ​E[∑t=0∞​γtrt​]
  • Example: Autonomous vehicle trajectory control, AlphaGo, and robotic arm manipulation.

a) Derivation of Logistic Regression from Linear Regression (8 Marks)​

1. The Limitation of Standard Linear Regression​

Standard linear regression models the dependent variable as an affine linear combination: z=wTx+b∈(−∞,+∞)z = \mathbf{w}^T \mathbf{x} + b \in (-\infty, +\infty)z=wTx+b∈(−∞,+∞) For binary classification (Y∈{0,1}Y \in \{0, 1\}Y∈{0,1}), modeling posterior probability P(Y=1∣x)P(Y = 1 \mid \mathbf{x})P(Y=1∣x) directly with zzz violates Kolmogorov's axioms because zzz can evaluate to z<0z < 0z<0 or z>1z > 1z>1.

2. Step-by-Step Derivation via Odds and Logit​

To constrain outputs strictly to (0,1)(0, 1)(0,1), we construct the mapping from probability to the real line in three mathematical steps:

Step 1: Odds Ratio​

Let p=P(Y=1∣x)p = P(Y = 1 \mid \mathbf{x})p=P(Y=1∣x). The Odds of the event occurring is the ratio of probability of occurrence to non-occurrence: Odds=p1−p∈[0,+∞)\text{Odds} = \frac{p}{1 - p} \in [0, +\infty)Odds=1−pp​∈[0,+∞)

Step 2: The Logit (Log-Odds) Link Function​

Taking the natural logarithm maps the non-negative interval [0,+∞)[0, +\infty)[0,+∞) onto the full real line (−∞,+∞)(-\infty, +\infty)(−∞,+∞): logit⁡(p)=ln⁡(p1−p)∈(−∞,+∞)\operatorname{logit}(p) = \ln\left(\frac{p}{1 - p}\right) \in (-\infty, +\infty)logit(p)=ln(1−pp​)∈(−∞,+∞)

We now equate this unbounded quantity to the linear regression equation: ln⁡(p1−p)=wTx+b=z\ln\left(\frac{p}{1 - p}\right) = \mathbf{w}^T \mathbf{x} + b = zln(1−pp​)=wTx+b=z

Step 3: Solving for Probability ppp (Sigmoid Inversion)​

Exponentiating both sides: p1−p=ez  ⟹  p=ez(1−p)=ez−pez\frac{p}{1 - p} = e^z \implies p = e^z(1 - p) = e^z - p e^z1−pp​=ez⟹p=ez(1−p)=ez−pez p(1+ez)=ez  ⟹  p=ez1+ezp(1 + e^z) = e^z \implies p = \frac{e^z}{1 + e^z}p(1+ez)=ez⟹p=1+ezez​ Dividing numerator and denominator by eze^zez: p=11+e−z≡σ(z)\mathbf{p = \frac{1}{1 + e^{-z}} \equiv \sigma(z)}p=1+e−z1​≡σ(z)

ii) Class Imbalance: Impact and Rectification Techniques (12 Marks)​

1. Adverse Impacts on Machine Learning Models​
  • The Accuracy Paradox: In fraud detection with 99.5%99.5\%99.5% legitimate and 0.5%0.5\%0.5% fraudulent transactions, a trivial model predicting "Legitimate" for all cases achieves 99.5%99.5\%99.5% accuracy while detecting 0%0\%0% of fraud.
  • Decision Boundary Drift: Standard optimization algorithms minimize global misclassification rate, pushing decision boundaries toward the minority class and treating minority errors as negligible noise.
2. Techniques to Rectify Class Imbalance​
A. Data-Level Resampling Techniques​
  1. Synthetic Minority Over-sampling Technique (SMOTE):
    • Instead of simple duplication (which causes overfitting), SMOTE synthesizes new minority points along the line segment connecting kkk-nearest minority neighbors: xnew=xi+λ(xzi−xi),λ∼U(0,1)\mathbf{x}_{\text{new}} = \mathbf{x}_i + \lambda (\mathbf{x}_{zi} - \mathbf{x}_i), \quad \lambda \sim \mathcal{U}(0, 1)xnew​=xi​+λ(xzi​−xi​),λ∼U(0,1)
  2. NearMiss Undersampling:
    • Selects majority class instances based on distance to nearest minority instances to eliminate redundant samples.
B. Algorithm-Level Modifications​
  1. Cost-Sensitive Learning (Class Weighting):
    • Assigns penalty weights inversely proportional to class frequencies: wc=NK⋅Ncw_c = \frac{N}{K \cdot N_c}wc​=K⋅Nc​N​ Misclassifying a rare fraud transaction is penalized 100×100\times100× more than misclassifying a legitimate one.
  2. Focal Loss:
    • Adds a modulating factor (1−pt)γ(1 - p_t)^\gamma(1−pt​)γ to cross-entropy to suppress gradients from well-classified easy examples.
C. Post-Processing: Threshold Moving​
  • Shifts the classification threshold from default τ=0.5\tau = 0.5τ=0.5 to a lower probability (e.g., τ=0.15\tau = 0.15τ=0.15) to maximize Recall or F1F_1F1​-score on the minority class.

Solution 4 (16 Marks)​

1. Confusion Matrix Concept and Metric Definitions (6 Marks)​

A Confusion Matrix is a contingency layout that cross-tabulates actual ground truth labels against model predictions, allowing granular evaluation of classifier performance:

  • Accuracy: Overall proportion of correct classifications: Accuracy=TP+TNTotal N\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{Total } N}Accuracy=Total NTP+TN​
  • Recall (Sensitivity / True Positive Rate): Proportion of actual positives correctly identified: Recall=TPTP+FN\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}Recall=TP+FNTP​
  • Precision (Positive Predictive Value): Proportion of predicted positives that are truly positive: Precision=TPTP+FP\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}Precision=TP+FPTP​
  • F1F_1F1​-Score: The harmonic mean of precision and recall: F1=2×Precision×RecallPrecision+Recall=2TP2TP+FP+FNF_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\text{TP}}{2\text{TP} + \text{FP} + \text{FN}}F1​=2×Precision+RecallPrecision×Recall​=2TP+FP+FN2TP​
  • False Positive Rate (FPR / Fall-out): Proportion of actual negatives incorrectly flagged as positive: FPR=FPFP+TN=1−Specificity\text{FPR} = \frac{\text{FP}}{\text{FP} + \text{TN}} = 1 - \text{Specificity}FPR=FP+TNFP​=1−Specificity

Solution 6 (16 Marks)​

1. Bagging, Stacking, and Voting Ensembles (16 Marks)​

a) Bagging (Bootstrap Aggregation) Mechanics (10 Marks)​

Bagging reduces the variance of unstable, high-capacity estimators by training multiple independent models on resampled subsets:

  1. Bootstrap Resampling: From training set D\mathcal{D}D of size NNN, sample NNN points uniformly with replacement. The probability of an instance not being chosen is: lim⁡N→∞(1−1N)N=e−1≈0.368 (36.8%)\lim_{N \to \infty} \left(1 - \frac{1}{N}\right)^N = e^{-1} \approx 0.368 \ (36.8\%)limN→∞​(1−N1​)N=e−1≈0.368 (36.8%) Thus, each base model trains on ≈63.2%\approx 63.2\%≈63.2% unique instances, leaving 36.8%36.8\%36.8% as Out-of-Bag (OOB) samples.
  2. Parallel Execution: All BBB base estimators train independently in parallel.
  3. Aggregation: Binary/multiclass predictions are consolidated via plurality vote: Y^=arg⁡max⁡c∈{1,…,K}∑b=1BI(y^b=c)\hat{Y} = \arg\max_{c \in \{1, \dots, K\}} \sum_{b=1}^B \mathbb{I}(\hat{y}_b = c)Y^=argmaxc∈{1,…,K}​∑b=1B​I(y^​b​=c)
b) Stacking and Voting Ensembles (6 Marks)​
  • Voting Classifier:
    • Hard Voting: Predicts the class receiving the simple majority of individual model votes (mode(y^1,…,y^M)\text{mode}(\hat{y}_1, \dots, \hat{y}_M)mode(y^​1​,…,y^​M​)).
    • Soft Voting: Averages predicted class probabilities across all models and selects the class maximizing average probability: y^=arg⁡max⁡c1M∑m=1MPm(Y=c∣x)\hat{y} = \arg\max_{c} \frac{1}{M}\sum_{m=1}^M P_m(Y = c \mid \mathbf{x})y^​=argmaxc​M1​∑m=1M​Pm​(Y=c∣x)
  • Stacking (Stacked Generalization):
    • Heterogeneous base models (M1M_1M1​: SVM, M2M_2M2​: Random Forest, M3M_3M3​: XGBoost) generate out-of-fold predictions.
    • A Meta-Learner (typically Logistic Regression or ElasticNet) trains on these predictions as input features to learn which base models perform best in different regions of the feature space.

2. OR: Random Forest Algorithm and Hyperparameter Tuning (16 Marks)​

1. Algorithmic Overview​

Random Forest introduces Random Feature Subspacing to standard bagging: at every candidate node split, only a random subset of m≈pm \approx \sqrt{p}m≈p​ features is considered.

2. The Decorrelation Mechanism​

For an ensemble of BBB trees with individual variance σ2\sigma^2σ2 and pairwise correlation ρ\rhoρ: Var⁡(Tˉ)=ρσ2+1−ρBσ2\operatorname{Var}(\bar{T}) = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2Var(Tˉ)=ρσ2+B1−ρ​σ2 As BBB grows large, variance approaches ρσ2\rho \sigma^2ρσ2. Random feature selection drives ρ→0\rho \to 0ρ→0, reducing overall ensemble variance without increasing bias.

3. Hyperparameter Justification​
  • n_estimators: Increasing trees stabilizes predictions and eliminates variance without causing overfitting.
  • max_features: Balances individual tree bias against ensemble correlation ρ\rhoρ (default p\sqrt{p}p​).
  • max_depth & min_samples_split: Prevents individual trees from learning extreme noise.

ii) Gradient Boosting (GBM / XGBoost)​

  1. Interpretability & Governance: Quantifies which variables drive model decisions, fulfilling regulatory explainability requirements (e.g., credit approval).
  2. Dimensionality Reduction: Identifies non-informative features, allowing removal of noisy columns to speed up training.

Solution 8 (16 Marks)​

i) Working Principle of K-Nearest Neighbors (KNN) (10 Marks)​

KNN is an instance-based, non-parametric, lazy learning classifier:

  1. Training Phase (O(1)O(1)O(1) Time): Stores training vectors D={(xi,yi)}i=1N\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^ND={(xi​,yi​)}i=1N​. No parametric function is learned.
  2. Inference Phase (O(N⋅d)O(N \cdot d)O(N⋅d) Time):
    • Distance Evaluation: Compute metric distance D(x∗,xi)D(\mathbf{x}^*, \mathbf{x}_i)D(x∗,xi​) between query point x∗\mathbf{x}^*x∗ and all NNN stored samples.
    • Neighborhood Selection: Sort distances and identify the kkk smallest instances (Nk(x∗)\mathcal{N}_k(\mathbf{x}^*)Nk​(x∗)).
    • Classification: Apply plurality voting: y^=arg⁡max⁡c∑i∈Nk(x∗)I(yi=c)\hat{y} = \arg\max_{c} \sum_{i \in \mathcal{N}_k(\mathbf{x}^*)} \mathbb{I}(y_i = c)y^​=argmaxc​∑i∈Nk​(x∗)​I(yi​=c)
    • Distance-Weighted Voting: Weights votes by inverse distance: wi=1D(x∗,xi)+ϵw_i = \frac{1}{D(\mathbf{x}^*, \mathbf{x}_i) + \epsilon}wi​=D(x∗,xi​)+ϵ1​

ii) Distance Measures and Their Impact on Neighborhoods (6 Marks)​

1. Distance Formulations​
  • Euclidean Distance (L2L_2L2​): d2(u,v)=∑(ui−vi)2d_2(\mathbf{u}, \mathbf{v}) = \sqrt{\sum (u_i - v_i)^2}d2​(u,v)=∑(ui​−vi​)2​. Generates spherical, circular neighborhoods. Highly sensitive to outliers due to squaring.
  • Manhattan Distance (L1L_1L1​): d1(u,v)=∑∣ui−vi∣d_1(\mathbf{u}, \mathbf{v}) = \sum \lvert u_i - v_i \rvertd1​(u,v)=∑∣ui​−vi​∣. Generates diamond-shaped neighborhoods. Robust to outliers and suited for urban grid networks.
  • Minkowski Distance (LpL_pLp​): dp(u,v)=(∑∣ui−vi∣p)1/pd_p(\mathbf{u}, \mathbf{v}) = (\sum \lvert u_i - v_i \rvert^p)^{1/p}dp​(u,v)=(∑∣ui​−vi​∣p)1/p. Generalization (p=1  ⟹  L1,p=2  ⟹  L2p=1 \implies L_1, p=2 \implies L_2p=1⟹L1​,p=2⟹L2​).
  • Cosine Distance: 1−u⋅v∥u∥∥v∥1 - \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}1−∥u∥∥v∥u⋅v​. Evaluates angular orientation, making it invariant to document length in text classification.
2. Impact on Decision Boundaries & Preprocessing Requirement​
  • Scale Dominance Hazard: If Feature A has scale 1000−50,0001000 - 50,0001000−50,000 (income) and Feature B has scale 1−51 - 51−5 (rating), Feature A will completely dominate L2L_2L2​ distance by orders of magnitude.
  • Remedy: Z-score standardization or Min-Max normalization is mandatory prior to running KNN.

Solution 9 (16 Marks)​

a) Core Issues in Supervised Learning Algorithms (6 Marks)​

  1. Bias-Variance Dilemma: High bias causes underfitting; high variance causes overfitting. Achieving minimal out-of-sample error requires optimizing model capacity.
  2. Curse of Dimensionality: As feature dimension d→∞d \to \inftyd→∞, volume of feature space grows exponentially (V∝rdV \propto r^dV∝rd), causing points to become equidistant and rendering distance metrics ineffective.
  3. Label Noise & Measurement Artifacts: Erroneous or subjective annotations corrupt loss gradient updates.
  4. Class Imbalance: Disproportionate class ratios cause models to ignore minority targets.

b) Naïve Bayes Classifier: Principle, Mathematics, and Example (10 Marks)​

1. Mathematical Formulation​

Given feature vector x=[x1,…,xd]T\mathbf{x} = [x_1, \dots, x_d]^Tx=[x1​,…,xd​]T, Bayes' Theorem yields: P(Y=c∣x)=P(Y=c)P(x∣Y=c)P(x)P(Y = c \mid \mathbf{x}) = \frac{P(Y = c) P(\mathbf{x} \mid Y = c)}{P(\mathbf{x})}P(Y=c∣x)=P(x)P(Y=c)P(x∣Y=c)​ Applying the Class-Conditional Independence Assumption: P(x∣Y=c)=∏j=1dP(xj∣Y=c)P(\mathbf{x} \mid Y = c) = \prod_{j=1}^d P(x_j \mid Y = c)P(x∣Y=c)=∏j=1d​P(xj​∣Y=c) The decision rule selects the class maximizing posterior probability: y^=arg⁡max⁡c[ln⁡P(Y=c)+∑j=1dln⁡P(xj∣Y=c)]\hat{y} = \arg\max_{c} \left[ \ln P(Y = c) + \sum_{j=1}^d \ln P(x_j \mid Y = c) \right]y^​=argmaxc​[lnP(Y=c)+∑j=1d​lnP(xj​∣Y=c)]
