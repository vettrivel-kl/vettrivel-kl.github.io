PART 1: LOGISTIC REGRESSION CLASSIFIER IN DETAIL (10 marks)​

1.1 Statistical Definition & GLM Framework (2 marks)​

Logistic Regression is a supervised machine learning algorithm used for binary classification (predicting a target label y∈{0,1}y \in \{0, 1\}y∈{0,1}).

Unlike linear regression, which models continuous outputs directly, Logistic Regression is a Generalized Linear Model (GLM) where:

  1. The target variable is assumed to follow a Bernoulli distribution: yi∼Bernoulli(Pi)y_i \sim \text{Bernoulli}(P_i)yi​∼Bernoulli(Pi​).
  2. We model the conditional probability Pi=P(yi=1∣xi)P_i = P(y_i = 1 \mid \mathbf{x}_i)Pi​=P(yi​=1∣xi​) that the input belongs to the positive class.
  3. The link function used is the non-linear logit link function (log-odds), which maps the continuous range (−∞,∞)(-\infty, \infty)(−∞,∞) of the linear equation to a [0,1][0, 1][0,1] probability range.

1.2 Mathematical Formulation & Sigmoid Activation (2 marks)​

The model starts by computing an unbounded continuous score (the logit score) zzz: z=wTx+b=w1x1+w2x2+⋯+wnxn+bz = \mathbf{w}^T \mathbf{x} + b = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + bz=wTx+b=w1​x1​+w2​x2​+⋯+wn​xn​+b

We convert this unbounded logit score into a bounded conditional probability P(y=1∣x)P(y = 1 \mid \mathbf{x})P(y=1∣x) by passing it through the Sigmoid (Logistic) Function:

P(y=1∣x)=σ(z)=11+e−z=11+e−(wTx+b)\boxed{P(y = 1 \mid \mathbf{x}) = \sigma(z) = \frac{1}{1 + e^{-z}} = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}}P(y=1∣x)=σ(z)=1+e−z1​=1+e−(wTx+b)1​​

Decision Boundary (1 mark)​

To convert the estimated probability into a discrete class prediction y^∈{0,1}\hat{y} \in \{0, 1\}y^​∈{0,1}, a decision threshold τ\tauτ (conventionally τ=0.5\tau = 0.5τ=0.5) is applied:

y^={1if P(y=1∣x)≥0.5(equivalent to z≥0)0if P(y=1∣x)<0.5(equivalent to z<0)\boxed{\hat{y} = \begin{cases} 1 & \text{if } P(y = 1 \mid \mathbf{x}) \ge 0.5 \quad (\text{equivalent to } z \ge 0) \\ 0 & \text{if } P(y = 1 \mid \mathbf{x}) < 0.5 \quad (\text{equivalent to } z < 0) \end{cases}}y^​={10​if P(y=1∣x)≥0.5(equivalent to z≥0)if P(y=1∣x)<0.5(equivalent to z<0)​​

PART 2: LOSS FUNCTION & MINIMIZATION VIA GRADIENT DESCENT (10 marks)​

2.1 What is a Loss Function? (2 marks)​

A Loss Function (or cost function) is a mathematical objective function that quantifies the difference between a model's predicted outputs and the actual ground-truth labels. It maps the error of a model's parameters to a single scalar value.

Why We Cannot Use Mean Squared Error (MSE) for Logistic Regression:​

In linear regression, MSE is convex. However, if we apply MSE to Logistic Regression, squaring the non-linear Sigmoid output results in a non-convex cost function with numerous local minima. Gradient descent can easily get trapped in sub-optimal local minima.

The Solution: Binary Cross-Entropy Loss (Log-Loss):​

Derived from the Maximum Likelihood Estimation (MLE) of a Bernoulli process, we use Log-Loss, which is guaranteed to be convex:

J(w,b)=−1N∑i=1N[yiln⁡(pi)+(1−yi)ln⁡(1−pi)]\boxed{\mathcal{J}(\mathbf{w}, b) = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]}J(w,b)=−N1​i=1∑N​[yi​ln(pi​)+(1−yi​)ln(1−pi​)]​

Where:

  • yiy_iyi​ = Actual ground truth label (000 or 111)
  • pip_ipi​ = Model predicted probability (σ(zi)\sigma(z_i)σ(zi​))
  • NNN = Number of training samples
How the Log-Loss penalizes errors:​
  • If yi=1y_i = 1yi​=1: Loss =−ln⁡(pi)= -\ln(p_i)=−ln(pi​). As prediction pi→1p_i \rightarrow 1pi​→1, Loss →0\rightarrow 0→0. As pi→0p_i \rightarrow 0pi​→0, Loss →∞\rightarrow \infty→∞ (heavily penalizes False Negatives).
  • If yi=0y_i = 0yi​=0: Loss =−ln⁡(1−pi)= -\ln(1 - p_i)=−ln(1−pi​). As prediction pi→0p_i \rightarrow 0pi​→0, Loss →0\rightarrow 0→0. As pi→1p_i \rightarrow 1pi​→1, Loss →∞\rightarrow \infty→∞ (heavily penalizes False Positives).

2.2 Gradient Descent Minimization Mechanics (3 marks)​

Gradient Descent is an iterative numerical optimization algorithm used to find the global minimum of a convex cost function J(w,b)\mathcal{J}(\mathbf{w}, b)J(w,b).

The Physical Intuition:​

Imagine being at the top of a mountain basin in thick fog. To find the bottom of the basin, you can feel the slope of the ground beneath your feet and take a step in the direction of the steepest descent (downward).

In mathematical terms:

  1. The gradient vector ∇wJ\nabla_{\mathbf{w}} \mathcal{J}∇w​J points in the direction of steepest ascent.
  2. Therefore, to minimize the loss, we must move in the opposite direction—the negative gradient (−∇wJ-\nabla_{\mathbf{w}} \mathcal{J}−∇w​J).

Iterative Update Equations:​

At each iteration ttt, we update the weights and bias parameters:

w(t+1)=w(t)−η∇wJ(w,b)\boxed{\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \nabla_{\mathbf{w}} \mathcal{J}(\mathbf{w}, b)}w(t+1)=w(t)−η∇w​J(w,b)​

b(t+1)=b(t)−η∂J∂b\boxed{b^{(t+1)} = b^{(t)} - \eta \frac{\partial \mathcal{J}}{\partial b}}b(t+1)=b(t)−η∂b∂J​​

Where η>0\eta > 0η>0 is the learning rate (step size).

  • If η\etaη is too small, convergence is extremely slow.
  • If η\etaη is too large, the algorithm can overshoot the minimum and diverge.

2.3 Step-by-Step Calculus Derivation of Gradients (5 marks)​

To implement the update rules, we derive the partial derivatives of the Cost Function J\mathcal{J}J with respect to the parameters. We use the chain rule for a single observation iii:

∂Ji∂wj=∂Ji∂pi⋅∂pi∂zi⋅∂zi∂wj\frac{\partial \mathcal{J}_i}{\partial w_j} = \frac{\partial \mathcal{J}_i}{\partial p_i} \cdot \frac{\partial p_i}{\partial z_i} \cdot \frac{\partial z_i}{\partial w_j}∂wj​∂Ji​​=∂pi​∂Ji​​⋅∂zi​∂pi​​⋅∂wj​∂zi​​

Where:

  • Ji=−[yiln⁡(pi)+(1−yi)ln⁡(1−pi)]\mathcal{J}_i = - \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]Ji​=−[yi​ln(pi​)+(1−yi​)ln(1−pi​)]
  • pi=σ(zi)=11+e−zip_i = \sigma(z_i) = \frac{1}{1 + e^{-z_i}}pi​=σ(zi​)=1+e−zi​1​
  • zi=wTxi+bz_i = \mathbf{w}^T \mathbf{x}_i + bzi​=wTxi​+b

Step 1: Compute ∂Ji∂pi\frac{\partial \mathcal{J}_i}{\partial p_i}∂pi​∂Ji​​ (Derivative of Loss w.r.t. Probability)​

∂Ji∂pi=−ddpi[yiln⁡(pi)+(1−yi)ln⁡(1−pi)]\frac{\partial \mathcal{J}_i}{\partial p_i} = -\frac{d}{dp_i} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]∂pi​∂Ji​​=−dpi​d​[yi​ln(pi​)+(1−yi​)ln(1−pi​)]

∂Ji∂pi=−[yipi−1−yi1−pi]=−yi(1−pi)+pi(1−yi)pi(1−pi)\frac{\partial \mathcal{J}_i}{\partial p_i} = - \left[ \frac{y_i}{p_i} - \frac{1 - y_i}{1 - p_i} \right] = \frac{-y_i(1 - p_i) + p_i(1 - y_i)}{p_i(1 - p_i)}∂pi​∂Ji​​=−[pi​yi​​−1−pi​1−yi​​]=pi​(1−pi​)−yi​(1−pi​)+pi​(1−yi​)​

∂Ji∂pi=−yi+yipi+pi−yipipi(1−pi)=pi−yipi(1−pi)\frac{\partial \mathcal{J}_i}{\partial p_i} = \frac{-y_i + y_i p_i + p_i - y_i p_i}{p_i(1 - p_i)} = \mathbf{\frac{p_i - y_i}{p_i(1 - p_i)}}∂pi​∂Ji​​=pi​(1−pi​)−yi​+yi​pi​+pi​−yi​pi​​=pi​(1−pi​)pi​−yi​​

Step 2: Compute ∂pi∂zi\frac{\partial p_i}{\partial z_i}∂zi​∂pi​​ (Derivative of Sigmoid w.r.t. Logit)​

As proved previously (derivative of sigmoid): ∂pi∂zi=σ(zi)(1−σ(zi))=pi(1−pi)\frac{\partial p_i}{\partial z_i} = \sigma(z_i)(1 - \sigma(z_i)) = \mathbf{p_i(1 - p_i)}∂zi​∂pi​​=σ(zi​)(1−σ(zi​))=pi​(1−pi​)

Step 3: Compute ∂zi∂wj\frac{\partial z_i}{\partial w_j}∂wj​∂zi​​ and ∂zi∂b\frac{\partial z_i}{\partial b}∂b∂zi​​ (Derivative of Logit w.r.t. Parameters)​

Since zi=w1xi,1+w2xi,2+⋯+wjxi,j+bz_i = w_1 x_{i,1} + w_2 x_{i,2} + \dots + w_j x_{i,j} + bzi​=w1​xi,1​+w2​xi,2​+⋯+wj​xi,j​+b: ∂zi∂wj=xi,j\frac{\partial z_i}{\partial w_j} = \mathbf{x_{i,j}}∂wj​∂zi​​=xi,j​

∂zi∂b=1\frac{\partial z_i}{\partial b} = \mathbf{1}∂b∂zi​​=1

Step 4: Combine Derivatives via Chain Rule​

Multiply the partial derivatives together: ∂Ji∂wj=[pi−yipi(1−pi)]⋅[pi(1−pi)]⋅xi,j\frac{\partial \mathcal{J}_i}{\partial w_j} = \left[ \frac{p_i - y_i}{p_i(1 - p_i)} \right] \cdot \left[ p_i(1 - p_i) \right] \cdot x_{i,j}∂wj​∂Ji​​=[pi​(1−pi​)pi​−yi​​]⋅[pi​(1−pi​)]⋅xi,j​

The intermediate pi(1−pi)p_i(1 - p_i)pi​(1−pi​) terms cancel out perfectly: ∂Ji∂wj=(pi−yi)xi,j\frac{\partial \mathcal{J}_i}{\partial w_j} = \mathbf{(p_i - y_i) x_{i,j}}∂wj​∂Ji​​=(pi​−yi​)xi,j​

Similarly, for the bias bbb: ∂Ji∂b=[pi−yipi(1−pi)]⋅[pi(1−pi)]⋅1=(pi−yi)\frac{\partial \mathcal{J}_i}{\partial b} = \left[ \frac{p_i - y_i}{p_i(1 - p_i)} \right] \cdot \left[ p_i(1 - p_i) \right] \cdot 1 = \mathbf{(p_i - y_i)}∂b∂Ji​​=[pi​(1−pi​)pi​−yi​​]⋅[pi​(1−pi​)]⋅1=(pi​−yi​)

Step 5: Average Over All NNN Samples​

Averaging the partial gradients across the entire dataset yields the final gradient equations for the optimization step:

∂J∂wj=1N∑i=1N(pi−yi)xi,j\boxed{\frac{\partial \mathcal{J}}{\partial w_j} = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i) x_{i,j}}∂wj​∂J​=N1​i=1∑N​(pi​−yi​)xi,j​​

∂J∂b=1N∑i=1N(pi−yi)\boxed{\frac{\partial \mathcal{J}}{\partial b} = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i)}∂b∂J​=N1​i=1∑N​(pi​−yi​)​

  • Inference & Significance: These mathematically elegant gradients represent the prediction error (pi−yip_i - y_ipi​−yi​) scaled by the feature value xi,jx_{i,j}xi,j​. This means that if a prediction has zero error (pi=yip_i = y_ipi​=yi​), the gradient becomes zero, and no updates are made. If the error is large, the parameter updates are proportional to the magnitude of that error.

KEY TAKEAWAYS (Quick Review)​

Logistic Regression:

  1. Fits a Sigmoid curve: P(y=1∣x)=11+e−zP(y=1 \mid \mathbf{x}) = \frac{1}{1 + e^{-z}}P(y=1∣x)=1+e−z1​.
  2. Probability boundary of τ=0.5\tau = 0.5τ=0.5 corresponds exactly to z=0z = 0z=0.
  3. Models log-odds linearly: ln⁡(odds)=wTx+b\ln(\text{odds}) = \mathbf{w}^T\mathbf{x} + bln(odds)=wTx+b.

Loss Functions & Optimization:

  1. MSE cannot be used because Sigmoid makes it non-convex.
  2. Log-Loss is convex and derived from Maximum Likelihood Estimation (MLE).
  3. Gradient Descent iteratively minimizes loss by taking steps proportional to the negative gradient.
  4. Updates scale directly with the model's prediction errors (pi−yip_i - y_ipi​−yi​).
