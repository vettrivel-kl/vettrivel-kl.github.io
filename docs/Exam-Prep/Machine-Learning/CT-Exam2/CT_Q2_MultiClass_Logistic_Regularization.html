(i) Handling More Than Two Classes Using Logistic Regression (10 Marks)​

Standard binary Logistic Regression is fundamentally designed for two-class (binary) classification. To extend it to handle multi-class classification (where the number of classes C>2C > 2C>2), three primary strategies are utilized in machine learning: One-vs-Rest (OvR), One-vs-One (OvO), and Multinomial Logistic Regression (Softmax Regression).

Strategy 1: One-vs-Rest (OvR) / One-vs-All (OvA)​

  • Mechanism: If there are CCC unique classes, we train CCC separate, independent binary logistic regression classifiers. For each classifier i∈{1,2,…,C}i \in \{1, 2, \dots, C\}i∈{1,2,…,C}:
    • Class iii is treated as the positive class (target label = 1).
    • All other C−1C-1C−1 classes are grouped together and treated as the negative class (target label = 0).
  • Mathematical Probability: Each classifier iii computes the probability of class iii versus all other classes combined using the standard Sigmoid function: P(y=i∣x)=σ(wiTx+bi)=11+e−(wiTx+bi)P(y = i \mid \mathbf{x}) = \sigma(\mathbf{w}_i^T \mathbf{x} + b_i) = \frac{1}{1 + e^{-(\mathbf{w}_i^T \mathbf{x} + b_i)}}P(y=i∣x)=σ(wiT​x+bi​)=1+e−(wiT​x+bi​)1​
  • Prediction (Inference): To classify a new unseen instance x\mathbf{x}x, it is evaluated by all CCC classifiers. The final predicted class y^\hat{y}y^​ is the one that achieves the highest confidence score: y^=arg⁡max⁡i∈{1,…,C}P(y=i∣x)\hat{y} = \arg\max_{i \in \{1, \dots, C\}} P(y = i \mid \mathbf{x})y^​=argmaxi∈{1,…,C}​P(y=i∣x)
Step-by-Step Example (OvR):​

Imagine predicting a customer's preferred subscription plan from three classes (C=3C = 3C=3): Basic, Standard, and Premium.

  1. Train Classifiers:
    • Classifier 1 (Basic Classifier): Basic (1) vs. [Standard, Premium] (0) →\rightarrow→ Outputs P(y=Basic∣x)P(y = \text{Basic} \mid \mathbf{x})P(y=Basic∣x).
    • Classifier 2 (Standard Classifier): Standard (1) vs. [Basic, Premium] (0) →\rightarrow→ Outputs P(y=Standard∣x)P(y = \text{Standard} \mid \mathbf{x})P(y=Standard∣x).
    • Classifier 3 (Premium Classifier): Premium (1) vs. [Basic, Standard] (0) →\rightarrow→ Outputs P(y=Premium∣x)P(y = \text{Premium} \mid \mathbf{x})P(y=Premium∣x).
  2. Inference: A new customer has features x\mathbf{x}x.
    • Classifier 1 outputs: P(y=Basic∣x)=0.15P(y = \text{Basic} \mid \mathbf{x}) = 0.15P(y=Basic∣x)=0.15
    • Classifier 2 outputs: P(y=Standard∣x)=0.65P(y = \text{Standard} \mid \mathbf{x}) = 0.65P(y=Standard∣x)=0.65

  • Limitations:
    1. Class Imbalance: During training, the negative class (all other classes combined) easily dominates the positive class, introducing bias into individual classifiers.
    2. Probability Unnormalization: The computed probabilities do not naturally sum to 1 (∑P(y=i∣x)=0.15+0.65+0.20=1.00\sum P(y=i \mid \mathbf{x}) = 0.15 + 0.65 + 0.20 = 1.00∑P(y=i∣x)=0.15+0.65+0.20=1.00 here by chance; normally they don't, e.g., they could sum to 1.3 or 0.8), because they are predicted by independent models.

Strategy 2: One-vs-One (OvO)​

  • Mechanism: Instead of training one classifier per class, OvO trains a binary classifier for every possible pair of classes.
  • Number of Classifiers: For CCC classes, the total number of binary classifiers trained is given by the combination formula: Nclassifiers=C(C−1)2N_{\text{classifiers}} = \frac{C(C-1)}{2}Nclassifiers​=2C(C−1)​
  • Inference Voting Scheme: When a new instance x\mathbf{x}x is evaluated, it is passed through all C(C−1)2\frac{C(C-1)}{2}2C(C−1)​ classifiers. Each classifier votes for one of its two target classes. The class with the most "wins" (votes) across all pairwise comparisons is predicted as the final label.
Step-by-Step Example (OvO):​

Using the same subscription plan classes (C=3C = 3C=3):

  1. Train Classifiers: We train 3(2)2=3\frac{3(2)}{2} = 323(2)​=3 independent binary classifiers:
    • Classifier 1: Basic vs. Standard
    • Classifier 2: Basic vs. Premium
    • Classifier 3: Standard vs. Premium
  2. Inference voting: A new customer x\mathbf{x}x is evaluated:
    • Classifier 1 predicts: Standard (Basic: 0, Standard: 1, Premium: 0)
    • Classifier 2 predicts: Basic (Basic: 1, Standard: 1, Premium: 0)
    • Classifier 3 predicts: Standard (Basic: 1, Standard: 2, Premium: 0)
  3. Decision: Standard has 222 votes, Basic has 111 vote, and Premium has 000 votes. The model predicts the Standard plan.
  • Trade-offs:
    • Pro: Mitigates the class imbalance issues of OvR because each classifier is only trained on a pairwise subset of the dataset.
    • Con: The number of classifiers grows quadratically (O(C2)O(C^2)O(C2)), making it computationally expensive for datasets with many classes.

(ii) What is Logistic Regression & Sigmoid Curve Derivation (5 Marks)​

1. What is Logistic Regression?​

Logistic Regression is a supervised learning classification algorithm used to predict the probability of a discrete target variable. It models the probability P(y=1∣x)P(y=1 \mid \mathbf{x})P(y=1∣x) that a given input x\mathbf{x}x belongs to a positive class. Although it contains "Regression" in its name, it is fundamentally a classifier that places a decision boundary (e.g., P≥0.5P \ge 0.5P≥0.5) on top of continuous probability estimates.

Statistically, it is a Generalized Linear Model (GLM) where the target variable is assumed to follow a Bernoulli distribution, and the link function is the logit function which maps the linear prediction to probability.

2. Converting the Line Equation into a Sigmoid Curve​

To fit a binary classification problem, we must map an unbounded linear regression equation output to a bounded probability domain. This is achieved mathematically using the log-odds (logit) transformation.

DOMAIN MAPPING FLOW:
[Probability Space]        --->       [Odds Space]        --->       [Log-Odds Space]
    P ∈ (0, 1)                         Odds ∈ (0, ∞)                   ln(Odds) ∈ (-∞, ∞)
                       P / (1 - P)                     ln(P / (1 - P))
Step-by-Step Mathematical Derivation:​

  1. The Unbounded Linear Line Equation: A standard linear regression model predicts a continuous, unbounded output zzz: z=wTx+bz = \mathbf{w}^T \mathbf{x} + bz=wTx+b Since z∈(−∞,+∞)z \in (-\infty, +\infty)z∈(−∞,+∞), it cannot represent a probability P∈[0,1]P \in [0, 1]P∈[0,1].

  2. Introducing the Odds Ratio: To restrict the lower bound to 0, we calculate the odds of an event occurring (probability of success divided by probability of failure): Odds=P1−POdds = \frac{P}{1 - P}Odds=1−PP​ Since P∈[0,1]P \in [0, 1]P∈[0,1], the Odds∈[0,+∞)Odds \in [0, +\infty)Odds∈[0,+∞).

  3. Introducing Log-Odds (Logit): To map the odds from [0,+∞)[0, +\infty)[0,+∞) to the entire real line (−∞,+∞)(-\infty, +\infty)(−∞,+∞) to match the range of our linear output zzz, we take the natural logarithm of the odds: ln⁡(Odds)=ln⁡(P1−P)\ln(Odds) = \ln\left(\frac{P}{1 - P}\right)ln(Odds)=ln(1−PP​) We now set this log-odds equal to our linear equation zzz: ln⁡(P1−P)=wTx+b\ln\left(\frac{P}{1 - P}\right) = \mathbf{w}^T \mathbf{x} + bln(1−PP​)=wTx+b

  4. Solving for Probability PPP (The Algebraic Conversion):

    • Step 4a: Exponentiate both sides to remove the logarithm: P1−P=ewTx+b\frac{P}{1 - P} = e^{\mathbf{w}^T \mathbf{x} + b}1−PP​=ewTx+b
    • Step 4b: Multiply by (1−P)(1 - P)(1−P) to clear the denominator: P=(1−P)ewTx+bP = (1 - P) e^{\mathbf{w}^T \mathbf{x} + b}P=(1−P)ewTx+b
    • Step 4c: Expand the right side: P=ewTx+b−PewTx+bP = e^{\mathbf{w}^T \mathbf{x} + b} - P e^{\mathbf{w}^T \mathbf{x} + b}P=ewTx+b−PewTx+b
    • Step 4d: Group PPP terms on the left side: P+PewTx+b=ewTx+bP + P e^{\mathbf{w}^T \mathbf{x} + b} = e^{\mathbf{w}^T \mathbf{x} + b}P+PewTx+b=ewTx+b
    • Step 4e: Factor out PPP on the left side: P(1+ewTx+b)=ewTx+bP \left(1 + e^{\mathbf{w}^T \mathbf{x} + b}\right) = e^{\mathbf{w}^T \mathbf{x} + b}P(1+ewTx+b)=ewTx+b
    • Step 4f: Isolate PPP: P=ewTx+b1+ewTx+bP = \frac{e^{\mathbf{w}^T \mathbf{x} + b}}{1 + e^{\mathbf{w}^T \mathbf{x} + b}}P=1+ewTx+bewTx+b​
    • Step 4g: Divide the numerator and denominator by ewTx+be^{\mathbf{w}^T \mathbf{x} + b}ewTx+b (which is equivalent to multiplying by e−(wTx+b)e^{-(\mathbf{w}^T \mathbf{x} + b)}e−(wTx+b)): P=ewTx+bewTx+b1ewTx+b+ewTx+bewTx+bP = \frac{\frac{e^{\mathbf{w}^T \mathbf{x} + b}}{e^{\mathbf{w}^T \mathbf{x} + b}}}{\frac{1}{e^{\mathbf{w}^T \mathbf{x} + b}} + \frac{e^{\mathbf{w}^T \mathbf{x} + b}}{e^{\mathbf{w}^T \mathbf{x} + b}}}P=ewTx+b1​+ewTx+bewTx+b​ewTx+bewTx+b​​ P=1e−(wTx+b)+1P = \frac{1}{e^{-(\mathbf{w}^T \mathbf{x} + b)} + 1}P=e−(wTx+b)+11​ P=11+e−(wTx+b)P = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}P=1+e−(wTx+b)1​

  5. The Sigmoid Function: Replacing wTx+b\mathbf{w}^T \mathbf{x} + bwTx+b back with zzz yields the standard Sigmoid (Logistic) function: σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​ This function compresses any real-valued continuous input zzz into an S-shaped curve strictly bounded between [0,1][0, 1][0,1], allowing the output to be interpreted directly as a probability.

(iii) What is Regularization & Its Types (5 Marks)​

1. What is Regularization?​

Regularization is a set of techniques used to prevent overfitting in machine learning models by adding a penalty term to the cost/loss function. Overfitting occurs when a model fits the training noise too closely, resulting in extremely large parameter weights (w\mathbf{w}w) and poor generalization on unseen test data. Regularization constrains or shrinks the model weights toward zero, simplifying the model's decision boundaries and ensuring better generalizability.

Mathematically, it balances the tradeoff between minimizing empirical training loss and minimizing model complexity: LossRegularized(w)=Lossoriginal(w)+λ⋅Ω(w)Loss_{Regularized}(\mathbf{w}) = Loss_{original}(\mathbf{w}) + \lambda \cdot \Omega(\mathbf{w})LossRegularized​(w)=Lossoriginal​(w)+λ⋅Ω(w) Where Ω(w)\Omega(\mathbf{w})Ω(w) is the complexity penalty and λ≥0\lambda \ge 0λ≥0 is the regularization strength hyperparameter.

2. Types of Regularization​

Type 1: L1 Regularization (Lasso - Least Absolute Shrinkage and Selection Operator)​
  • Mechanism: Adds a penalty proportional to the sum of the absolute values of the coefficients to the original loss function.
  • Primal Formulation Under Constraint: min⁡wLossoriginalsubject to∑i=1n∣wi∣≤t\min_{\mathbf{w}} Loss_{original} \quad \text{subject to} \quad \sum_{i=1}^{n} |w_i| \le tminw​Lossoriginal​subject to∑i=1n​∣wi​∣≤t
  • Mathematical Formula (Regularized Loss): LossL1=Lossoriginal+λ∑i=1n∣wi∣Loss_{L1} = Loss_{original} + \lambda \sum_{i=1}^{n} |w_i|LossL1​=Lossoriginal​+λ∑i=1n​∣wi​∣
  • Why L1 Causes Sparsity (Geometric Intuition): In two dimensions (w1,w2w_1, w_2w1​,w2​), the L1 constraint region ∑∣wi∣≤t\sum |w_i| \le t∑∣wi​∣≤t forms a diamond shape with sharp corners (vertices) on the axes. The contours of the original loss function expand outward from their unconstrained minimum. Because of the diamond's sharp corners, the loss function's contours are highly likely to first touch the constraint region at one of the corners on an axis (where one of the coefficients is exactly zero). This forces less important features to be completely eliminated.
  • Optimization Challenge: Because the L1 penalty ∣wi∣|w_i|∣wi​∣ is non-differentiable at wi=0w_i = 0wi​=0, standard gradient descent cannot be directly applied. Advanced numerical optimization methods like Coordinate Descent or Proximal Gradient Descent are used instead to optimize Lasso objectives.
Type 2: L2 Regularization (Ridge Regression / Weight Decay)​
  • Mechanism: Adds a penalty proportional to the sum of the squared values of the coefficients to the original loss function.
  • Primal Formulation Under Constraint: min⁡wLossoriginalsubject to∑i=1nwi2≤t\min_{\mathbf{w}} Loss_{original} \quad \text{subject to} \quad \sum_{i=1}^{n} w_i^2 \le tminw​Lossoriginal​subject to∑i=1n​wi2​≤t
  • Mathematical Formula (Regularized Loss): LossL2=Lossoriginal+λ∑i=1nwi2Loss_{L2} = Loss_{original} + \lambda \sum_{i=1}^{n} w_i^2LossL2​=Lossoriginal​+λ∑i=1n​wi2​
  • Why L2 is called "Weight Decay" (Gradient Descent Update Proof): Let's derive the gradient descent update for the regularized loss function (assuming 12\frac{1}{2}21​ scaling factor on the penalty for mathematical convenience): Loss(w)=Lossoriginal(w)+λ12∑i=1nwi2Loss(\mathbf{w}) = Loss_{\text{original}}(\mathbf{w}) + \lambda \frac{1}{2} \sum_{i=1}^n w_i^2Loss(w)=Lossoriginal​(w)+λ21​∑i=1n​wi2​ Taking the gradient with respect to parameter weight vector w\mathbf{w}w: ∇wLoss(w)=∇wLossoriginal(w)+λw\nabla_{\mathbf{w}} Loss(\mathbf{w}) = \nabla_{\mathbf{w}} Loss_{\text{original}}(\mathbf{w}) + \lambda \mathbf{w}∇w​Loss(w)=∇w​Lossoriginal​(w)+λw The gradient descent update step is: w(t+1)=w(t)−η∇wLoss(w(t))\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \nabla_{\mathbf{w}} Loss(\mathbf{w}^{(t)})w(t+1)=w(t)−η∇w​Loss(w(t)) Substituting our regularized gradient: w(t+1)=w(t)−η(∇wLossoriginal(w(t))+λw(t))\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \left( \nabla_{\mathbf{w}} Loss_{\text{original}}(\mathbf{w}^{(t)}) + \lambda \mathbf{w}^{(t)} \right)w(t+1)=w(t)−η(∇w​Lossoriginal​(w(t))+λw(t)) w(t+1)=w(t)−ηλw(t)−η∇wLossoriginal(w(t))\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \lambda \mathbf{w}^{(t)} - \eta \nabla_{\mathbf{w}} Loss_{\text{original}}(\mathbf{w}^{(t)})w(t+1)=w(t)−ηλw(t)−η∇w​Lossoriginal​(w(t)) w(t+1)=1−ηλw(t)−η∇wLossoriginal(w(t))\mathbf{w}^{(t+1)} = \mathbf{1 - \eta \lambda}\mathbf{w}^{(t)} - \eta \nabla_{\mathbf{w}} Loss_{\text{original}}(\mathbf{w}^{(t)})w(t+1)=1−ηλw(t)−η∇w​Lossoriginal​(w(t)) Since η>0\eta > 0η>0 (learning rate) and λ>0\lambda > 0λ>0, the term (1−ηλ)(1 - \eta\lambda)(1−ηλ) is strictly less than 1. At every step of gradient descent, the weights are first scaled down (decayed) by this factor before the standard training loss gradient is subtracted. This keeps the model weights highly stable and bounded.
Type 3: Elastic Net Regularization​
  • Mechanism: A hybrid approach that linearly combines both L1 (Lasso) and L2 (Ridge) penalties in the loss function.
  • Mathematical Formula (Regularized Loss): LossElasticNet=Lossoriginal+λ[α∑i=1n∣wi∣+(1−α)∑i=1nwi2]Loss_{ElasticNet} = Loss_{original} + \lambda \left[ \alpha \sum_{i=1}^{n} |w_i| + (1 - \alpha) \sum_{i=1}^{n} w_i^2 \right]LossElasticNet​=Lossoriginal​+λ[α∑i=1n​∣wi​∣+(1−α)∑i=1n​wi2​] Where α∈[0,1]\alpha \in [0, 1]α∈[0,1] is the mixing ratio.
  • Business Impact: Highly recommended when the number of features (nnn) is much larger than the number of training samples (NNN), or when there are multiple groups of strongly correlated variables. It selects groups of correlated features together (grouping effect) while still enforcing sparse selection.

Summary Checklist for Exam Preparation​

  • Multiclass:
    • OvR: Train CCC models. Simple, but suffers from imbalance and unnormalized probabilities.
    • OvO: Train C(C−1)2\frac{C(C-1)}{2}2C(C−1)​ models. Pairwise comparisons; voting-scheme prediction. High computational complexity (O(C2)O(C^2)O(C2)).
    • Softmax: Single model optimizing Cross-Entropy loss directly over a normalized probability distribution.
  • Sigmoid Conversion:
    • Memorize the sequence: Linear Line Equation →\rightarrow→ Odds Ratio →\rightarrow→ Logit →\rightarrow→ Algebraic Rearrangement (isolate PPP) →\rightarrow→ Negative Exponent Division →\rightarrow→ Sigmoid Function.
    • Be ready to prove the derivative relation: σ′(z)=σ(z)(1−σ(z))\sigma'(z) = \sigma(z)(1 - \sigma(z))σ′(z)=σ(z)(1−σ(z)).
  • Regularization Intuition:
    • L1: Diamond boundary, touches at corners, forces coefficients to 000 (Automatic Feature Selection). Non-differentiable at 0 (requires Coordinate Descent).
    • L2: Circular boundary, touches smoothly, shrinks coefficients to near-000 but never exactly 000 (Handles Multicollinearity). Mathematically derived as Weight Decay in gradient descent updates.
    • Elastic Net: Hybrid boundary, handles correlation groups and sparsity concurrently.
