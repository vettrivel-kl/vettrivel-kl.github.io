Question 1 (20 Marks)​

info

Question Statement

A FinTech startup wants to build a system to detect fraudulent transactions in real-time. They have a massive dataset of past transactions, with some of them already labeled as 'fraudulent' or 'legitimate'. They are also considering incorporating new, unlabeled transaction data to discover new fraud patterns.

  • i) Explain the primary challenge of using a pure supervised learning approach for this task, especially when new, unknown fraud types emerge. (10 Marks)
  • ii) Propose a hybrid machine learning strategy that combines both supervised and unsupervised learning techniques to address this challenge. Justify your choice of approach by explaining how it overcomes the limitations of using a single learning paradigm. (10 Marks)

Solution 1 (20 Marks)​

(i) Primary Challenges of Pure Supervised Learning (10 Marks)​

A pure supervised model learns a decision boundary mapping transaction features x∈Rd\mathbf{x} \in \mathbb{R}^dx∈Rd to historical class labels y∈{0,1}y \in \{0, 1\}y∈{0,1} by approximating the posterior P(Y∣x)P(Y \mid \mathbf{x})P(Y∣x). While highly effective for known, stationary fraud topologies, this paradigm faces fundamental structural failures in a dynamic financial environment:

1. Violation of the Closed-World Assumption (Zero-Day Invisibility)​
  • Supervised models operate under the closed-world hypothesis: test data distributions are assumed to follow the support of the training distribution (x∼Ptrain(X)\mathbf{x} \sim P_{\text{train}}(\mathbf{X})x∼Ptrain​(X)).
  • Emerging fraud schemes (e.g., automated credential stuffing bots, synthetic identities, novel micro-deposit exploits) exhibit feature patterns never seen during model training.
  • Because the supervised model has only seen historical legitimate points in that new region of space, it assigns a high posterior probability of legitimacy (P(Y=0∣xnovel)→1P(Y=0 \mid \mathbf{x}_{\text{novel}}) \to 1P(Y=0∣xnovel​)→1), resulting in catastrophic False Negatives.
2. Concept Drift & Adversarial Distribution Shifts​
  • Fraud detection is inherently adversarial. Attackers continuously alter behavior to bypass production classification thresholds:
    • Covariate Shift: Ptrain(X)≠Ptest(X)P_{\text{train}}(\mathbf{X}) \neq P_{\text{test}}(\mathbf{X})Ptrain​(X)=Ptest​(X) (spending behaviors shift due to external trends).
    • Concept Drift: Ptrain(Y∣X)≠Ptest(Y∣X)P_{\text{train}}(Y \mid \mathbf{X}) \neq P_{\text{test}}(Y \mid \mathbf{X})Ptrain​(Y∣X)=Ptest​(Y∣X) (a previously benign transaction signature is repurposed for exploitation).
  • Pure supervised classifiers cannot detect drift autonomously; they require verified labels from the shifted distribution to update their loss surfaces.
3. Severe Label Latency Window​
  • Ground-truth fraud labels are subject to substantial latency due to banking dispute processes and 30 to 90-day chargeback cycles.
  • During this latency window, a pure supervised model remains static and blind, allowing new fraud campaigns to scale undetected before ground-truth labels can be incorporated into retraining.
4. Extreme Class Imbalance & Majority Loss Domination​
  • Fraud typically accounts for less than 0.1% of transactions (P(Y=1)<0.001P(Y=1) < 0.001P(Y=1)<0.001). Under empirical risk minimization, the loss function is dominated by the legitimate majority class, suppressing sensitivity to subtle fraud boundaries unless aggressive sampling is applied.

(ii) Proposed Hybrid Machine Learning Strategy (10 Marks)​

To bridge the gap between real-time millisecond execution and zero-day anomaly detection, we propose a Two-Stage Hybrid Learning Pipeline integrating Unsupervised Outlier Scoring, Supervised Gradient Boosted Classifiers, and Active Learning.

Pipeline Components​
1. Stage 1: Unsupervised Representation & Anomaly Scoring (Novel Pattern Discovery)​
  • Deep Semi-Supervised Autoencoder: An autoencoder is trained on high-volume, unflagged transactions to learn the compact manifold of normal behavior: min⁡θ,ϕ1n∑i=1n∥xi−gϕ(fθ(xi))∥22\min_{\theta, \phi} \frac{1}{n}\sum_{i=1}^{n} \|\mathbf{x}_i - g_\phi(f_\theta(\mathbf{x}_i))\|_2^2θ,ϕmin​n1​i=1∑n​∥xi​−gϕ​(fθ​(xi​))∥22​
  • Anomaly Reconstruction Score: When an unseen fraud pattern xnovel\mathbf{x}_{\text{novel}}xnovel​ arrives, its reconstruction error serves as a continuous anomaly score: sanom(x)=∥x−gϕ(fθ(x))∥2s_{\text{anom}}(\mathbf{x}) = \|\mathbf{x} - g_\phi(f_\theta(\mathbf{x}))\|_2sanom​(x)=∥x−gϕ​(fθ​(x))∥2​ Because novel fraud schemes deviate from normal transactions, they produce high reconstruction errors without requiring historical labels.
2. Stage 2: Supervised Real-Time Classification (High Precision on Known Patterns)​
  • Feature Augmentation: The supervised model (e.g., LightGBM) takes original transaction features x\mathbf{x}x augmented with the unsupervised latent embedding and anomaly score: xaugmented=[x ∥ sanom(x) ∥ zlatent]\mathbf{x}_{\text{augmented}} = \left[\mathbf{x} \,\|\, s_{\text{anom}}(\mathbf{x}) \,\|\, \mathbf{z}_{\text{latent}}\right]xaugmented​=[x∥sanom​(x)∥zlatent​]
  • Latency SLA: LightGBM evaluates the augmented feature vector in sub-10 milliseconds, satisfying real-time production requirements.
3. Stage 3: Active Learning & Semi-Supervised Triage​
  • Transactions exhibiting high unsupervised anomaly scores (sanom>θanoms_{\text{anom}} > \theta_{\text{anom}}sanom​>θanom​) but uncertain supervised probabilities (0.3<P(Y=1)<0.70.3 < P(Y=1) < 0.70.3<P(Y=1)<0.7) are sent to an analyst review queue.
  • Analyst verifications generate ground truth for emerging patterns, updating the supervised dataset via Active Learning: x∗=arg⁡max⁡x∈DunlabeledH(P(Y∣x))×sanom(x)\mathbf{x}^* = \arg\max_{\mathbf{x} \in \mathcal{D}_{\text{unlabeled}}} \mathcal{H}(P(Y \mid \mathbf{x})) \times s_{\text{anom}}(\mathbf{x})x∗=argx∈Dunlabeled​max​H(P(Y∣x))×sanom​(x)

Question 3 (20 Marks)​

info

Question Statement

A marketing team has collected a dataset of customer feedback on a new product. The feedback is highly varied and includes both structured data and unstructured, highly subjective text. The relationship between the input variables and customer satisfaction seems to be non-linear and complex. The team leader suggests using a simple linear regression model to predict satisfaction.

  • i) Justify why a non-parametric model, such as a Support Vector Machine (SVM) or Naïve Bayes Classifier, might be a better choice than a linear model for this scenario. (10 Marks)
  • ii) Explain how your chosen non-parametric model handles the non-linear and complex nature of the data. (10 Marks)

Solution 3 (20 Marks)​

(i) Justification Against Linear Regression and for Non-Parametric Models (10 Marks)​

The team leader's recommendation to use Simple Linear Regression suffers from key structural limitations in this scenario:

Deficiencies of Linear Regression​
  1. Rigid Parametric Form: Linear regression enforces a strict hyperplanar hypothesis space: y=wTx+b+ϵy = \mathbf{w}^T \mathbf{x} + b + \epsilony=wTx+b+ϵ It assumes constant marginal effects (∂y∂xj=wj\frac{\partial y}{\partial x_j} = w_j∂xj​∂y​=wj​), unable to model saturation, thresholds, or non-linear customer satisfaction dynamics.
  2. Failure in High-Dimensional Sparse Text: Vectorizing subjective customer feedback (via TF-IDF or Bag-of-Words) generates thousands of sparse textual features (d≫103d \gg 10^3d≫103). When d>nd > nd>n, the sample covariance matrix XTX\mathbf{X}^T \mathbf{X}XTX is singular and non-invertible, causing Ordinary Least Squares (OLS) estimates to collapse.
  3. Multimodal Incompatibility: The dataset mixes dense structured numerical variables with sparse unstructured sentiment tokens. Linear regression cannot capture cross-modal feature interactions without manual polynomial expansion.

(ii) How Kernel SVM Handles Non-Linear, Complex Data (10 Marks)​

1. Cover's Theorem & High-Dimensional Projections​

Cover's Theorem states that a non-linear pattern classification problem is more likely to be linearly separable when cast into a higher-dimensional space through a non-linear mapping: Φ:Rd→H\Phi: \mathbb{R}^d \to \mathcal{H}Φ:Rd→H

2. The Kernel Trick (Avoiding Explicit Inner Products)​

Directly evaluating Φ(x)\Phi(\mathbf{x})Φ(x) in high dimensions is computationally intractable. In the dual formulation of SVM, the training data enters exclusively via inner products: max⁡α∑i=1nαi−12∑i=1n∑j=1nαiαjyiyj⟨Φ(xi),Φ(xj)⟩\max_{\boldsymbol{\alpha}} \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j \langle \Phi(\mathbf{x}_i), \Phi(\mathbf{x}_j) \ranglemaxα​∑i=1n​αi​−21​∑i=1n​∑j=1n​αi​αj​yi​yj​⟨Φ(xi​),Φ(xj​)⟩ subject to 0≤αi≤C0 \le \alpha_i \le C0≤αi​≤C and ∑i=1nαiyi=0\sum_{i=1}^{n} \alpha_i y_i = 0∑i=1n​αi​yi​=0.

The Kernel Trick replaces the inner product with an equivalent Mercer kernel function evaluated directly in the input space: K(xi,xj)=⟨Φ(xi),Φ(xj)⟩HK(\mathbf{x}_i, \mathbf{x}_j) = \langle \Phi(\mathbf{x}_i), \Phi(\mathbf{x}_j) \rangle_{\mathcal{H}}K(xi​,xj​)=⟨Φ(xi​),Φ(xj​)⟩H​

3. The Radial Basis Function (RBF) Kernel​

For non-linear marketing feedback combining text features and numerical metrics, the Gaussian RBF kernel is optimal: K(xi,xj)=exp⁡(−γ∥xi−xj∥2),γ>0K(\mathbf{x}_i, \mathbf{x}_j) = \exp\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right), \quad \gamma > 0K(xi​,xj​)=exp(−γ∥xi​−xj​∥2),γ>0

Expanding the exponential term via Taylor series shows that the RBF kernel corresponds to an infinite-dimensional polynomial feature space: exp⁡(−γ∥xi−xj∥2)=exp⁡(−γ∥xi∥2)exp⁡(−γ∥xj∥2)∑k=0∞(2γxiTxj)kk!\exp\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right) = \exp(-\gamma \|\mathbf{x}_i\|^2)\exp(-\gamma \|\mathbf{x}_j\|^2) \sum_{k=0}^{\infty} \frac{(2\gamma \mathbf{x}_i^T \mathbf{x}_j)^k}{k!}exp(−γ∥xi​−xj​∥2)=exp(−γ∥xi​∥2)exp(−γ∥xj​∥2)∑k=0∞​k!(2γxiT​xj​)k​ This enables the SVM to model complex feature interactions across text sentiment and purchase metadata without explicitly computing infinite coordinates.

Question 4 (20 Marks)​

info

Question Statement

You have trained a single Decision Tree model to predict housing prices. While the model has a very low error on the training data, its performance on new, unseen data is significantly worse. Your manager is concerned about this and asks for a more robust solution.

  • i) Diagnose the problem with your current single Decision Tree model. (6 Marks)
  • ii) Propose a solution using Ensembling techniques. (6 Marks)
  • iii) Explain in detail how a specific Ensembling method addresses the problem identified in your diagnosis. (8 Marks)

Solution 4 (20 Marks)​

(i) Diagnosis of the Single Decision Tree Model (6 Marks)​

The combination of near-zero training error and poor test performance is a classic manifestation of Overfitting, driven by High Variance and Low Bias in the Bias-Variance Decomposition: ED[(y−f^(x))2]=Bias2(f^(x))+Var(f^(x))+σϵ2\mathbb{E}_{\mathcal{D}}\left[(y - \hat{f}(\mathbf{x}))^2\right] = \text{Bias}^2(\hat{f}(\mathbf{x})) + \text{Var}(\hat{f}(\mathbf{x})) + \sigma_{\epsilon}^2ED​[(y−f^​(x))2]=Bias2(f^​(x))+Var(f^​(x))+σϵ2​

Root Causes​
  1. Unconstrained Tree Depth: Without pruning or depth constraints, the tree recursively splits feature space until leaves contain single instances (Nm=1N_m = 1Nm​=1). Training bias vanishes (Bias2≈0\text{Bias}^2 \approx 0Bias2≈0), but variance explodes (Var≫0\text{Var} \gg 0Var≫0).
  2. High Sensitivity (Instability): CART models use greedy recursive splitting. A minor change in a single training housing record can alter the root or early splits, resulting in an entirely different tree topology.
  3. Step-Function Approximation: Regression trees approximate continuous target variables (housing prices) with piecewise-constant partitions. Fitting smooth price curves requires excessive splits, memorizing localized noise and outliers.

(ii) Proposed Solution: Ensemble Learning (6 Marks)​

To eliminate high variance while preserving the non-linear expressive power of decision trees, we deploy Random Forest Regression (an ensemble of Bootstrap-Aggregated decision trees with feature subspace randomization).

(iii) Detailed Mechanics of Random Forest Regression (8 Marks)​

1. Bootstrap Aggregation (Bagging)​

  • Each sample leaves approximately 36.8%36.8\%36.8% of instances out of training: P(omitted)=(1−1N)N→N→∞e−1≈0.368P(\text{omitted}) = \left(1 - \frac{1}{N}\right)^N \xrightarrow{N \to \infty} e^{-1} \approx 0.368P(omitted)=(1−N1​)NN→∞​e−1≈0.368 These form the Out-Of-Bag (OOB) dataset, providing an internal validation estimate.

Question Statement

You are a data scientist working for a bioinformatics company. Your task is to analyze a gene expression dataset with 5,000 genes (features) and 100 samples (data points). The company wants to identify patterns in the data to potentially discover new disease subtypes. The high number of genes makes it impossible to visualize and difficult for most machine learning algorithms to process efficiently.

  • i) Justify the need for dimensionality reduction in this specific scenario. (6 Marks)
  • ii) Propose a suitable dimensionality reduction technique for this dataset and explain its underlying working principle. (8 Marks)
  • iii) After applying dimensionality reduction, you decide to use K-Means Clustering to identify potential disease subtypes. Explain a key challenge you might face when interpreting the resulting clusters and how you could address it to provide meaningful insights to the biologists. (6 Marks)

Solution 5 (20 Marks)​

(i) Justification for Dimensionality Reduction (p≫np \gg np≫n) (6 Marks)​

In this dataset, features (genes, p=5,000p = 5,000p=5,000) vastly exceed samples (patients, n=100n = 100n=100). This p≫np \gg np≫n regime requires dimensionality reduction due to:

  1. Distance Metric Degeneration (Loss of Contrast): In high-dimensional spaces, pairwise Euclidean distances converge to a uniform scalar: lim⁡p→∞distmax⁡−distmin⁡distmin⁡→0\lim_{p \to \infty} \frac{\text{dist}_{\max} - \text{dist}_{\min}}{\text{dist}_{\min}} \to 0limp→∞​distmin​distmax​−distmin​​→0 Every patient vector becomes equidistant from every other patient in R5000\mathbb{R}^{5000}R5000, rendering distance-based clustering algorithms like K-Means ineffective.
  2. Subspace Rank Deficiency: The empirical data matrix X∈R100×5000\mathbf{X} \in \mathbb{R}^{100 \times 5000}X∈R100×5000 has a maximum possible rank of min⁡(n,p)=100\min(n, p) = 100min(n,p)=100. The data lies entirely within a 99-dimensional subspace; the remaining 4,901 dimensions represent empty space dominated by biological assay noise.
  3. High Multicollinearity: Co-regulated genes share similar expression patterns. Retaining all 5,000 features introduces redundant information that destabilizes distance calculations.
  4. Visual Intractability: Visual inspection of cluster separation requires projecting high-dimensional expression manifolds into 2D/3D representations.

Question Statement

A cybersecurity firm is developing a model to detect network intrusions. The dataset is highly imbalanced, with only 0.5% of the data representing actual intrusions. The initial model, a Logistic Regression classifier, has an accuracy of 99.5% but misses nearly all the intrusion events.

  • i) Evaluate the misleading nature of accuracy as a performance metric for this imbalanced classification problem. (6 Marks)
  • ii) Recommend two alternative metrics that would be more appropriate for this scenario. Justify why each of these metrics is a better choice. (6 Marks)
  • iii) Suggest two strategies to handle the class imbalance in the dataset to improve the model's ability to detect intrusions. (8 Marks)

Solution 6 (20 Marks)​

(i) Misleading Nature of Accuracy (The Accuracy Paradox) (6 Marks)​

The reported 99.5%99.5\%99.5% accuracy is a textbook demonstration of the Accuracy Paradox in severe class imbalance:

1. Mathematical Demonstration of the Null Model​

Let the network dataset contain N=10,000N = 10,000N=10,000 packets:

  • Actual Intrusions (Minority, Y=1Y = 1Y=1): 0.5%  ⟹  N1=500.5\% \implies N_1 = 500.5%⟹N1​=50 packets
  • Benign Traffic (Majority, Y=0Y = 0Y=0): 99.5%  ⟹  N0=9,95099.5\% \implies N_0 = 9,95099.5%⟹N0​=9,950 packets

Consider a trivial Null Predictor that classifies every packet as benign (Y^=0\hat{Y} = 0Y^=0): TP=0,FN=50,FP=0,TN=9,950TP = 0, \quad FN = 50, \quad FP = 0, \quad TN = 9,950TP=0,FN=50,FP=0,TN=9,950

Accuracy=TP+TNN=0+9,95010,000=99.50%\text{Accuracy} = \frac{TP + TN}{N} = \frac{0 + 9,950}{10,000} = \mathbf{99.50\%}Accuracy=NTP+TN​=10,0000+9,950​=99.50% Recall=TPTP+FN=00+50=0.00%\text{Recall} = \frac{TP}{TP + FN} = \frac{0}{0 + 50} = \mathbf{0.00\%}Recall=TP+FNTP​=0+500​=0.00%

The null classifier achieves 99.5%99.5\%99.5% accuracy while missing 100%100\%100% of security intrusions.

2. Cross-Entropy Loss Domination​

Standard Logistic Regression minimizes binary cross-entropy: min⁡w,b−1N[∑i∈Benignlog⁡(1−σ(wTxi+b))+∑j∈Intrusionlog⁡(σ(wTxj+b))]\min_{\mathbf{w}, b} -\frac{1}{N} \left[\sum_{i \in \text{Benign}} \log(1 - \sigma(\mathbf{w}^T \mathbf{x}_i + b)) + \sum_{j \in \text{Intrusion}} \log(\sigma(\mathbf{w}^T \mathbf{x}_j + b))\right]minw,b​−N1​[∑i∈Benign​log(1−σ(wTxi​+b))+∑j∈Intrusion​log(σ(wTxj​+b))] Because benign samples outnumber intrusions 199 to 1, the gradient is dominated by benign terms. The optimizer drives the intercept b→−∞b \to -\inftyb→−∞, pushing predicted probabilities σ(wTx+b)→0\sigma(\mathbf{w}^T \mathbf{x} + b) \to 0σ(wTx+b)→0 for all instances to minimize training loss.

(ii) Two Recommended Alternative Metrics (6 Marks)​

1. Precision-Recall AUC (PR-AUC / Average Precision)​
  • Definition: The area under the Precision-Recall curve across all classification thresholds τ∈[0,1]\tau \in [0, 1]τ∈[0,1]: PR-AUC=∫01Precision(R) dR\text{PR-AUC} = \int_{0}^{1} \text{Precision}(R) \, dRPR-AUC=∫01​Precision(R)dR
  • Justification: ROC-AUC is misleading here because the False Positive Rate denominator (FPR=FPTN+FPFPR = \frac{FP}{TN + FP}FPR=TN+FPFP​) contains TN=9,950TN = 9,950TN=9,950. Hundreds of false alarms produce a small FPRFPRFPR, artificially inflating the ROC-AUC score. PR-AUC focuses exclusively on the positive minority class (TP,FP,FNTP, FP, FNTP,FP,FN), making it sensitive to genuine intrusion detection performance.
2. F2F_2F2​-Score (Recall-Weighted Harmonic Mean)​
  • Definition: F2=(1+22)Precision×Recall22Precision+Recall=5×Precision×Recall4×Precision+RecallF_2 = (1 + 2^2) \frac{\text{Precision} \times \text{Recall}}{2^2 \text{Precision} + \text{Recall}} = 5 \times \frac{\text{Precision} \times \text{Recall}}{4 \times \text{Precision} + \text{Recall}}F2​=(1+22)22Precision+RecallPrecision×Recall​=5×4×Precision+RecallPrecision×Recall​
  • Justification: A missed intrusion (FNFNFN) risks severe security breaches, while a false alarm (FPFPFP) incurs minor analyst review overhead. (iii) Two Strategies to Handle Class Imbalance (8 Marks)​

1. Algorithm-Level Strategy: Cost-Sensitive Learning & Balanced Class Weights​

Modify the cross-entropy loss function to weight errors inversely proportional to class frequencies: LCS(θ)=−∑i=1N[w1yilog⁡(y^i)+w0(1−yi)log⁡(1−y^i)]\mathcal{L}_{\text{CS}}(\theta) = -\sum_{i=1}^{N} \left[ w_1 y_i \log(\hat{y}_i) + w_0 (1 - y_i) \log(1 - \hat{y}_i) \right]LCS​(θ)=−∑i=1N​[w1​yi​log(y^​i​)+w0​(1−yi​)log(1−y^​i​)] Setting balanced weights: w1=N2×N1=10,0002×50=100,w0=10,0002×9,950≈0.5025w_1 = \frac{N}{2 \times N_1} = \frac{10,000}{2 \times 50} = \mathbf{100}, \quad w_0 = \frac{10,000}{2 \times 9,950} \approx \mathbf{0.5025}w1​=2×N1​N​=2×5010,000​=100,w0​=2×9,95010,000​≈0.5025 A single missed intrusion is penalized 200 times more heavily than a false positive, preventing the majority class from dominating gradient updates.

Question 7 (20 Marks)​

info

Question Statement

A manufacturing plant is using a Boosting model to predict equipment failure based on sensor data. The model is highly accurate but is so complex that a human engineer cannot understand how it makes its predictions. The engineers are hesitant to trust a model they cannot interpret, which is crucial for root cause analysis of failures.

  • i) Analyze the trade-off between model complexity and interpretability in this context. (6 Marks)
  • ii) Explain why the boosting model might be difficult to interpret compared to a single Decision Tree. (6 Marks)
  • iii) Propose an alternative approach that could offer a better balance between predictive performance and interpretability, and discuss its potential advantages and disadvantages in this specific scenario. (8 Marks)

Solution 7 (20 Marks)​

(i) Complexity vs. Interpretability Trade-Off Analysis (6 Marks)​

In industrial manufacturing, deploying machine learning requires balancing Predictive Accuracy (Expressive Capacity) against Cognitive Transparency (Interpretability):

Model ParadigmInterpretabilityPredictive AccuracyRoot Cause Analysis (RCA) Utility
White-Box Baselines (Single Tree, Linear Model)High (Transparent rules)Low-to-Moderate (Underfits sensor complexity)High (Immediate physical validation)
Black-Box Ensembles (Gradient Boosting, Deep Nets)Low (Entangled additive splits)High (Captures non-linear failure signals)Low (Blind alert triggers unneeded teardowns)
Glass-Box Ensembles (Explainable Boosting - EBM)High (Additive 2D curves)High (Near-XGBoost performance)High (Direct component attribution)
1. The Cost of Pure Complexity Without Interpretability​
  • Ensemble models (such as XGBoost with 300 trees) capture higher-order sensor interactions (vibration, heat, pressure), yielding high failure detection rates.
  • The Operational Bottleneck: High accuracy without interpretability prevents Root Cause Analysis (RCA). If a model predicts a 94% probability of failure but cannot indicate which component is degrading (e.g., bearing wear vs. coolant blockage), maintenance crews must perform costly system teardowns, negating predictive maintenance benefits.
2. Trust, Safety, and Spurious Correlations​
  • Plant engineers carry operational liability. An uninterpretable model risks exploiting non-causal correlations (e.g., shifts in ambient factory temperature or operator shift times rather than true mechanical stress).
  • Engineers cannot validate model logic against thermodynamic principles, leading them to bypass alerts during critical operations.

(ii) Why Boosting is Difficult to Interpret vs. a Single Decision Tree (6 Marks)​

1. Single Decision Tree: Transparent, Rule-Based Logic​

A single decision tree features high simulative interpretability (can be validated step-by-step by a domain expert):

  • Prediction paths map directly to IF-THEN rules: IF (Bearing Vibration>4.8 mm/s)∧(Lubricant Temp>92∘C)  ⟹  Failure\text{IF } (\text{Bearing Vibration} > 4.8\,\text{mm/s}) \land (\text{Lubricant Temp} > 92^\circ\text{C}) \implies \text{Failure}IF (Bearing Vibration>4.8mm/s)∧(Lubricant Temp>92∘C)⟹Failure
  • The feature space is segmented into visible, axis-aligned orthogonal partitions.
2. Boosting Model: Additive Gradient Entanglement​

Gradient Boosted Decision Trees (GBDT) replace this single rule set with an additive expansion of MMM sequentially dependent weak learners (M∈[100,1000]M \in [100, 1000]M∈[100,1000]): FM(x)=F0(x)+∑m=1Mη hm(x)F_M(\mathbf{x}) = F_0(\mathbf{x}) + \sum_{m=1}^{M} \eta \, h_m(\mathbf{x})FM​(x)=F0​(x)+∑m=1M​ηhm​(x) where each tree hm(x)h_m(\mathbf{x})hm​(x) does not predict the target failure label, but instead fits the pseudo-residuals (negative loss gradients) of preceding trees: rim=−[∂L(yi,F(xi))∂F(xi)]F=Fm−1r_{im} = -\left[\frac{\partial \mathcal{L}(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right]_{F=F_{m-1}}rim​=−[∂F(xi​)∂L(yi​,F(xi​))​]F=Fm−1​​

(iii) Proposed Alternative Approaches & Trade-Offs (8 Marks)​

To reconcile predictive power with interpretability, two primary methodologies are applicable:

Approach 1: Explainable Boosting Machines (EBM / GA2^22M) [Intrinsic Glass-Box]​

EBMs are Generalized Additive Models with Pairwise Interactions: g(E[y])=β0+∑j=1pfj(xj)+∑j≠kfjk(xj,xk)g(\mathbb{E}[y]) = \beta_0 + \sum_{j=1}^{p} f_j(x_j) + \sum_{j \neq k} f_{jk}(x_j, x_k)g(E[y])=β0​+∑j=1p​fj​(xj​)+∑j=k​fjk​(xj​,xk​)

  • Mechanism: Trees are trained on one feature at a time using round-robin cyclic learning, preventing feature entanglement.
  • Interpretability: Each fj(xj)f_j(x_j)fj​(xj​) produces an exact 2D graph showing how changes in that sensor affect failure risk.
Approach 2: TreeSHAP (Shapley Additive Explanations) [Post-Hoc Attribution]​

Keep the existing Boosting model, but compute local feature attribution values via TreeSHAP: f(x)=ϕ0+∑j=1pϕj(x)f(\mathbf{x}) = \phi_0 + \sum_{j=1}^{p} \phi_j(\mathbf{x})f(x)=ϕ0​+∑j=1p​ϕj​(x) where ϕj(x)\phi_j(\mathbf{x})ϕj​(x) represents the exact marginal contribution of sensor jjj to the prediction, satisfying four axiomatic game-theoretic properties: Efficiency, Symmetry, Dummy (Null Effect), and Additivity.
