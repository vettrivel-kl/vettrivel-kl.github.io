(ii) Overfitting and Underfitting in Student Performance Prediction (5 Marks)​

  • Underfitting (High Bias, Low Variance):
    • Definition: The model is too simplistic to capture the true underlying pattern (e.g., fitting a horizontal line or linear line when study returns diminish).
    • Characteristics: High training error and high test error.
    • Impact on Reliability: The model fails to recognize legitimate gains from studying, producing uniform predictions that miss at-risk students.
  • Overfitting (Low Bias, High Variance):
    • Definition: The model is overly complex and memorizes noise/outliers in the training set (e.g., high-degree polynomial fitting a student who fell ill during the exam).
    • Characteristics: Near-zero training error but high test error.
    • Impact on Reliability: Unstable predictions that oscillate wildly on new student cohorts, making the model untrustworthy for academic advising.

  1. Mean Absolute Error (MAE): MAE=1n∑i=1n∣Yi−Y^i∣\text{MAE} = \frac{1}{n} \sum_{i=1}^n \lvert Y_i - \hat{Y}_i \rvertMAE=n1​∑i=1n​∣Yi​−Y^i​∣ Importance: Directly measures average prediction error in original score units (marks). It treats all errors linearly and is robust to outliers.

Question Statement

A retail analytics company is developing a machine learning model to predict customer purchasing behavior. The goal is to classify customers into three spending categories: "low spender," "moderate spender," and "high spender." The dataset includes features such as monthly income, number of purchases, and average purchase value. Explain how Logistic Regression could be applied to estimate the probability of a customer being a "high spender." Describe the process of converting the linear regression equation into a sigmoid function and interpreting the resulting probability values for classifying customers. Since there are three categories ("low spender," "moderate spender," and "high spender"), explain how Logistic Regression can be adapted for multi-class classification. Let x=[x1,x2,x3]T\mathbf{x} = [x_1, x_2, x_3]^Tx=[x1​,x2​,x3​]T represent Monthly Income, Number of Purchases, and Average Purchase Value. Define the binary target:

Y={1,if High Spender0,otherwise (Low or Moderate Spender)Y = \begin{cases} 1, & \text{if High Spender} \\ 0, & \text{otherwise (Low or Moderate Spender)} \end{cases}Y={1,0,​if High Spenderotherwise (Low or Moderate Spender)​

P(Y=1∣x)=σ(wTx+b)P(Y = 1 \mid \mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b)P(Y=1∣x)=σ(wTx+b)

Question 3 (20 Marks)​

info

Question Statement

A telecommunications company is building a machine learning model to predict customer chum (whether a customer will switch to another service provider). The dataset includes customer demographics, usage patterns, and support interaction history. The team wants to ensure the model generalizes well to new data and avoids overfitting. Explain how cross-validation can be utilized to assess the performance of the chum prediction model and discuss the purpose of cross-validation and how it helps in improving the generalization of the model to unseen data. (20 Marks)

Solution 3 (20 Marks)​

1. Purpose of Cross-Validation (5 Marks)​

Cross-validation (CV) provides an unbiased empirical estimate of expected generalization error on unseen data.

  • Why Holdout (Simple Train-Test Split) Fails: A single split yields high estimator variance depending on which samples fall into the test set by random chance, and it wastes valuable training data in small cohorts.
  • Core Role: By systematically rotating data so that every sample is used for validation exactly once, CV ensures the model does not memorize training noise and provides a reliable measure of out-of-sample performance.

2. Utilizing Stratified K-Fold Cross-Validation in Telecom Churn (8 Marks)​

A. Stratified KKK-Fold Cross-Validation (Mandatory Architecture)​

Telecom churn typically suffers from class imbalance (e.g., 15%15\%15% churners, 85%85\%85% retained). Standard random KKK-fold can produce validation folds with very few or zero churn cases.

Stratified KKK-Fold partitions the dataset into KKK disjoint folds (typically K=5K = 5K=5 or 101010) while strictly preserving the full dataset's class ratio in every fold:

nchurn(k)ntotal(k)≈NchurnNtotal∀k∈{1,…,K}\frac{n_{\text{churn}}^{(k)}}{n_{\text{total}}^{(k)}} \approx \frac{N_{\text{churn}}}{N_{\text{total}}} \quad \forall k \in \{1, \dots, K\}ntotal(k)​nchurn(k)​​≈Ntotal​Nchurn​​∀k∈{1,…,K}
Execution Steps:​
  1. Divide data into KKK stratified folds.
  2. For k=1k = 1k=1 to KKK:
    • Train on (K−1)(K-1)(K−1) folds.
    • Validate on the held-out kkk-th fold to compute metric MkM_kMk​.
  3. Compute aggregate generalization performance: Mˉ=1K∑k=1KMk,SE⁡=sK\bar{M} = \frac{1}{K}\sum_{k=1}^K M_k, \quad \operatorname{SE} = \frac{s}{\sqrt{K}}Mˉ=K1​∑k=1K​Mk​,SE=K​s​
B. Data Leakage Prevention​

Feature transformers (e.g., StandardScaler, imputation) must be fitted strictly inside the (K−1)(K-1)(K−1) training folds and applied out-of-fold to the validation fold to avoid data leakage.

3. How Cross-Validation Improves Generalization & Prevents Overfitting (7 Marks)​

  1. Detects High Variance (Overfitting): A large gap between training performance (98%98\%98%) and cross-validation score (74%74\%74%) flags overfitting, signaling the need for regularization (L2 penalty, tree pruning).
  2. Robust Hyperparameter Selection: Optimal hyperparameters (e.g., regularization parameter CCC, tree depth) are chosen based on average out-of-fold performance across all KKK folds rather than a single lucky split.
  3. Informs Early Stopping: Evaluates when model iterations begin overfitting validation folds without touching the test set.
  4. Aligns with Imbalanced Metrics: Allows tuning for ROC-AUC, PR-AUC, and F1F_1F1​-score rather than raw classification accuracy, which is misleading under class imbalance.
tip

Examiner's Note

Question 4 (20 Marks)​

info

Question Statement

A food delivery app is building a recommendation system to suggest restaurants to users based on preferences and location. The dataset includes features like cuisine type, user ratings, average cost, and proximity. The team decides to use the K-Nearest Neighbors (KNN) algorithm. Explain how the KNN algorithm works in this context and discuss how the choice of K affects model performance, including challenges with very small or large K values. Describe the role of distance metrics, comparing Euclidean and Manhattan distances, and recommend the most suitable metric for this scenario. Finally, suggest evaluation metrics to assess the model's effectiveness in recommending relevant restaurants, justifying their importance in this context. (20 Marks)

Solution 4 (20 Marks)​

1. How KNN Works in Restaurant Recommendation (4 Marks)​

K-Nearest Neighbors is a non-parametric, instance-based lazy learner. It does not train an explicit model; instead, it stores feature vectors and defers computation until inference:

  1. Feature Vector: Each restaurant is encoded as x=[xcuisine,xrating,xcost,xproximity]T\mathbf{x} = [x_{\text{cuisine}}, x_{\text{rating}}, x_{\text{cost}}, x_{\text{proximity}}]^Tx=[xcuisine​,xrating​,xcost​,xproximity​]T.
  2. Distance Calculation: For a user query q\mathbf{q}q, compute the pairwise distance D(q,xi)D(\mathbf{q}, \mathbf{x}_i)D(q,xi​) to all restaurants.
  3. Neighbor Selection: Identify the KKK smallest distances (NK(q)\mathcal{N}_K(\mathbf{q})NK​(q)).
  4. Aggregation & Ranking: Aggregate neighbor ratings via distance-weighted scoring (wi=1D(q,xi)+ϵw_i = \frac{1}{D(\mathbf{q}, \mathbf{x}_i) + \epsilon}wi​=D(q,xi​)+ϵ1​) to rank and recommend the top restaurants.

2. Effect of the Choice of KKK (Bias-Variance Trade-off) (5 Marks)​

  • Very Small KKK (K=1K = 1K=1 or 222):
    • Profile: Low bias, high variance (Overfitting).
    • Challenges: Extreme sensitivity to noise, anomalies, or a newly registered restaurant with a single fake 5-star review. Decision boundaries are jagged and unstable.
  • Very Large KKK (K→NK \to NK→N):
    • Profile: High bias, low variance (Underfitting).
    • Challenges: Neighborhood incorporates geographically distant or irrelevant restaurants. Recommendations collapse to the globally most frequent restaurant category (e.g., mass-market fast food), destroying personalization.
  • Optimal KKK: Typically set to K≈NK \approx \sqrt{N}K≈N​ and tuned via cross-validation using odd values to avoid voting ties.

  • Manhattan Distance (L1L_1L1​) is recommended:
    1. In urban delivery, couriers travel along street grids rather than flying straight lines; L1L_1L1​ approximates travel time more realistically.
    2. Its linear penalty prevents extreme values in cost from dominating ratings and proximity.
  • Mandatory Preprocessing (Feature Scaling): Because proximity (km), rating (1−51-51−5), and cost (currency) use completely different units, Min-Max scaling or Z-score standardization is mandatory before computing distances.

Question Statement

Consider a dataset with two features: height (in cm) and weight (in kg) of individuals. Solution 7 (20 Marks)​

1. Preprocessing Steps Prior to K-Means (5 Marks)​

  1. Feature Standardization (Z-score / Min-Max):
    • Why: Height (140−200 cm140-200\text{ cm}140−200 cm) and Weight (45−100 kg45-100\text{ kg}45−100 kg) use different units and scales. Because K-Means relies on Euclidean distance (d=Δx12+Δx22d = \sqrt{\Delta x_1^2 + \Delta x_2^2}d=Δx12​+Δx22​​), unscaled features with larger numeric variance arbitrarily dominate cluster assignments.
    • Remedy: Standardize to zero mean and unit variance (z=x−μσz = \frac{x - \mu}{\sigma}z=σx−μ​).
  2. Outlier Detection and Removal:
    • K-Means updates centroids using the arithmetic mean (μk=1∣Ck∣∑xi\boldsymbol{\mu}_k = \frac{1}{|C_k|}\sum \mathbf{x}_iμk​=∣Ck​∣1​∑xi​), which is sensitive to extreme values. Outliers should be removed via IQR or Z-score filtering.
  3. Smart Centroid Initialization (K-Means++):
    • Initialize centroids probabilistically proportional to squared distance (D(x)2D(x)^2D(x)2) to prevent poor local minima.

2. Determining the Optimal Number of Clusters (kkk) (8 Marks)​

Method 1: The Elbow Method (Within-Cluster Sum of Squares - WCSS)​
  • Formula: WCSS(k)=∑j=1k∑xi∈Cj∥xi−μj∥22\text{WCSS}(k) = \sum_{j=1}^k \sum_{\mathbf{x}_i \in C_j} \|\mathbf{x}_i - \boldsymbol{\mu}_j\|_2^2WCSS(k)=∑j=1k​∑xi​∈Cj​​∥xi​−μj​∥22​
  • Procedure:
    1. Run K-Means across a range of k∈{1,2,…,Kmax⁡}k \in \{1, 2, \dots, K_{\max}\}k∈{1,2,…,Kmax​}.
    2. Plot WCSS(k)\text{WCSS}(k)WCSS(k) vs. kkk. WCSS decreases monotonically as kkk increases.
    3. Identify the elbow point—the value of kkk where the rate of decrease abruptly slows (diminishing marginal returns).
Method 2: The Silhouette Analysis​
  • Formula: For each point iii: s(i)=b(i)−a(i)max⁡(a(i),b(i))∈[−1,+1]s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))} \in [-1, +1]s(i)=max(a(i),b(i))b(i)−a(i)​∈[−1,+1] where a(i)a(i)a(i) is the mean intra-cluster distance and b(i)b(i)b(i) is the mean distance to the nearest neighboring cluster.
  • Procedure:
    1. Compute the average silhouette score Sˉ(k)=1N∑s(i)\bar{S}(k) = \frac{1}{N}\sum s(i)Sˉ(k)=N1​∑s(i).
    2. Select the value of kkk that maximizes Sˉ(k)\bar{S}(k)Sˉ(k) with minimal negative scores.
