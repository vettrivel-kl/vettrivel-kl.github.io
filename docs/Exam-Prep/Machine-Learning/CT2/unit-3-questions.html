(iii) Class Prediction & Independence Assumption (5 Marks)​

  • Class Prediction (2 Marks):

    • MAP Decision Rule: y^=arg⁡max⁡cP(C=c∣X)\hat{y} = \arg\max_{c} P(C = c \mid \mathbf{X})y^​=argmaxc​P(C=c∣X)
    • Since P(Spam∣Email)=1.0>P(NotSpam∣Email)=0.0P(\text{Spam} \mid \text{Email}) = 1.0 > P(\text{NotSpam} \mid \text{Email}) = 0.0P(Spam∣Email)=1.0>P(NotSpam∣Email)=0.0, the email is classified as Spam.

  • Class-Conditional Independence Assumption (1.5 Marks):

    • Formal Definition: All features are assumed conditionally independent given the class label: P(X1,X2,…,Xd∣C)=∏j=1dP(Xj∣C)P(X_1, X_2, \dots, X_d \mid C) = \prod_{j=1}^d P(X_j \mid C)P(X1​,X2​,…,Xd​∣C)=∏j=1d​P(Xj​∣C)
    • In this context, knowing the email contains 'Offer' provides zero information about 'Win', once the class is fixed.

  • Practical Validity & Trade-offs (1.5 Marks):

    • Why "Naïve": Real-world text features are strongly correlated (e.g., "Offer" and "Win" co-occur in spam).
    • Why It Works: Classification only requires the correct probability ranking (arg⁡max⁡\arg\maxargmax), not calibrated values. It reduces parameter complexity from O(2d)O(2^d)O(2d) to O(d)O(d)O(d), preventing overfitting.

Question 1.b: Comparative Analysis of Classifiers on Medical Data (5 Marks)​

info

Question Statement

A data scientist is working on three models for classifying medical test results:

  • KNN (k=5k=5k=5)
  • Gaussian Naïve Bayes
  • SVM with RBF kernel

Assume given is a small dataset with numeric features:

  • a. Which algorithm handles non-linear boundaries best and why? (2 Marks)
  • b. Which algorithm is most sensitive to irrelevant features? (1.5 Marks)
  • c. Which algorithm performs better when data is small and has missing values? (1.5 Marks)

Solution 1.b​

📝 Exam-Ready Answer (Crisp 5-Mark Structure)​

(a) Best for Non-Linear Boundaries: SVM with RBF Kernel (2 Marks)​
  • Algorithm: SVM with RBF Kernel
  • Why (Key Points):
    • Infinite-Dimensional Mapping: The RBF kernel K(x,x′)=exp⁡(−γ∥x−x′∥2)K(\mathbf{x}, \mathbf{x}') = \exp(-\gamma \|\mathbf{x} - \mathbf{x}'\|^2)K(x,x′)=exp(−γ∥x−x′∥2) projects inputs into an infinite-dimensional Hilbert space.
    • Smooth Decision Surfaces: A linear hyperplane in this transformed space maps back to smooth, continuous non-linear contours in the original feature space.
(b) Most Sensitive to Irrelevant Features: KNN (k=5k=5k=5) (1.5 Marks)​
  • Algorithm: K-Nearest Neighbors (KNN)
  • Why (Key Points):
    • Uniform Distance Metric: Calculates Euclidean distance equally across all DDD features: d=∑j=1D(xj−yj)2d = \sqrt{\sum_{j=1}^D (x_j - y_j)^2}d=∑j=1D​(xj​−yj​)2​.
    • Curse of Dimensionality: Irrelevant dimensions inject random noise, collapsing distance contrast (dmax⁡≈dmin⁡d_{\max} \approx d_{\min}dmax​≈dmin​) and destroying neighborhood ranking.
(c) Best for Small Data and Missing Values: Gaussian Naïve Bayes (1.5 Marks)​
  • Algorithm: Gaussian Naïve Bayes
  • Why (Key Points):
    • Parameter Efficiency: Estimates only 222 parameters per feature (μ,σ2\mu, \sigma^2μ,σ2), resisting overfitting on small samples via high bias/low variance.
    • Native Missing Value Handling: Computes likelihoods by simply omitting missing attributes from the conditional product: P(xobs∣C)=∏j∈obsP(xj∣C)P(\mathbf{x}_{\text{obs}} \mid C) = \prod_{j \in \text{obs}} P(x_j \mid C)P(xobs​∣C)=∏j∈obs​P(xj​∣C).
Quick Comparison Summary​
CriterionWinnerCore Reason
Non-Linear Boundary (2M)SVM (RBF)Kernel trick creates smooth boundaries in infinite-dimensional space.
Sensitive to Irrelevant Features (1.5M)KNN (k=5k=5k=5)Euclidean distance equally sums noise from all dimensions.

    • Scale Dominance: KNN distance calculations are sensitive to magnitude. Features with larger ranges (e.g., Income in thousands) dominate features with smaller ranges (e.g., Spending in tens), distorting distance measurements.
    • Remedy: Apply Min-Max Normalization ([0,1][0, 1][0,1]) or Z-Score Standardization so all dimensions contribute proportionally.

  • Effect of Parameter KKK (1.5 Marks):

    • KKK Too Small (K=1K = 1K=1): Low Bias, High Variance   ⟹  \implies⟹ sensitive to noise and outliers, causing Overfitting (jagged boundaries).
    • KKK Too Large (K→NK \to NK→N): High Bias, Low Variance   ⟹  \implies⟹ overly smooth boundaries, degenerating into global majority voting (Underfitting).
    • Tip: Choose an odd KKK to break ties (rule of thumb: K≈NK \approx \sqrt{N}K≈N​).
(e) Real-World Application of KNN (2 Marks)​
  • Application (1 Mark):
    • Recommender Systems / Collaborative Filtering (e.g., Amazon product recommendations or Spotify music matching).
  • Why Preferred (1 Mark):
    • Lazy Learning (Zero Training Cost): Stores training data directly; new users or products are ingested in real time without expensive model retraining.
    • Intuitive & Non-Parametric: Recommends items by finding users with similar consumption profiles without assuming any underlying mathematical distribution.
