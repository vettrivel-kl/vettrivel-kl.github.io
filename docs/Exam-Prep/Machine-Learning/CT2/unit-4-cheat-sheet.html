2. Question 3 Rapid Blueprint: CART Classification Tree (20 Marks)​

The 4-Step Mental Algorithm​

  1. Root Gini: Compute class frequencies (N=7N=7N=7, 4 Yes, 3 No)   ⟹  Gini=1−(pYes2+pNo2)\implies \text{Gini} = 1 - (p_{\text{Yes}}^2 + p_{\text{No}}^2)⟹Gini=1−(pYes2​+pNo2​).
  2. Evaluate Binary Partitions: For k=3k=3k=3 categories, test all 2k−1−1=32^{k-1}-1 = 32k−1−1=3 binary groupings.
  3. Compute Weighted Gini: Ginisplit=NLNGini(DL)+NRNGini(DR)\text{Gini}_{\text{split}} = \frac{N_L}{N}\text{Gini}(D_L) + \frac{N_R}{N}\text{Gini}(D_R)Ginisplit​=NNL​​Gini(DL​)+NNR​​Gini(DR​).
  4. Select Minimal Gini: The partition with lowest weighted Gini (highest Gini Gain ΔGini\Delta \text{Gini}ΔGini) is selected.

Tie-Breaking Protocols (Sub-part d: 2 Marks)

If two candidate attributes have identical Gini index values:

  1. Acquisition Cost: Pick the feature cheaper or less invasive to collect in practice (e.g., Age Group over verified Income).
  2. Subtree Balance: Pick the split producing more evenly balanced sample counts between left and right children.
  3. Deterministic Schema Order: Fall back to default dataset column order (first column in table).
  4. Secondary Divergence: Check Information Gain (Entropy) to see if logarithmic spread breaks the tie.
tip

Key Advantages of CART over ID3 / C4.5 (Sub-part e: 2 Marks)

  1. Dual Capability (Classification & Regression): CART handles both categorical targets (via Gini Index) and continuous targets (via Variance Reduction / MSE). ID3 is classification-only.
  2. Strict Binary Splitting: CART strictly generates 2 branches per split (2k−1−12^{k-1}-12k−1−1 groupings). This stops multi-way branch fragmentation (a known flaw of ID3) and preserves statistical sample size in deeper nodes.
  3. Disciplined Cost-Complexity Pruning: Employs minimal cost-complexity α\alphaα-pruning validated with cross-validation, which is theoretically sounder than C4.5's heuristic error-based pruning.

3. Question 4 Rapid Blueprint: AdaBoost Fraud Classifier (20 Marks)​

The Core Boosting Workflow & Math​

1. Initialize uniform weights : w_i^(1) = 1/N
2. Train weak stump h_m(x)
3. Compute weighted error    : ε_m = Σ w_i * I(y_i ≠ h_m(x_i))
4. Compute stump importance  : α_m = (1/2) * ln((1 - ε_m) / ε_m)
5. Update sample weights     : w_i^(m+1) = w_i^(m) * exp(-α_m * y_i * h_m(x_i)) / Z_m
   - Correct samples         : w_i * exp(-α_m)  (attenuated)
   - Wrong samples           : w_i * exp(+α_m)  (boosted)

5. Exam Traps & Avoidance Rules​

danger

Common Pitfalls in Unit 4

  1. Confusing Gini with Entropy: Gini Index uses squared probabilities (1−∑pi21 - \sum p_i^21−∑pi2​). Do NOT write −∑pilog⁡2(pi)- \sum p_i \log_2(p_i)−∑pi​log2​(pi​) (which is Entropy used in ID3). Gini has NO logarithms.
  2. Forgetting to Weight the Child Nodes: When computing Ginisplit\text{Gini}_{\text{split}}Ginisplit​, always multiply child Gini values by their branch proportions NLN\frac{N_L}{N}NNL​​ and NRN\frac{N_R}{N}NNR​​. Never take a simple unweighted arithmetic average.
  3. Evaluating Multi-Way Splits Instead of Binary Partitions: CART strictly evaluates binary splits (2k−1−1=32^{k-1}-1 = 32k−1−1=3 candidate splits for 3 categories). If you only compute a single 3-way split, you will lose method marks for CART mechanics.
  4. Log Base Error in AdaBoost α\alphaα: AdaBoost importance weight uses the natural logarithm (ln⁡\lnln), not log⁡10\log_{10}log10​ or log⁡2\log_2log2​. Remember that 12ln⁡(9)=ln⁡(9)=ln⁡(3)≈1.0986\frac{1}{2}\ln(9) = \ln(\sqrt{9}) = \ln(3) \approx 1.098621​ln(9)=ln(9​)=ln(3)≈1.0986.
  5. Sign Mix-up in Weight Updates: Misclassified samples get increased weights (e+αe^{+\alpha}e+α), and correctly classified samples get reduced weights (e−αe^{-\alpha}e−α). Inverting the sign breaks boosting dynamics.
