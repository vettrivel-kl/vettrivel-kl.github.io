(d) Tie-Breaking: What Happens if Both Attributes Have the Same Gini Value? (2 Marks)​

If two attributes produce identical Gini index values, standard CART algorithms resolve the tie using the following established protocols:

  1. Domain-Specific / Cost Priority: Select the attribute that is cheaper, faster, or less intrusive to acquire in real-world production (e.g., Age Group may be easier to collect than verified Income).
  2. Subtree Balance / Child Node Distribution: Choose the split that creates more evenly distributed subset sizes (minimizing sample variance between child nodes).
  3. Deterministic Heuristic: Follow a consistent tie-breaking rule, such as selecting the attribute that appears first in the dataset schema (e.g., column index order).
  4. Secondary Information Metric: Compute Information Gain (Entropy) or Gain Ratio to assess if higher-order divergence distinguishes the attributes.
(e) Two Key Advantages of CART over ID3 or C4.5 (2 Marks)​
  1. Unified Framework for Classification & Regression:
    • CART seamlessly builds both Classification Trees (using the Gini Index for categorical targets) and Regression Trees (using Mean Squared Error / Variance Reduction for continuous numerical targets). In contrast, ID3 is strictly limited to classification, and C4.5 requires separate extensions.
  2. Binary Splitting Avoids Multi-Way Fragmentation:
    • CART strictly enforces binary splits (222 child nodes per split), preventing the exponential data fragmentation problem seen in ID3 (which creates a separate branch for every category). This preserves sample statistical power in lower nodes and naturally prevents overfitting on high-cardinality nominal attributes.
  3. Rigorous Cost-Complexity Pruning:
    • CART uses a mathematically disciplined Minimal Cost-Complexity Pruning algorithm (α\alphaα-pruning parameterized with cross-validation), which is theoretically superior to the greedy heuristic error-based pruning utilized in C4.5.

Question 4: AdaBoost Transaction Fraud Classification (20 Marks)​

info

Question Statement

An online payment platform applies AdaBoost to classify transactions as Fraudulent or Genuine. Each weak learner is a decision stump based on one feature (like transaction amount or device ID).

  • i) Explain why decision stumps are used as weak learners in AdaBoost. (4 Marks)
  • ii) Describe how sample weights are updated after each iteration. (4 Marks)
  • iii) Suppose a stump misclassifies 10% of samples - explain how its error and alpha (importance weight) are computed. (4 Marks)
  • iv) Discuss how boosting reduces bias but can sometimes increase variance. (4 Marks)
  • v) If the dataset has missing values in the "Device ID" feature, explain how AdaBoost handles this situation. (4 Marks)

Solution 4​

📝 Exam-Ready Answer (Structured for 20 Marks)​

(i) Why Decision Stumps are Used as Weak Learners in AdaBoost (4 Marks)​

A decision stump is a 1-level decision tree consisting of a single root split node (testing exactly one attribute threshold) connected directly to two terminal leaf nodes.

  1. Satisfaction of Weak Learner Condition (1 Mark):
    • Boosting theory (Freund & Schapire) requires base learners to perform only slightly better than random guessing (error ϵ<0.5\epsilon < 0.5ϵ<0.5 in binary classification). A simple 1-feature stump easily satisfies this minimal requirement without needing complex parameter tuning.
  2. High Bias, Ultra-Low Variance Structure (1 Mark):
    • Stumps are extreme high-bias, low-variance models. Since boosting is fundamentally designed to reduce ensemble bias by additively combining weak models, starting with low-variance base learners prevents the ensemble from exploding in variance.
  3. Computational Speed & Scalability (1 Mark):
    • Training a stump requires scanning only O(N⋅D)O(N \cdot D)O(N⋅D) candidate thresholds. In production transaction systems (such as high-frequency fraud detection), hundreds of boosting rounds can be trained in seconds.
  4. Interpretability & Feature Ranking (1 Mark):
    • Because each stump isolates a single feature (e.g., Amount>500\text{Amount} > 500Amount>500), aggregating the stump weights provides an intuitive, mathematically exact measure of cumulative feature importance.
(ii) How Sample Weights are Updated After Each Iteration (4 Marks)​

  1. Step 1: Initialization (1 Mark)

    • At iteration m=1m = 1m=1, all NNN transaction samples are initialized with equal, uniform weights: wi(1)=1N,∀i∈{1,2,…,N}w_i^{(1)} = \frac{1}{N}, \quad \forall i \in \{1, 2, \dots, N\}wi(1)​=N1​,∀i∈{1,2,…,N}

  2. Step 2: Weighted Error Rate Computation (1 Mark)

    • For the mmm-th weak learner hm(x)h_m(\mathbf{x})hm​(x), the weighted misclassification error ϵm\epsilon_mϵm​ is computed as the sum of weights of incorrectly predicted transactions: ϵm=∑i=1Nwi(m)⋅I(yi≠hm(xi))\epsilon_m = \sum_{i=1}^N w_i^{(m)} \cdot \mathbb{I}\left( y_i \ne h_m(\mathbf{x}_i) \right)ϵm​=∑i=1N​wi(m)​⋅I(yi​=hm​(xi​)) where yi∈{−1,+1}y_i \in \{-1, +1\}yi​∈{−1,+1} and I(⋅)\mathbb{I}(\cdot)I(⋅) is the indicator function.

  3. Step 3: Learner Importance Weight αm\alpha_mαm​ (1 Mark)

(iv) How Boosting Reduces Bias but Can Sometimes Increase Variance (4 Marks)​

  1. How Boosting Reduces Bias (2 Marks):

    • Additive Sequential Correction: Individual decision stumps have severe underfitting (high bias) because a single threshold cannot capture complex decision surfaces.
    • Progressive Residual Modeling: Each successive learner is trained on the reweighted distribution of samples misclassified by preceding learners.
    • Non-Linear Boundary Synthesis: Linearly combining numerous piecewise linear stumps forms highly expressive, intricate, non-linear decision boundaries: lim⁡M→∞Bias2→0\lim_{M \to \infty} \text{Bias}^2 \to 0limM→∞​Bias2→0 This guarantees that the ensemble training error drops exponentially toward zero as iterations increase.

  2. Why Boosting Can Sometimes Increase Variance (2 Marks):

    • Extreme Sensitivity to Outliers & Label Noise: If a payment dataset contains mislabeled transactions (e.g., an abnormal genuine purchase falsely flagged as fraud) or anomalous outliers, AdaBoost repeatedly misclassifies them.
    • Exponential Weight Explosion: The weight of these noisy points escalates exponentially (emαe^{m \alpha}emα), causing the algorithm to over-focus on learning isolated noise points rather than generalizable fraud patterns.
    • Overfitting & Decision Boundary Fragmentation: The ensemble boundary contorts into irregular, sharp pockets around noisy outliers, leading to high variance, brittle predictions, and deteriorated test accuracy.
    • Mitigation: Employing shrinkage (learning rate η<1\eta < 1η<1), limiting maximum boosting iterations MMM, or using robust variants like Gradient Boosting with Huber loss.
(v) Handling Missing Values in the "Device ID" Feature (4 Marks)​

In practical fraud detection, "Device ID" is frequently missing due to private browsing modes, cookie blocking, or emulator masking. AdaBoost handles this through several robust mechanisms:

  1. Feature Bypassing via Alternative Stumps (Primary CART/Stump Defense) (1.5 Marks):
    • In AdaBoost, each weak learner selects only one best feature to split on at each iteration. If "Device ID" contains extensive missing entries that degrade its split quality, the algorithm automatically selects an alternative, fully observed attribute (e.g., Transaction Amount, IP Geolocation, or Time of Transaction) that yields a lower weighted error ϵm\epsilon_mϵm​.
  2. Missing as an Informative Predictive Category (1 Mark):
    • In cyber-fraud analysis, a missing Device ID is rarely random (it is Missing Not At Random, MNAR). Fraudsters deliberately conceal device fingerprints. AdaBoost treats Missing / Null as a separate, dedicated categorical level (Device_ID = Unknown). This category often becomes an exceptionally powerful indicator of fraudulent intent.
  3. Surrogate Split Rule (CART-Specific Mechanism) (1 Mark):
    • If a stump insists on evaluating Device ID, CART constructs a surrogate split using an auxiliary feature (e.g., IP Address or Browser Type) that mimics the Device ID split with maximum mutual correlation, routing missing transactions along the surrogate branch.
  4. Weighted Proportional Assignment (0.5 Marks):
    • When encountering a missing value during split evaluation, the sample's weight can be split proportionally across both branches according to the relative weight distribution of observed transactions in the child nodes.
