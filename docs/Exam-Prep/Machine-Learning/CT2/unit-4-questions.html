Question 3: CART Classification Tree Construction (20 Marks)​

info

Question Statement

A retail company wants to build a CART classification tree to decide whether a customer will Buy (Yes) or Not Buy (No) a product based on two attributes: Age Group and Annual Income Level.

The training dataset is as follows:

CustomerAge GroupIncome LevelBuy
C1YoungLowNo
C2YoungMediumNo
C3MiddleLowYes
C4MiddleHighYes
C5SeniorMediumYes
C6SeniorHighYes
C7SeniorLowNo
  • (a) Calculate the Gini Index for the parent node (root) before any split. (4 Marks)
  • (b) Compute the Gini Index for each possible split based on: (8 Marks)
    • Age Group
    • Income Level
  • (c) Determine the Best Attribute to Split using Gini Index criterion. (4 Marks)
  • (d) Explain what would happen if both attributes had the same Gini value. (2 Marks)
  • (e) Mention two advantages of CART over ID3 or C4.5 decision trees. (2 Marks)

Solution 3​

📝 Exam-Ready Answer (Crisp 20-Mark Structure)​

(a) Gini Index for the Parent Node (Root) (4 Marks)​

  • Step 1: Class Distribution & Probabilities (2 Marks)

    • Total samples: N=7N = 7N=7
    • Class counts: NYes=4N_{\text{Yes}} = 4NYes​=4 (C3, C4, C5, C6),   NNo=3\; N_{\text{No}} = 3NNo​=3 (C1, C2, C7)
    • Probabilities: pYes=47,  pNo=37p_{\text{Yes}} = \frac{4}{7}, \; p_{\text{No}} = \frac{3}{7}pYes​=74​,pNo​=73​

  • Step 2: Formula & Calculation (2 Marks) Gini(Root)=1−∑pi2=1−[(47)2+(37)2]=1−2549=2449≈0.4898\text{Gini}(\text{Root}) = 1 - \sum p_i^2 = 1 - \left[ \left(\frac{4}{7}\right)^2 + \left(\frac{3}{7}\right)^2 \right] = 1 - \frac{25}{49} = \mathbf{\frac{24}{49} \approx 0.4898}Gini(Root)=1−∑pi2​=1−[(74​)2+(73​)2]=1−4925​=4924​≈0.4898

(b) Compute Gini Index for Each Possible Split (8 Marks)​

CART strictly uses binary splits. For an attribute with k=3k=3k=3 discrete categories, there are 2k−1−1=32^{k-1} - 1 = 32k−1−1=3 candidate binary partitions: Ginisplit=NLNGini(DL)+NRNGini(DR)\text{Gini}_{\text{split}} = \frac{N_L}{N}\text{Gini}(D_L) + \frac{N_R}{N}\text{Gini}(D_R)Ginisplit​=NNL​​Gini(DL​)+NNR​​Gini(DR​)

1. Splits for Age Group (k=3k=3k=3: Young, Middle, Senior) (4 Marks)​

  • Partition 1: {Young}\{\text{Young}\}{Young} vs {Middle, Senior}\{\text{Middle, Senior}\}{Middle, Senior}

    • Left (NL=2N_L = 2NL​=2, Young): 0 Yes, 2 No   ⟹  Gini(DL)=1−(0+1)=0.0\implies \text{Gini}(D_L) = 1 - (0 + 1) = \mathbf{0.0}⟹Gini(DL​)=1−(0+1)=0.0 (Pure Leaf)
    • Right (NR=5N_R = 5NR​=5, Mid+Sen): 4 Yes, 1 No   ⟹  Gini(DR)=1−[(45)2+(15)2]=1−1725=0.320\implies \text{Gini}(D_R) = 1 - \left[\left(\frac{4}{5}\right)^2 + \left(\frac{1}{5}\right)^2\right] = 1 - \frac{17}{25} = \mathbf{0.320}⟹Gini(DR​)=1−[(54​)2+(51​)2]=1−2517​=0.320
    • Weighted Gini: 27(0.0)+57(0.320)=1.67≈0.2286\frac{2}{7}(0.0) + \frac{5}{7}(0.320) = \frac{1.6}{7} \approx \mathbf{0.2286}72​(0.0)+75​(0.320)=71.6​≈0.2286

  • Partition 3: {Senior}\{\text{Senior}\}{Senior} vs {Young, Middle}\{\text{Young, Middle}\}{Young, Middle}

    • Left (NL=3N_L = 3NL​=3, Senior): 2 Yes, 1 No   ⟹  Gini(DL)=1−[49+19]=49≈0.4444\implies \text{Gini}(D_L) = 1 - \left[\frac{4}{9} + \frac{1}{9}\right] = \frac{4}{9} \approx \mathbf{0.4444}⟹Gini(DL​)=1−[94​+91​]=94​≈0.4444
    • Right (NR=4N_R = 4NR​=4, Young+Mid): 2 Yes, 2 No   ⟹  Gini(DR)=1−[416+416]=0.500\implies \text{Gini}(D_R) = 1 - \left[\frac{4}{16} + \frac{4}{16}\right] = \mathbf{0.500}⟹Gini(DR​)=1−[164​+164​]=0.500
    • Weighted Gini: 37(49)+47(0.500)=1021≈0.4762\frac{3}{7}\left(\frac{4}{9}\right) + \frac{4}{7}(0.500) = \frac{10}{21} \approx \mathbf{0.4762}73​(94​)+74​(0.500)=2110​≈0.4762

Best Split for Age Group: {Young} vs {Middle, Senior}  ⟹  Gini≈0.2286\mathbf{\text{Best Split for Age Group: } \{\text{Young}\} \text{ vs } \{\text{Middle, Senior}\} \implies \text{Gini} \approx 0.2286}Best Split for Age Group: {Young} vs {Middle, Senior}⟹Gini≈0.2286

2. Splits for Income Level (k=3k=3k=3: Low, Medium, High) (4 Marks)​

  • Partition 1: {Low}\{\text{Low}\}{Low} vs {Medium, High}\{\text{Medium, High}\}{Medium, High}

  • Partition 2: {Medium}\{\text{Medium}\}{Medium} vs {Low, High}\{\text{Low, High}\}{Low, High}

    • Right (NR=5N_R = 5NR​=5, Low+Med): 2 Yes, 3 No   ⟹  Gini(DR)=1−[425+925]=0.480\implies \text{Gini}(D_R) = 1 - \left[\frac{4}{25} + \frac{9}{25}\right] = \mathbf{0.480}⟹Gini(DR​)=1−[254​+259​]=0.480

(d) Tie-Breaking Protocol for Identical Gini Values (2 Marks)​

If two attributes produce identical Gini values, resolve the tie using:

  1. Acquisition Cost: Choose the attribute cheaper or easier to collect in practice (e.g., Age Group over verified Income).
  2. Subtree Balance: Pick the split creating more evenly balanced sample counts between child nodes.
  3. Schema Order: Default to the attribute appearing first in the dataset schema.
  4. Secondary Metric: Compute Information Gain (Entropy) to test if logarithmic divergence breaks the tie.
(e) Two Key Advantages of CART over ID3 or C4.5 (2 Marks)​
  1. Classification & Regression Support: CART natively constructs both Classification Trees (via Gini Index) and Regression Trees (via Variance Reduction / MSE). ID3 supports classification only.
  2. Binary Splitting Avoids Fragmentation: Enforcing strictly 2 branches per split (2k−1−12^{k-1}-12k−1−1) prevents multi-way branch fragmentation (a flaw of ID3/C4.5), preserving statistical sample power in deeper child nodes.
  3. Disciplined Cost-Complexity Pruning: Uses minimal cost-complexity α\alphaα-pruning parameterized with cross-validation, which is theoretically sounder than heuristic error pruning.

Question 4: AdaBoost Transaction Fraud Classification (20 Marks)​

info

Question Statement

An online payment platform applies AdaBoost to classify transactions as Fraudulent or Genuine. Each weak learner is a decision stump based on one feature (like transaction amount or device ID).

  • i) Explain why decision stumps are used as weak learners in AdaBoost. (4 Marks)
  • ii) Describe how sample weights are updated after each iteration. (4 Marks)
  • iii) Suppose a stump misclassifies 10% of samples - explain how its error and alpha (importance weight) are computed. (4 Marks)
  • iv) Discuss how boosting reduces bias but can sometimes increase variance. (4 Marks)
  • v) If the dataset has missing values in the "Device ID" feature, explain how AdaBoost handles this situation. (4 Marks)

Solution 4​

Exam-Ready Answer (Crisp 20-Mark Structure)​

(i) Why Decision Stumps are Used as Weak Learners (4 Marks)​
  1. Weak Learner: Only one simple split on a single feature threshold.
  2. Low Variance: Extremely simple structure makes it less sensitive to training-data variations and prevents ensemble variance explosion.
  3. Fast: Each stump is computationally cheap to train (O(N⋅D)O(N \cdot D)O(N⋅D)), allowing hundreds of iterations in real time.
  4. Interpretable: Easy to understand and provides direct feature importance rankings.

Memory: One Split -> Low Variance -> Fast -> Interpretable

(ii) How Sample Weights are Updated After Each Iteration (4 Marks)​

  • Step 1 - Uniform Initialization: Give every sample equal initial weight: wi(1)=1N,∀i∈{1,2,…,N}w_i^{(1)} = \frac{1}{N}, \quad \forall i \in \{1, 2, \dots, N\}wi(1)​=N1​,∀i∈{1,2,…,N}

  • Step 2 - Weighted Misclassification Error: Add the weights of incorrectly classified samples: ϵm=∑i=1Nwi(m)⋅I(yi≠hm(xi))\epsilon_m = \sum_{i=1}^N w_i^{(m)} \cdot \mathbb{I}\left( y_i \ne h_m(\mathbf{x}_i) \right)ϵm​=∑i=1N​wi(m)​⋅I(yi​=hm​(xi​))

  • Step 3 - Learner Importance (α\alphaα): Calculate how much the stump is trusted: αm=12ln⁡(1−ϵmϵm)\alpha_m = \frac{1}{2} \ln\left( \frac{1 - \epsilon_m}{\epsilon_m} \right)αm​=21​ln(ϵm​1−ϵm​​) (Low error →\to→ High α\alphaα →\to→ Stronger vote)

  • Step 4 - Exponential Reweighting & Normalization:

    • Wrong samples: Weight increases (wi(m+1)=wi(m)⋅e+αmw_i^{(m+1)} = w_i^{(m)} \cdot e^{+\alpha_m}wi(m+1)​=wi(m)​⋅e+αm​).
    • Correct samples: Weight decreases (wi(m+1)=wi(m)⋅e−αmw_i^{(m+1)} = w_i^{(m)} \cdot e^{-\alpha_m}wi(m+1)​=wi(m)​⋅e−αm​).
    • Normalize: Divide by Zm=∑wi(m+1)Z_m = \sum w_i^{(m+1)}Zm​=∑wi(m+1)​ so weights sum to 111.
    • Train the next stump using the updated sample weights.

Memory: Uniform -> Error -> Alpha -> Reweight -> Normalize -> Next Stump

(iii) Calculate Alpha When Error is 10% (4 Marks)​

  • Given: ϵm=10%=0.10\epsilon_m = 10\% = 0.10ϵm​=10%=0.10

  • Formula & Calculation: αm=12ln⁡(1−0.100.10)=12ln⁡(9)=12ln⁡(32)=ln⁡(3)≈1.0986\alpha_m = \frac{1}{2} \ln\left( \frac{1 - 0.10}{0.10} \right) = \frac{1}{2} \ln(9) = \frac{1}{2} \ln(3^2) = \ln(3) \approx \mathbf{1.0986}αm​=21​ln(0.101−0.10​)=21​ln(9)=21​ln(32)=ln(3)≈1.0986

  • Meaning:

    • Low error →\to→ High α\alphaα →\to→ Strong positive vote in final ensemble.
    • This error and α\alphaα belong specifically to this one stump/iteration.
(iv) How Boosting Reduces Bias but Can Increase Variance (4 Marks)​

  • Why Bias Decreases:

    • Individual decision stumps are simple and underfit alone.
    • Each successive stump explicitly focuses on samples misclassified by previous rounds.
    • Combining many weak learners creates a stronger, non-linear ensemble boundary.
    • Therefore, training bias decreases toward zero.

  • Why Variance Can Increase:

    • Boosting aggressively focuses on hard-to-classify samples.
    • If those difficult instances are noise or outliers, their weights become exponentially inflated.
    • Subsequent stumps fit the noise rather than the underlying pattern, leading to overfitting.
    • Therefore, variance can increase.

Memory: Correct mistakes -> Bias ↓\downarrow↓ | Chase noise -> Variance ↑\uparrow↑

(v) Handling Missing Values in "Device ID" (4 Marks)​

AdaBoost has no built-in missing value handling; it relies on preprocessing or base-learner capabilities:

  1. Pre-processing / Imputation:
    • Impute missing values before boosting using mode or median, optionally adding a binary missingness indicator flag.
  2. Missing as an Informative Category:
    • Treat Missing or Unknown as a distinct category, allowing stumps to learn if missingness itself predicts fraud.
  3. Base Learner Handles Missing Values Natively:
    • CART stump: Uses surrogate splits as a backup feature if Device ID is missing.
    • C4.5-style stump: Distributes the instance's weight fractionally across all possible branches.

Memory: Impute -> Missing Category -> Native Handling
