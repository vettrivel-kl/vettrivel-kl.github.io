Step 4: Prediction & Theory (5 Marks)​

  • Prediction: By MAP rule (arg⁡max⁡\arg\maxargmax), since 1.0>0.01.0 > 0.01.0>0.0, predicted class is Spam.
  • Independence Assumption: Assumes features are mutually conditionally independent given the class label: P(X1,X2∣C)=P(X1∣C)⋅P(X2∣C)P(X_1, X_2 \mid C) = P(X_1 \mid C) \cdot P(X_2 \mid C)P(X1​,X2​∣C)=P(X1​∣C)⋅P(X2​∣C)
  • Why "Naïve": Keywords correlate in real natural language (promotional words like "Offer" and "Win" co-occur).
  • Why It Works: Accurate classification only requires correct ranking (arg⁡max⁡\arg\maxargmax), not calibrated probabilities. It reduces parameter complexity from O(2d)O(2^d)O(2d) to O(d)O(d)O(d).

3. Question 1.b: Classifier Trade-offs (5 Marks)​

Remember the "S - K - N" rule:

  • (a) Non-Linear Boundaries (2M): SVM with RBF Kernel

    • Infinite-Dimensional Mapping: Projects inputs into infinite-dimensional Hilbert space via K(x,x′)=exp⁡(−γ∥x−x′∥2)K(\mathbf{x}, \mathbf{x}') = \exp(-\gamma \|\mathbf{x} - \mathbf{x}'\|^2)K(x,x′)=exp(−γ∥x−x′∥2).
    • Smooth Decision Surfaces: A linear hyperplane in this space maps to smooth, continuous non-linear contours.

  • (b) Most Sensitive to Irrelevant Features (1.5M): KNN (k=5k=5k=5)

    • Uniform Distance Metric: Calculates Euclidean distance equally across all DDD features: d=∑j=1D(xj−yj)2d = \sqrt{\sum_{j=1}^D (x_j - y_j)^2}d=∑j=1D​(xj​−yj​)2​.
    • Curse of Dimensionality: Irrelevant dimensions inject random noise, collapsing distance contrast (dmax⁡≈dmin⁡d_{\max} \approx d_{\min}dmax​≈dmin​).

  • (c) Best for Small Data + Missing Values (1.5M): Gaussian Naïve Bayes

    • Parameter Efficiency: Estimates only 222 parameters per feature (μ,σ2\mu, \sigma^2μ,σ2), resisting overfitting on small samples.
    • Native Missing Value Handling: Computes likelihoods by simply omitting missing attributes from conditional product: P=∏j∈obsP(xj∣C)P = \prod_{j \in \text{obs}} P(x_j \mid C)P=∏j∈obs​P(xj​∣C).

Ranking & Majority Voting (K=3K=3K=3)​

  1. Top-3 Nearest Neighbors:
    • Rank 1 (Tie): C3 (dE≈11.18d_E \approx 11.18dE​≈11.18)   ⟹  \implies⟹ High
    • Rank 2 (Tie): C5 (dE≈11.18d_E \approx 11.18dE​≈11.18)   ⟹  \implies⟹ Low
    • Rank 3: C4 (dE≈16.55d_E \approx 16.55dE​≈16.55)   ⟹  \implies⟹ High
  2. Majority Voting: 2 High2 \text{ High}2 High vs 1 Low  ⟹  1 \text{ Low} \implies1 Low⟹ Predicted class: High Spender (P=2/3≈66.7%P = 2/3 \approx 66.7\%P=2/3≈66.7%).
  3. Manhattan Comparison: Sorted distances are C3 (151515), C5 (151515), C4 (222222)   ⟹  \implies⟹ Same top-3 set {C3,C5,C4}  ⟹  \{C3, C5, C4\} \implies{C3,C5,C4}⟹ Prediction is topologically invariant.

Theory Scoring Points​

  • Feature Scaling (1.5 Marks): Features with larger numeric ranges dominate Euclidean distances, collapsing multidimensional space into a 1D space. Fix with Min-Max Normalization ([0,1][0, 1][0,1]) or Z-Score Standardization.
  • Choice of KKK (1.5 Marks):
    • K=1K = 1K=1: Low Bias, High Variance   ⟹  \implies⟹ captures noise and outliers (Overfitting).
    • K→NK \to NK→N: High Bias, Low Variance   ⟹  \implies⟹ overly smooth, predicts majority class (Underfitting).
    • Rule: Choose odd KKK to prevent ties (K≈NK \approx \sqrt{N}K≈N​).
  • Real-World Application (2 Marks): Recommender Systems / Collaborative Filtering (e.g., Amazon, Spotify). Preferred because lazy learning requires zero offline training time (instant profile ingestion) and intuitive neighborhood matching.

danger

Avoid These Common Traps

  1. Forgetting Prior P(C)P(C)P(C) in Bayes: Don't just multiply feature likelihoods; always include P(Spam)=0.5P(\text{Spam}) = 0.5P(Spam)=0.5.
  2. Missing Normalization: Always show P(Spam∣X)=0.250.25=1.0P(\text{Spam} \mid \mathbf{X}) = \frac{0.25}{0.25} = 1.0P(Spam∣X)=0.250.25​=1.0 so the posterior sums to 111.
  3. Omitting the Square Root in KNN: Δ2=125  ⟹  d=125≈11.18\Delta^2 = 125 \implies d = \sqrt{125} \approx 11.18Δ2=125⟹d=125​≈11.18.
  4. K=1K=1K=1 is NOT High Bias: Remember: K=1K=1K=1 is complex and sensitive to noise   ⟹  \implies⟹ Low Bias, High Variance.
