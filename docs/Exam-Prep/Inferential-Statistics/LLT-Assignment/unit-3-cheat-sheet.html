Unit 3 Cheat Sheet: Sampling & Estimation

This cheat sheet provides a practical mapping framework to translate raw exam questions into correct parameters, select the appropriate formula, and compute exact confidence intervals.

1. Quick-Glance Decision Rules​

  • Proportions (ppp): Always use the ZZZ-distribution (SE=p^q^nSE = \sqrt{\frac{\hat{p}\hat{q}}{n}}SE=np^​q^​​​).
  • Means (μ\muμ):
    • If n≥30n \ge 30n≥30 or σ\sigmaσ is known   ⟹  \implies⟹ ZZZ-distribution (SE=σnSE = \frac{\sigma}{\sqrt{n}}SE=n​σ​).
    • If n<30n < 30n<30 and σ\sigmaσ is unknown   ⟹  \implies⟹ ttt-distribution with df=n−1df = n - 1df=n−1 (SE=snSE = \frac{s}{\sqrt{n}}SE=n​s​).
  • Finite Population Correction (FPC): If total population NNN is given and nN>0.05\frac{n}{N} > 0.05Nn​>0.05 (5%5\%5%)   ⟹  \implies⟹ Multiply SESESE by N−nN−1\sqrt{\frac{N - n}{N - 1}}N−1N−n​​.

4. Worked Problem Archetypes​

Every Unit 3 problem maps to one of the following three templates.

Archetype 1: Population Mean with Known σ\sigmaσ or Large Sample (ZZZ-Interval)​

Exam Scenario: A random sample of 363636 employees spends an average of 22 hours22\text{ hours}22 hours on training with a population standard deviation of 6 hours6\text{ hours}6 hours. Construct a 95%95\%95% confidence interval for the true mean training time.

How to Map the Problem​

  1. Extract Parameters:
    • xˉ=22 hours\bar{x} = 22\text{ hours}xˉ=22 hours
    • σ=6 hours\sigma = 6\text{ hours}σ=6 hours (population standard deviation is known)
    • n=36n = 36n=36 (n≥30  ⟹  n \ge 30 \impliesn≥30⟹ Normal ZZZ-distribution applies)
    • 95% confidence  ⟹  Z0.025=1.96095\%\text{ confidence} \implies Z_{0.025} = \mathbf{1.960}95% confidence⟹Z0.025​=1.960
  2. Calculate Standard Error (SESESE): SE=σn=636=66=1.0 hourSE = \frac{\sigma}{\sqrt{n}} = \frac{6}{\sqrt{36}} = \frac{6}{6} = \mathbf{1.0\text{ hour}}SE=n​σ​=36​6​=66​=1.0 hour
  3. Calculate Margin of Error (MEMEME): ME=Zα/2×SE=1.960×1.0=1.960 hoursME = Z_{\alpha/2} \times SE = 1.960 \times 1.0 = \mathbf{1.960\text{ hours}}ME=Zα/2​×SE=1.960×1.0=1.960 hours
  4. Construct Confidence Interval: CI=xˉ±ME=22±1.960=[20.040, 23.960] hours\text{CI} = \bar{x} \pm ME = 22 \pm 1.960 = \mathbf{[20.040, \, 23.960]\text{ hours}}CI=xˉ±ME=22±1.960=[20.040,23.960] hours

Archetype 2: Population Mean with Small Sample & Unknown σ\sigmaσ (ttt-Interval)​

Exam Scenario: A researcher tests 151515 students using a new study method. The sample mean test score is 787878 with a sample standard deviation of 101010. Construct a 95%95\%95% confidence interval for the true average score.

How to Map the Problem​

  1. Extract Parameters:
    • xˉ=78\bar{x} = 78xˉ=78
    • s=10s = 10s=10 (σ\sigmaσ is unknown)
    • n=15n = 15n=15 (n<30  ⟹  n < 30 \impliesn<30⟹ Small sample, requires ttt-distribution)
    • Degrees of Freedom: df=n−1=15−1=14df = n - 1 = 15 - 1 = \mathbf{14}df=n−1=15−1=14
  2. Lookup ttt-Critical Value:
    • For 95%95\%95% confidence (α/2=0.025\alpha/2 = 0.025α/2=0.025) with df=14df = 14df=14: t0.025,14=2.145t_{0.025, 14} = \mathbf{2.145}t0.025,14​=2.145
  3. Calculate Standard Error (SESESE): SE=sn=1015≈103.873≈2.582SE = \frac{s}{\sqrt{n}} = \frac{10}{\sqrt{15}} \approx \frac{10}{3.873} \approx \mathbf{2.582}SE=n​s​=15​10​≈3.87310​≈2.582
  4. Calculate Margin of Error (MEMEME): ME=tc×SE=2.145×2.582≈5.538ME = t_c \times SE = 2.145 \times 2.582 \approx \mathbf{5.538}ME=tc​×SE=2.145×2.582≈5.538
  5. Construct Confidence Interval: CI=78±5.538=[72.46, 83.54]\text{CI} = 78 \pm 5.538 = \mathbf{[72.46, \, 83.54]}CI=78±5.538=[72.46,83.54]

5. Universal Execution Checklist for Exams​

When solving any estimation problem, write down these 4 numbered steps on your exam script to ensure full method marks:

  1. Step 1: Identify Parameters: List n,xˉ (or p^),σ (or s),N (if given)n, \bar{x}\text{ (or } \hat{p}), \sigma\text{ (or } s), N\text{ (if given)}n,xˉ (or p^​),σ (or s),N (if given).
  2. Step 2: Justify Distribution Choice: State "Since n≥30n \ge 30n≥30, we use the ZZZ-distribution" OR "Since n<30n < 30n<30 and σ\sigmaσ is unknown, we use the ttt-distribution with df=n−1df = n - 1df=n−1".
  3. Step 3: State & Compute SESESE and MEMEME: Show the standard error formula and multiply by the critical value.
  4. Step 4: State Final Interval with Units: Lower Limit=Estimate−ME\text{Lower Limit} = \text{Estimate} - MELower Limit=Estimate−ME, Upper Limit=Estimate+ME\text{Upper Limit} = \text{Estimate} + MEUpper Limit=Estimate+ME.

6. Exam Traps & Pro-Tips​

danger

Common Traps to Avoid

  1. Standard Deviation vs. Standard Error: Never use σ\sigmaσ or sss directly as your margin of error. You must always divide by n\sqrt{n}n​ to obtain the Standard Error (SESESE) before multiplying by the critical value.
  2. Forgetting FPC: If a question explicitly specifies a total population size (e.g., "Assuming a total of 1000 customers..."), it is an intentional signal to test whether you calculate and apply the FPC factor.
  3. Hypothesis Testing via Confidence Interval (Duality): When an exam question asks whether a claimed value μ0\mu_0μ0​ is supported by the sample data:
    • If μ0\mu_0μ0​ falls inside the (1−α)(1 - \alpha)(1−α) interval   ⟹  \implies⟹ Fail to reject H0H_0H0​ (Claim is plausible).
    • If μ0\mu_0μ0​ falls outside the (1−α)(1 - \alpha)(1−α) interval   ⟹  \implies⟹ Reject H0H_0H0​ (Claim is significantly different).
