Question Statement

A security system requires users to create a 5-character access code using the letters A-Z (uppercase only). Each character in the code must be a letter, and letters cannot be repeated.

Solution 1​

  1. Identify Parameters & Counting Principle:

    • Total available uppercase English letters: n=26n = 26n=26 (AAA through ZZZ).
    • Length of access code: r=5r = 5r=5.
    • Constraint: Characters cannot be repeated (sampling without replacement).
    • Order significance: In an access code/password, the sequence matters (e.g., ABCDE≠EDCBAABCDE \neq EDCBAABCDE=EDCBA). Hence, this is a Permutation problem.

  2. Permutation Formula: P(n,r)=nPr=n!(n−r)!P(n, r) = {}^n P_r = \frac{n!}{(n - r)!}P(n,r)=nPr​=(n−r)!n!​

  3. Calculation: 26P5=26!(26−5)!=26!21!=26×25×24×23×22{}^{26}P_5 = \frac{26!}{(26 - 5)!} = \frac{26!}{21!} = 26 \times 25 \times 24 \times 23 \times 2226P5​=(26−5)!26!​=21!26!​=26×25×24×23×22

    • 26×25=65026 \times 25 = 65026×25=650
    • 650×24=15,600650 \times 24 = 15,600650×24=15,600
    • 15,600×23=358,80015,600 \times 23 = 358,80015,600×23=358,800
    • 358,800×22=7,893,600358,800 \times 22 = \mathbf{7,893,600}358,800×22=7,893,600

  4. Conclusion: The security system can generate exactly 7,893,6007,893,6007,893,600 unique 5-character access codes.

Question 3​

info

Question Statement

A company produces three types of beverages: A, B, and C. The probability of a beverage being defective is as follows:The probability of a beverage being defective for A is 0.02, The probability of a beverage being defective for B is 0.05. The probability of a beverage being defective for C is 0.01, The conditional probabilities that a defective beverage comes from each type are : The probability that a defective beverage is of type A is 0.2, The probability that a defective beverage is of type B is 0.3, The probability that a defective beverage is of type C is 0.35. If a defective beverage is discovered, what is the most likely type of beverage (A, B, or C) that it is?

Solution 3​

Let DDD denote the event that a beverage is defective, and A,B,CA, B, CA,B,C denote the beverage types.

  • Priors (Production Shares): P(A)=0.20,  P(B)=0.30,  P(C)=0.35P(A) = 0.20, \; P(B) = 0.30, \; P(C) = 0.35P(A)=0.20,P(B)=0.30,P(C)=0.35
  • Likelihoods (Defect Rates): P(D∣A)=0.02,  P(D∣B)=0.05,  P(D∣C)=0.01P(D \mid A) = 0.02, \; P(D \mid B) = 0.05, \; P(D \mid C) = 0.01P(D∣A)=0.02,P(D∣B)=0.05,P(D∣C)=0.01
1. Joint Defect Probabilities P(Type∩D)P(\text{Type} \cap D)P(Type∩D)​
  • P(A∩D)=0.20×0.02=0.0040P(A \cap D) = 0.20 \times 0.02 = \mathbf{0.0040}P(A∩D)=0.20×0.02=0.0040
  • P(B∩D)=0.30×0.05=0.0150P(B \cap D) = 0.30 \times 0.05 = \mathbf{0.0150}P(B∩D)=0.30×0.05=0.0150
  • P(C∩D)=0.35×0.01=0.0035P(C \cap D) = 0.35 \times 0.01 = \mathbf{0.0035}P(C∩D)=0.35×0.01=0.0035
2. Total Probability of Defect P(D)P(D)P(D)​

P(D)=0.0040+0.0150+0.0035=0.0225P(D) = 0.0040 + 0.0150 + 0.0035 = \mathbf{0.0225}P(D)=0.0040+0.0150+0.0035=0.0225

3. Posterior Probabilities (Bayes' Rule)​

P(Type∣D)=P(Type∩D)P(D)P(\text{Type} \mid D) = \frac{P(\text{Type} \cap D)}{P(D)}P(Type∣D)=P(D)P(Type∩D)​

  • P(A∣D)=0.00400.0225≈17.78%P(A \mid D) = \frac{0.0040}{0.0225} \approx \mathbf{17.78\%}P(A∣D)=0.02250.0040​≈17.78%
  • P(B∣D)=0.01500.0225≈66.67%P(B \mid D) = \frac{0.0150}{0.0225} \approx \mathbf{66.67\%}P(B∣D)=0.02250.0150​≈66.67%
  • P(C∣D)=0.00350.0225≈15.56%P(C \mid D) = \frac{0.0035}{0.0225} \approx \mathbf{15.56\%}P(C∣D)=0.02250.0035​≈15.56%

Conclusion: Comparing posterior probabilities (66.67%>17.78%>15.56%66.67\% > 17.78\% > 15.56\%66.67%>17.78%>15.56%), Type B is overwhelmingly the most likely defective beverage.
