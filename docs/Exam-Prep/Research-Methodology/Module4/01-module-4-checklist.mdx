### Section C: Response Surface Methodology & Optimization
- [ ] **[RSM Fundamentals & First-Order Modeling](../../../ResearchMethodology/Module4/04-rsm-fundamentals-and-first-order.mdx):**
  - [ ] Memorize the **Canonical 10-Step Methodological Framework of RSM**:
    1. Define the Problem (Objective: Maximize, Minimize, or Target).
    2. Select Response Variable(s) ($Y$).
    3. Identify Factors and Levels (Coded levels: Low $-1$, Center $0$, High $+1$).
    4. Select Experimental Design (CCD / BBD).
    5. Conduct Experiments according to design matrix and record responses.
    6. Fit the Mathematical Model ($Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2$).
    7. Analyze the Model using statistical tests (ANOVA, $F$-value, $p$-value, $R^2$, Adjusted $R^2$, Lack-of-Fit).
    8. Study the Response Surface (Contour plots, 3D surface plots).
    9. Determine the Optimum Conditions (Steepest ascent path / stationary point $\mathbf{x}_0$).
    10. Conduct Confirmation Experiments (Validate predicted vs. actual responses).
  - [ ] Calculate 1st-order regression coefficients ($\beta_0 = \frac{\sum Y}{N}, \beta_j = \frac{\sum X_j Y}{N}$).
  - [ ] Execute the **Method of Steepest Ascent** along gradient $\nabla Y = [\beta_1, \beta_2]^T$ with proportional step conversions.
- [ ] **[RSM Designs: Central Composite & Box-Behnken](../../../ResearchMethodology/Module4/05-rsm-designs-ccd-and-bbd.mdx):**
  - [ ] Understand Central Composite Design (CCD) point structure: Factorial ($2^k$) + Star ($2k$) + Center ($n_c$).
  - [ ] Calculate total runs in CCD: $N = 2^k + 2k + n_c$ (e.g., $k=2, n_c=5 \implies N = 13$).
  - [ ] Derive star distance for rotatability: $\alpha = (2^k)^{1/4}$ ($\sqrt{2} \approx 1.414$ for $k=2$).
  - [ ] Convert coded star coordinates $(\pm \alpha)$ into physical engineering settings.
  - [ ] Understand Box-Behnken Design (BBD): Edge midpoints with strictly 3 levels ($-1, 0, +1$).
  - [ ] Calculate total runs in BBD: $N = 2k(k - 1) + n_c$ (e.g., $k=3, n_c=3 \implies N = 15$).
  - [ ] Explain why BBD is safer for hazardous processes (omits extreme factorial corners and out-of-range star points).
  - [ ] Reproduce the comparison matrix between CCD and BBD.
- [ ] **[RSM: Multi-Response Optimization (MRO)](../../../ResearchMethodology/Module4/06-rsm-multi-response-optimization.mdx):**
  - [ ] Formulate linear desirability functions for Larger-the-better ($d_Y = \frac{Y - Y_{\min}}{Y_{\max} - Y_{\min}}$) and Smaller-the-better ($d_R = \frac{R_{\max} - R}{R_{\max} - R_{\min}}$).
  - [ ] Compute overall composite desirability via geometric mean: $D = (d_1 \times \dots \times d_k)^{1/k}$.
  - [ ] Explain the Zero-Product Rule: if any $d_i = 0$, $D = 0$.
  - [ ] Solve multi-response trade-off problems balancing competing criteria (e.g., Yield vs. Roughness).
- [ ] **[Global Optimization & Metaheuristics Taxonomy](../../../ResearchMethodology/Module4/07-global-optimization-and-taxonomy.mdx):**
  - [ ] Define the 5 components of an optimization problem: Decision Variables, Objective Function, Constraints, Parameters, and Algorithm.
  - [ ] Differentiate between a **Local Optimum** and a **Global Optimum**.
  - [ ] Define Heuristic vs. Metaheuristic; explain the balance between **Exploration (Diversification)** and **Exploitation (Intensification)**.
  - [ ] Reproduce the 5-Branch Taxonomy Tree:

- [ ] **[Genetic Algorithms (GA)](../../../ResearchMethodology/Module4/08-genetic-algorithms.mdx):**

  - [ ] Detail the 7 execution stages: Chromosome formation, population init, fitness evaluation, selection, crossover, mutation, and elitist replacement.
  - [ ] Perform a manual 1-generation GA calculation maximizing $f(x) = x^2$ with 5-bit strings.

## 2. Master Formula Cheatsheet

### 1. Analysis of Variance (ANOVA) Layouts

$$\text{Correction Factor: } CF = \frac{G^2}{N}, \quad \text{Total SS: } \text{SST} = \sum y^2 - CF$$

| Experimental Design | Treatment SS ($\text{SSTreat}$) | Blocking / Gradient SS | Error SS ($\text{SSE}$) | Error Degrees of Freedom ($\text{df}_{\text{Error}}$) |
| :--- | :--- | :--- | :--- | :--- |
| **CRD** ($t$ treat, $r$ rep) | $\sum \frac{T_i^2}{r} - CF$ | None | $\text{SST} - \text{SSTreat}$ | $N - t = t(r - 1)$ |
| **RBD** ($t$ treat, $r$ blocks) | $\sum \frac{T_i^2}{r} - CF$ | $\text{SSBlock} = \sum \frac{B_j^2}{t} - CF$ | $\text{SST} - \text{SSTreat} - \text{SSBlock}$ | $(t - 1)(r - 1)$ |
| **LSD** ($p \times p$ square) | $\sum \frac{T_i^2}{p} - CF$ | $\text{SSRow} = \sum \frac{R_j^2}{p} - CF$<br/>$\text{SSCol} = \sum \frac{C_k^2}{p} - CF$ | $\text{SST} - \text{SSTreat} - \text{SSRow} - \text{SSCol}$ | $(p - 1)(p - 2)$ |

*Test Statistic:* $F_{\text{cal}} = \frac{\text{MSTreat}}{\text{MSE}} = \frac{\text{SSTreat} / \text{df}_{\text{Treat}}}{\text{SSE} / \text{df}_{\text{Error}}}$

### 2. $2^k$ Full Factorial Design Formulas

$$\text{Contrast: } C = \sum_{i=1}^{2^k} \pm y_{i+}, \quad \text{Estimated Effect: } \hat{E} = \frac{C}{2^{k-1} \cdot r}, \quad \text{Sum of Squares: } \text{SS}_E = \frac{C^2}{2^k \cdot r}$$

---

### 3. Taguchi Robust Design Formulas

*   **Quality Loss Function:**
    $$L(y) = k(y - m)^2, \quad \text{where } k = \frac{\text{Cost at Specification Limit}}{\Delta^2}$$
*   **Signal-to-Noise Ratios (dB):**
    *   **Larger-the-Better (LTB):**
        $$\eta = -10 \log_{10}\left(\frac{1}{n}\sum_{i=1}^n \frac{1}{y_i^2}\right) \quad \xrightarrow{n=1} \quad 20 \log_{10}(y)$$
    *   **Smaller-the-Better (STB):**
        $$\eta = -10 \log_{10}\left(\frac{1}{n}\sum_{i=1}^n y_i^2\right)$$
    *   **Nominal-the-Best (NTB):**
        $$\eta = 10 \log_{10}\left(\frac{\bar{y}^2}{s^2}\right)$$
*   **Predicted Optimum Performance:**
    $$\overline{S/N}_{\text{pred}} = \overline{S/N}_{\text{overall}} + \sum_{j=1}^k \left(\overline{S/N}_{j, \text{opt}} - \overline{S/N}_{\text{overall}}\right)$$

---

### 4. Response Surface & Desirability Formulas

*   **First-Order Planar Model & Orthogonal Coefficient Estimation:**
    $$Y = \beta_0 + \sum_{i=1}^k \beta_i X_i, \quad \beta_0 = \frac{\sum Y_i}{N}, \quad \beta_j = \frac{\sum X_{ji} Y_i}{N}$$
*   **Steepest Ascent Gradient Direction:**
    $$\nabla Y = \begin{bmatrix} \beta_1 & \beta_2 & \dots & \beta_k \end{bmatrix}^T$$
*   **Second-Order Quadratic Model:**
    $$y = \beta_0 + \sum_{i=1}^k \beta_i x_i + \sum_{i=1}^k \beta_{ii} x_i^2 + \sum_{i < j} \beta_{ij} x_i x_j + \epsilon$$
*   **Derringer-Suich Overall Desirability:**
    $$D = \left(d_1 \times d_2 \times \dots \times d_m\right)^{\frac{1}{m}} = \left(\prod_{i=1}^m d_i\right)^{\frac{1}{m}}$$

---

### 5. Metaheuristic Governing Formulas

*   **Simulated Annealing Metropolis Criterion:**
    $$\Delta E = E_{\text{new}} - E_{\text{current}}, \quad P = \begin{cases} 1 & \text{if } \Delta E \le 0 \\ \exp\left(-\frac{\Delta E}{T}\right) & \text{if } \Delta E > 0 \end{cases}$$
    $$\text{Cooling Schedule: } T_{k+1} = \alpha T_k \quad (0.8 \le \alpha < 1)$$
*   **Particle Swarm Optimization (PSO) Updates:**
    $$\mathbf{V}_i^{t+1} = w \mathbf{V}_i^t + c_1 r_1 \left(\mathbf{pbest}_i - \mathbf{X}_i^t\right) + c_2 r_2 \left(\mathbf{gbest} - \mathbf{X}_i^t\right)$$
    $$\mathbf{X}_i^{t+1} = \mathbf{X}_i^t + \mathbf{V}_i^{t+1}$$
