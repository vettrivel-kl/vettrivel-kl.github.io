Why Logistic Regression

Topic — Linear regression is designed to predict unbounded continuous quantities like housing prices or temperature. When applied to classification problems (pass/fail, default/repay, spam/ham), linear regression fails catastrophically: it produces nonsensical negative or >100%>100\%>100% probabilities and allows distant outliers to warp the decision boundary. This chapter explores these structural failure modes and introduces the sigmoid activation function as the proper mathematical gateway to probabilistic classification.

1. The Core Concept​

In supervised binary classification, target labels are discrete binary states:

y∈{0,1}y \in \{0, 1\}y∈{0,1}

Rather than outputting hard discrete labels directly, modern machine learning models estimate the conditional posterior probability:

P(y=1∣x)P(y = 1 \mid x)P(y=1∣x)

A valid probability must strictly adhere to the Kolmogorov axioms, specifically bounded within the unit interval:

0≤P(y=1∣x)≤10 \le P(y = 1 \mid x) \le 10≤P(y=1∣x)≤1

While Ordinary Least Squares (OLS) linear regression fits a hyper-plane y=wTx+by = w^T x + by=wTx+b, its outputs are completely unconstrained (y∈(−∞,+∞)y \in (-\infty, +\infty)y∈(−∞,+∞)). Wrapping this linear score inside a monotonic, non-linear sigmoid squashing function guarantees valid probabilities.

tip

If you only take one thing from this page

Despite its historical name, Logistic Regression is a classification algorithm, not a regression algorithm. It models the log-odds of a binary event as a linear function of features, mapping real-valued inputs into valid [0,1][0, 1][0,1] probabilities via the sigmoid function σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​.

3. The Two Fatal Flaws of Linear Regression​

Why can we not simply fit Ordinary Least Squares y=mx+by = mx + by=mx+b and apply a cutoff at 0.50.50.5?

  • 🚫 Flaw 1: Nonsensical Probabilities
  • 💥 Flaw 2: Severe Outlier Sensitivity

  • The Problem: Linear equations are unbounded rays: as x→±∞x \to \pm \inftyx→±∞, y→±∞y \to \pm \inftyy→±∞.
  • Real-world Disaster: If predicting student pass/fail based on study hours (y=0.16x−0.58y = 0.16x - 0.58y=0.16x−0.58):
    • Student studying 1 hour: predicted score is −0.42-0.42−0.42 (Negative probability!).
    • Student studying 15 hours: predicted score is 1.821.821.82 (Probability of 182%!).
  • Statistical Violation: Violates Kolmogorov probability axioms. Downstream decision systems (expected value, risk budgeting) fail when passed negative probabilities.

  • The Problem: OLS minimizes squared residuals ∑(yi−y^i)2\sum (y_i - \hat{y}_i)^2∑(yi​−y^​i​)2.
  • The Distortion: A student who studied 50 hours and passed easily has yi=1y_i = 1yi​=1. The linear model predicts y^=7.6\hat{y} = 7.6y^​=7.6.
  • The Paradox: Because 7.6≫1.07.6 \gg 1.07.6≫1.0, OLS treats this successful student as an enormous error with squared loss (1−7.6)2=43.56(1 - 7.6)^2 = 43.56(1−7.6)2=43.56.
  • The Collapse: To minimize this artificial penalty, OLS rotates its slope downwards, pulling down predictions for borderline students and misclassifying true positives.

5. Mathematical Anatomy of the Sigmoid Curve​

The standard logistic sigmoid function σ(z)\sigma(z)σ(z) maps any real number z∈(−∞,+∞)z \in (-\infty, +\infty)z∈(−∞,+∞) into the open unit interval (0,1)(0, 1)(0,1):

σ(z)=11+e−z=ez1+ez\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}σ(z)=1+e−z1​=1+ezez​

  • 1. Numerator: 1
  • 2. Denominator Term: e^(-z)
  • 3. Fundamental Symmetry

  • Acts as the upper asymptotic ceiling.
  • As z→+∞z \to +\inftyz→+∞, e−z→0e^{-z} \to 0e−z→0, forcing σ(z)→11+0=1.0\sigma(z) \to \frac{1}{1 + 0} = 1.0σ(z)→1+01​=1.0.

  • The exponential engine driving smooth non-linear saturation.
  • When z=0z = 0z=0, e−0=1.0e^{-0} = 1.0e−0=1.0, producing the exact symmetry center: σ(0)=11+1=0.5\sigma(0) = \frac{1}{1 + 1} = 0.5σ(0)=1+11​=0.5.
  • As z→−∞z \to -\inftyz→−∞, e−z→+∞e^{-z} \to +\inftye−z→+∞, driving σ(z)→0.0\sigma(z) \to 0.0σ(z)→0.0.

  • The Identity: σ(−z)=1−σ(z)\sigma(-z) = 1 - \sigma(z)σ(−z)=1−σ(z).
  • Proof: 1−σ(z)=1−11+e−z=e−z1+e−z=1ez+1=σ(−z)1 - \sigma(z) = 1 - \frac{1}{1 + e^{-z}} = \frac{e^{-z}}{1 + e^{-z}} = \frac{1}{e^z + 1} = \sigma(-z)1−σ(z)=1−1+e−z1​=1+e−ze−z​=ez+11​=σ(−z)
  • Engineering Value: The probability of failure (1−p1 - p1−p) equals the sigmoid of the negated linear score.

7. Common Mistakes​

  • 🚨 1. Confusing Classification with Regression
  • 🚨 2. Using OLS for Probability Estimation
  • 🚨 3. Blindly Fixing Threshold at 0.5
  • 🚨 4. Confusing Sigmoid with Tanh
  • 🚨 5. Fitting Linear Regression Outliers

  • The Misconception: "Logistic Regression has 'Regression' in its name, so it is used to predict continuous numeric values."
  • ❌ Wrong Thinking: Using LogisticRegression to forecast prices or temperature.
  • ✅ The Right Principle: The name is an artifact of statistics (modeling the continuous log-odds parameter). Logistic Regression is fundamentally a classification algorithm designed for discrete categorical targets.

  • The Misconception: "We can fit linear regression to 0/1 labels and simply clamp predictions into [0, 1] using min/max."
  • ❌ Wrong Thinking: Patching linear models with artificial clipping.
  • ✅ The Right Principle: Clamping ignores the non-linear relationship of probabilities near 0 and 1, distorts variance, and remains fragile to outlier-induced boundary shifts. Use Logistic Regression natively.

  • The Misconception: "A model should always predict positive when P≥0.5P \ge 0.5P≥0.5."
  • ❌ Wrong Thinking: Treating the 0.5 mathematical midpoint as a universal business rule.
  • ✅ The Right Principle: Thresholds must reflect downstream asymmetric costs. In fraud detection or cancer diagnostics, false negatives are catastrophic; lower the threshold to 0.1 or 0.2 to maximize recall.

  • The Misconception: "Sigmoid and Hyperbolic Tangent (Tanh) are interchangeable activation functions."
  • ❌ Wrong Thinking: Using Tanh to model probabilities.
  • ✅ The Right Principle: Sigmoid maps to (0,1)(0, 1)(0,1), matching probability axioms. Tanh maps to (−1,1)(-1, 1)(−1,1), zero-centered for neural network hidden states, but invalid for direct binary probabilities.

  • The Misconception: "Squared error loss (MSEMSEMSE) is suitable for training binary classification models."
  • ❌ Wrong Thinking: Minimizing (y−y^)2(y - \hat{y})^2(y−y^​)2 on binary targets.
  • ✅ The Right Principle: Squared error penalizes correct but confident predictions (y=1,y^=3  ⟹  loss=4y=1, \hat{y}=3 \implies \text{loss}=4y=1,y^​=3⟹loss=4). Logistic regression uses Binary Cross-Entropy (Log Loss), which creates zero penalty for confident correct classifications.

8. Summary​

🤖 Linear Regression Failures

  • Unbounded Output: Linear predictions escape [0,1][0, 1][0,1], producing impossible negative and >100%>100\%>100% probabilities.
  • Outlier Sensitivity: OLS penalizes confident correct samples (y=1,y^≫1y=1, \hat{y} \gg 1y=1,y^​≫1), tilting the decision boundary.
  • Loss Function Mismatch: Mean Squared Error creates non-convex optimization surfaces when paired with non-linear activations.

🛠️ The Sigmoid Solution

  • Strict Bounding: σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​ mathematically guarantees outputs in open unit interval (0,1)(0, 1)(0,1).
  • Symmetry: Perfect anti-symmetry centered at (0,0.5)(0, 0.5)(0,0.5) via σ(−z)=1−σ(z)\sigma(-z) = 1 - \sigma(z)σ(−z)=1−σ(z).
  • Robust Asymptotes: Extreme values plateau smoothly, rendering parameter updates robust to outliers.

📌 Key Takeaways

  • 🎯 Probabilities require sigmoid: Linear models cannot enforce the unit interval constraint [0,1][0, 1][0,1].
  • ⚖️ Sigmoid symmetry simplifies math: σ(−z)=1−σ(z)\sigma(-z) = 1 - \sigma(z)σ(−z)=1−σ(z) ensures that modeling P(y=1)P(y=1)P(y=1) automatically defines P(y=0)P(y=0)P(y=0).
  • 🛡️ Asymptotes protect against outliers: The plateau of the S-curve prevents extreme inputs from distorting classifications near the decision threshold.

Review Flashcards​

❓ 1. [THEORY] Why is the sigmoid function preferred over a simple step function (Heaviside) for classification?

  • Differentiability: A step function has a derivative of zero everywhere except at z=0z=0z=0, where it is undefined. Gradient-based optimization (gradient descent) cannot compute parameter updates.
  • Continuous Probabilities: The sigmoid function is smooth, continuously differentiable everywhere (σ′(z)=σ(z)(1−σ(z))\sigma'(z) = \sigma(z)(1 - \sigma(z))σ′(z)=σ(z)(1−σ(z))), providing informative gradients that indicate not just whether a sample is classified correctly, but how confident the prediction is.

  • Multiply numerator and denominator by eze^zez: e−z⋅ez(1+e−z)⋅ez=1ez+1=11+ez=σ(−z)\frac{e^{-z} \cdot e^z}{(1 + e^{-z}) \cdot e^z} = \frac{1}{e^z + 1} = \frac{1}{1 + e^z} = \sigma(-z)(1+e−z)⋅eze−z⋅ez​=ez+11​=1+ez1​=σ(−z)
  • Thus, σ(−z)=1−σ(z)\sigma(-z) = 1 - \sigma(z)σ(−z)=1−σ(z) holds identically for all z∈Rz \in \mathbb{R}z∈R.
