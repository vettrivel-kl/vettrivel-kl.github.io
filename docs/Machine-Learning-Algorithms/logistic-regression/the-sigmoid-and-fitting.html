The Sigmoid and Fitting

Topic — How do we fit an S-shaped curve to discrete binary data? In linear regression, parameters are chosen by minimizing Mean Squared Error through a closed-form formula. In logistic regression, squared error creates non-convex surfaces with treacherous local minima. This chapter derives Binary Cross-Entropy (Log Loss) from the principle of Maximum Likelihood Estimation (MLE), steps through hand-worked parameter fitting, and tracks gradient descent convergence.

1. The Core Concept​

Logistic regression combines a linear combination of input features with the non-linear sigmoid activation function:

z=wTx+b=w1x1+w2x2+⋯+wdxd+bz = w^T x + b = w_1 x_1 + w_2 x_2 + \dots + w_d x_d + bz=wTx+b=w1​x1​+w2​x2​+⋯+wd​xd​+b

y^=P(y=1∣x)=σ(z)=11+e−z\hat{y} = P(y = 1 \mid x) = \sigma(z) = \frac{1}{1 + e^{-z}}y^​=P(y=1∣x)=σ(z)=1+e−z1​

Because the output y^\hat{y}y^​ represents the probability of a Bernoulli random variable, we cannot optimize parameters www and bbb using Ordinary Least Squares. Instead, we use Maximum Likelihood Estimation (MLE) to find the parameters that make the observed training data most probable.

tip

If you only take one thing from this page

Log Loss (Binary Cross-Entropy) is not an arbitrary choice: it is the direct negative log-likelihood of a Bernoulli distribution. It is strictly convex with respect to linear weights, guaranteeing that gradient descent always converges to the global minimum without getting trapped in local valleys.

  • Assuming independent and identically distributed (i.i.d.) observations, the joint likelihood across all nnn samples is the product: L(w,b)=∏i=1ny^iyi(1−y^i)1−yiL(w, b) = \prod_{i=1}^{n} \hat{y}_i^{y_i} (1 - \hat{y}_i)^{1 - y_i}L(w,b)=∏i=1n​y^​iyi​​(1−y^​i​)1−yi​

  • Multiplying thousands of fractional probabilities causes severe floating-point underflow.
  • Taking the natural logarithm converts the product into a numerically stable summation: ln⁡L(w,b)=ln⁡(∏i=1ny^iyi(1−y^i)1−yi)\ln L(w, b) = \ln \left( \prod_{i=1}^{n} \hat{y}_i^{y_i} (1 - \hat{y}_i)^{1 - y_i} \right)lnL(w,b)=ln(∏i=1n​y^​iyi​​(1−y^​i​)1−yi​) ln⁡L(w,b)=∑i=1n[yiln⁡(y^i)+(1−yi)ln⁡(1−y^i)]\ln L(w, b) = \sum_{i=1}^{n} \left[ y_i \ln(\hat{y}_i) + (1 - y_i) \ln(1 - \hat{y}_i) \right]lnL(w,b)=∑i=1n​[yi​ln(y^​i​)+(1−yi​)ln(1−y^​i​)]

  • In optimization, algorithms are conventionally formulated to minimize cost rather than maximize likelihood.
  • Multiplying by −1-1−1 and averaging over nnn samples produces the standard Binary Cross-Entropy Loss function: J(w,b)=−1n∑i=1n[yiln⁡(y^i)+(1−yi)ln⁡(1−y^i)]J(w, b) = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \ln(\hat{y}_i) + (1 - y_i) \ln(1 - \hat{y}_i) \right]J(w,b)=−n1​∑i=1n​[yi​ln(y^​i​)+(1−yi​)ln(1−y^​i​)]
  • Maximizing likelihood is mathematically identical to minimizing log loss.

5. Optimization Mechanics: Gradient Descent​

Unlike Ordinary Least Squares linear regression, setting ∇J(w,b)=0\nabla J(w, b) = 0∇J(w,b)=0 yields a transcendental equation that cannot be solved analytically in closed form. We must use iterative optimization (Gradient Descent).

The Elegance of the Gradient​

Using the chain rule, the derivative of the sigmoid is:

dσ(z)dz=σ(z)(1−σ(z))=y^(1−y^)\frac{d\sigma(z)}{dz} = \sigma(z)(1 - \sigma(z)) = \hat{y}(1 - \hat{y})dzdσ(z)​=σ(z)(1−σ(z))=y^​(1−y^​)

When taking the partial derivative of Log Loss J(w,b)J(w, b)J(w,b) with respect to weight wjw_jwj​, the non-linear terms cancel out cleanly:

∂J∂wj=1n∑i=1n(y^i−yi)xij\frac{\partial J}{\partial w_j} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) x_{ij}∂wj​∂J​=n1​∑i=1n​(y^​i​−yi​)xij​

∂J∂b=1n∑i=1n(y^i−yi)\frac{\partial J}{\partial b} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)∂b∂J​=n1​∑i=1n​(y^​i​−yi​)

The Universal Gradient Pattern

Notice that the gradient for Logistic Regression is identical in algebraic form to the gradient of Linear Regression:

Error×Input=(y^i−yi)xij\text{Error} \times \text{Input} = (\hat{y}_i - y_i) x_{ij}Error×Input=(y^​i​−yi​)xij​

The only difference is that for Logistic Regression, y^i=σ(wTxi+b)\hat{y}_i = \sigma(w^T x_i + b)y^​i​=σ(wTxi​+b) is bounded between 000 and 111.

7. Common Mistakes​

  • 1. Believing Closed-Form Solutions Exist
  • 2. Using MSE with Sigmoidal Activations
  • 3. Neglecting Numerical Stability in Logarithms
  • 4. Forgetting to Scale Features Before Optimization
  • 5. Omitting Regularization on Separable Data

  • The Misconception: "We can compute optimal logistic regression weights directly using a matrix formula like (XTX)−1XTy(X^T X)^{-1} X^T y(XTX)−1XTy."
  • Wrong Thinking: Searching for an analytical closed-form solution.
  • The Right Principle: The non-linear sigmoid inside the log-likelihood makes the derivative non-linear in parameters. Numerical optimization (Gradient Descent, Newton-CG, or L-BFGS) is mathematically required.

  • The Misconception: "Minimizing Mean Squared Error ∑(y−σ(wTx+b))2\sum (y - \sigma(w^T x + b))^2∑(y−σ(wTx+b))2 should work just as well as log loss."
  • Wrong Thinking: Combining MSE with sigmoid activations for classification.
  • The Right Principle: MSE combined with a sigmoid creates a non-convex cost function full of saddle points and local minima. Furthermore, confident wrong predictions produce tiny gradients (vanishing gradient problem), stopping learning entirely.

  • The Misconception: "Computing −ln⁡(y^)-\ln(\hat{y})−ln(y^​) in Python directly is fine for all model outputs."
  • Wrong Thinking: Passing raw floating-point 0.0 or 1.0 to np.log().
  • The Right Principle: If y^=0.0\hat{y} = 0.0y^​=0.0, ln⁡(0)\ln(0)ln(0) evaluates to −∞-\infty−∞ or raises a ZeroDivisionError / RuntimeWarning. Production implementations must always clamp probabilities using an epsilon (y^∈[ϵ,1−ϵ]\hat{y} \in [\epsilon, 1 - \epsilon]y^​∈[ϵ,1−ϵ] with ϵ=10−15\epsilon = 10^{-15}ϵ=10−15).

  • The Misconception: "Logistic regression outputs probabilities, so raw feature scales do not matter."
  • Wrong Thinking: Training gradient descent on unscaled features (e.g. Age in [20,60][20, 60][20,60] vs. Income in [20000,150000][20000, 150000][20000,150000]).
  • The Right Principle: Unscaled features create distorted, elliptical loss contours, causing gradient descent to oscillate wildly and converge slowly. Always scale features via StandardScaler inside a Pipeline.

  • The Misconception: "If classes are perfectly linearly separable, logistic regression achieves 100% accuracy and zero loss."
  • Wrong Thinking: Fitting unregularized logistic regression to perfectly separable data.
  • The Right Principle: On perfectly separable data, unregularized maximum likelihood drives weights to ±∞\pm \infty±∞ to force σ(z)→1.0\sigma(z) \to 1.0σ(z)→1.0 and 0.00.00.0, causing numerical overflow. Always apply L2 regularization (C parameter in scikit-learn).

8. Summary​

Theoretical Foundations

  • Model Hypothesis: y^=σ(wTx+b)=11+e−(wTx+b)\hat{y} = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}y^​=σ(wTx+b)=1+e−(wTx+b)1​.
  • Cost Function: Binary Cross-Entropy J(w,b)=−1n∑[yln⁡y^+(1−y)ln⁡(1−y^)]J(w, b) = -\frac{1}{n} \sum [y \ln \hat{y} + (1-y) \ln(1-\hat{y})]J(w,b)=−n1​∑[ylny^​+(1−y)ln(1−y^​)].
  • Derivation: Derived directly from the log-likelihood of a Bernoulli distribution.
  • Convexity: Log loss is strictly convex with respect to linear weights, guaranteeing a single global minimum.

Optimization Realities

  • No Closed Form: Requires numerical optimization (Gradient Descent, L-BFGS, Newton-Raphson).
  • Gradient Equation: ∂J∂wj=1n∑(y^i−yi)xij\frac{\partial J}{\partial w_j} = \frac{1}{n} \sum (\hat{y}_i - y_i) x_{ij}∂wj​∂J​=n1​∑(y^​i​−yi​)xij​.
  • Loss Gradient Advantage: Steep gradients for confident mistakes prevent vanishing gradient stalls.
  • Feature Scaling: Standardize features to ensure isotropic circular contours for fast gradient descent.

info

Key Takeaways

  • Log Loss is MLE: Minimizing Binary Cross-Entropy is mathematically equivalent to maximizing the likelihood of observing the training data under a Bernoulli assumption.
  • Avoid MSE on Classification: MSE creates non-convex surfaces and vanishes when predictions are confidently incorrect.
  • Gradient Descent is Universal: The gradient update formula (y^−y)x(\hat{y} - y)x(y^​−y)x is shared between Linear and Logistic regression, providing seamless mathematical continuity.

Review Flashcards​

1. [THEORY] Why does minimizing Binary Cross-Entropy guarantee finding the global optimum?

  • Convexity: The negative log-likelihood function J(w,b)J(w, b)J(w,b) of logistic regression is strictly convex with respect to the weights www and bias bbb.
  • Its Hessian matrix ∇2J=1nXTDX\nabla^2 J = \frac{1}{n} X^T D X∇2J=n1​XTDX (where DDD is a diagonal matrix with entries y^i(1−y^i)>0\hat{y}_i(1 - \hat{y}_i) > 0y^​i​(1−y^​i​)>0) is positive semi-definite everywhere.
  • Because there are no local minima or saddle points, gradient descent is mathematically guaranteed to converge to the unique global minimum.
2. [MATH] Why does the sigmoid derivative cancel out when differentiating Binary Cross-Entropy?

  • Using the chain rule: ∂Ji∂z=∂Ji∂y^i⋅∂y^i∂z\frac{\partial J_i}{\partial z} = \frac{\partial J_i}{\partial \hat{y}_i} \cdot \frac{\partial \hat{y}_i}{\partial z}∂z∂Ji​​=∂y^​i​∂Ji​​⋅∂z∂y^​i​​
  • ∂Ji∂y^i=−yiy^i+1−yi1−y^i=y^i−yiy^i(1−y^i)\frac{\partial J_i}{\partial \hat{y}_i} = -\frac{y_i}{\hat{y}_i} + \frac{1 - y_i}{1 - \hat{y}_i} = \frac{\hat{y}_i - y_i}{\hat{y}_i(1 - \hat{y}_i)}∂y^​i​∂Ji​​=−y^​i​yi​​+1−y^​i​1−yi​​=y^​i​(1−y^​i​)y^​i​−yi​​.
  • ∂y^i∂z=σ′(z)=y^i(1−y^i)\frac{\partial \hat{y}_i}{\partial z} = \sigma'(z) = \hat{y}_i(1 - \hat{y}_i)∂z∂y^​i​​=σ′(z)=y^​i​(1−y^​i​).
  • Multiplying them together cancels the denominator y^i(1−y^i)\hat{y}_i(1 - \hat{y}_i)y^​i​(1−y^​i​) completely, leaving: ∂Ji∂z=y^i−yi\frac{\partial J_i}{\partial z} = \hat{y}_i - y_i∂z∂Ji​​=y^​i​−yi​
  • This cancellation eliminates the vanishing gradient problem.
3. [PRACTICE] What happens to logistic regression weights if the training classes are perfectly linearly separable and no regularization is applied?

  • Weight Explosion: If classes are perfectly separable, the model can achieve a log loss of zero only if y^i=1\hat{y}_i = 1y^​i​=1 for all positives and y^i=0\hat{y}_i = 0y^​i​=0 for all negatives.
  • Because σ(z)→1\sigma(z) \to 1σ(z)→1 only as z→+∞z \to +\inftyz→+∞ and σ(z)→0\sigma(z) \to 0σ(z)→0 only as z→−∞z \to -\inftyz→−∞, gradient descent continues increasing the magnitude of weights ∥w∥→∞\|w\| \to \infty∥w∥→∞.
  • The Remedy: Apply L2 weight regularization (e.g. C=1.0), which adds 12C∥w∥2\frac{1}{2C} \|w\|^22C1​∥w∥2 penalty to the cost function, preventing weights from growing unbounded.
4. [ANALYZE] If a model predicts probability ŷ = 0.99 for an actual positive sample, what is the log loss? What if ŷ = 0.50?

  • For y^=0.99\hat{y} = 0.99y^​=0.99: Loss =−ln⁡(0.99)≈0.010= -\ln(0.99) \approx 0.010=−ln(0.99)≈0.010. The penalty is virtually zero because the model is confident and correct.
  • For y^=0.50\hat{y} = 0.50y^​=0.50: Loss =−ln⁡(0.50)=ln⁡(2)≈0.693= -\ln(0.50) = \ln(2) \approx 0.693=−ln(0.50)=ln(2)≈0.693. A loss of ≈0.693\approx 0.693≈0.693 represents complete uncertainty (random coin flip guessing).
  • Baseline Benchmark: Any trained binary classification model that exhibits a mean log loss >0.693> 0.693>0.693 is performing worse than a trivial coin toss.
5. [PRACTICE] Why are second-order optimization algorithms like L-BFGS or Newton-CG often used instead of basic SGD for small-to-medium logistic regression?

  • Curvature Information: Second-order methods utilize the Hessian matrix (curvature of the loss surface).
  • Because logistic regression is strictly convex, Newton-Raphson steps jump directly toward the optimum without requiring manual learning rate tuning (α\alphaα).
  • For datasets with N≤100,000N \le 100,000N≤100,000, L-BFGS converges in 10−2010-2010−20 iterations, whereas basic SGD may require hundreds of epochs.
