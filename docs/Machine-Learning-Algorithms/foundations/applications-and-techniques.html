Applications and Major Techniques

Topic — Across all of artificial intelligence, machine learning performs about nine core techniques. Every industry application is either one of these nine or a combination of them. The essential skill of an ML engineer is translating a business question into its corresponding technique by inspecting the shape of the required output.

1. The Nine Techniques at a Glance​

The fastest way to identify the correct technique is to examine what shape the answer is:

tip

The Two-Question Decision Shortcut

  1. Do you have historical answers (labels)?
    • Yes: You are in Supervised Learning (Regression, Classification, or Sequence Mining).
    • No: You are in Unsupervised Learning (Clustering, Association, Anomaly Detection, or PCA).
  2. If labeled, is the answer a continuous number or a discrete name?
    • Continuous number:   ⟹  \implies⟹ Regression (where numeric proximity matters).
    • Discrete name / category:   ⟹  \implies⟹ Classification (where labels are distinct categories).

3. One Dataset, Five Techniques​

A frequent beginner misunderstanding is believing that datasets belong to a specific technique. In reality, the business question, not the data, picks the technique.

Consider a single retail customer table:

  • tenure_months: How many months they have been subscribed.
  • monthly_spend: Average dollar expenditure per month.
  • support_tickets: Number of help-desk calls logged.
  • churned: Ground-truth historical label (1=cancelled,0=retained1 = \text{cancelled}, 0 = \text{retained}1=cancelled,0=retained).

4. Key Distinctions & Boundary Traps​

  • 1. Classification vs. Regression
  • 2. Association vs. Recommendation
  • 3. Anomaly Detection vs. Classification

  • The Trap: "Our loan default model outputs 0.83, so it's regression."
  • The Principle: In loan prediction, 0.83 is the model's posterior confidence probability P(Default∣X)P(\text{Default} \mid X)P(Default∣X). The underlying ground truth is discrete ({0,1}\{0, 1\}{0,1}).
  • The Litmus Test: Does numeric proximity matter? If predicting 525252 for 505050 is partly right, it is Regression. If predicting Class B for Class A is completely wrong, it is Classification.

  • Association: Operates on items (Market Basket Analysis: "If a basket contains diapers, it contains beer with 60% confidence"). The shopper's identity is completely ignored.
  • Recommendation: Operates on people (Collaborative Filtering: "Because user Alex watched Interstellar and has similar watch histories to user Jordan, recommend Inception").

  • When to use Classification: When you possess balanced, confirmed labels for both normal and fraudulent events (>1%>1\%>1% frequency).
  • When to use Anomaly Detection: When fraudulent events are unlabelled, extremely rare (<0.1%<0.1\%<0.1%), or when future attacks look nothing like past attacks.

6. Common Mistakes​

  • 1. Confusing Output Format with Task Type
  • 2. Labeling Datasets Instead of Questions
  • 3. Assuming Shuffling Never Matters
  • 4. Association vs. Personalized Recommendations

  • The Misconception: "A probability output like 0.85 means the algorithm is performing regression."
  • Wrong Thinking: Judging a model by its mathematical floating-point format.
  • The Right Principle: Check the ground-truth target. If the target in your training table is a discrete class (defaulted vs paid), the task is Classification.

  • The Misconception: "This customer dataset is a classification dataset."
  • Wrong Thinking: Believing a dataset is locked to a single technique.
  • The Right Principle: Datasets are neutral containers. You can run Regression on monthly_spend, Classification on churned, and Clustering on unlabeled demographic features. The business question picks the technique.

  • The Misconception: "Shuffling dataset rows has no impact on model training."
  • Wrong Thinking: Treating all data as independent and identically distributed (i.i.d.).
  • The Right Principle: In Sequence Mining and time-series forecasting, temporal order carries the informational signal. Shuffling rows completely destroys the transition dynamics.

  • The Misconception: "Market basket analysis gives personalized product suggestions to users."
  • Wrong Thinking: Confusing co-occurrence with individual taste profiling.
  • The Right Principle: Association rules are global to the checkout basket ("If coffee, then sugar"). True recommendation systems require user interaction history to personalize suggestions.

7. Summary​

Supervised Paradigms

  • Regression: Continuous numeric targets (R\mathbb{R}R). Proximity matters (R2R^2R2, RMSE).
  • Classification: Discrete categorical targets. Exact class matching (ROC-AUC, F1).
  • Sequence Mining: Next item in temporal chain. Shuffling breaks signal.

Unsupervised Paradigms

  • Clustering: Groups similar unlabeled rows (KMeans, Silhouette).
  • Association: Co-occurring item rules in baskets (Support, Lift).
  • Anomaly Detection: Flags rare outliers (<0.1%<0.1\%<0.1%, IsolationForest).
  • Dimensionality Reduction: Projects wide feature spaces into 2D/3D (PCA).

info

Key Takeaways

  • Output Shape Dictates Technique: Always identify the technique by what the answer looks like (continuous number, discrete label, cluster ID, or ranked list).
  • Data Does Not Pick the Technique: A single customer dataset can simultaneously support regression, classification, clustering, anomaly detection, and PCA.
  • The 0.83 Probability Trap: Output probabilities express confidence in classification; they do not turn the problem into regression.

Review Flashcards​

1. [THEORY] How do you distinguish between Association Rules and Recommendation Systems?

  • Association: Learns global co-occurrence rules between items ("If coffee in basket, then sugar with 70% confidence"). The specific individual shopper is ignored.
  • Recommendation Systems: Builds personalized ranked lists tailored to people based on their unique individual history and taste similarity to other users.
2. [ANALYZE] Why did KMeans clustering identify the churned customers without ever seeing the churned labels?

  • Natural Behavioral Separation: The input features (tenure_months and support_tickets) had natural mathematical boundaries.
  • The churned customers had short tenure (<6<6<6 months) and high support calls (>4>4>4 tickets).
  • Because their feature vectors formed an isolated cluster in coordinate space, KMeans grouped them together purely from geometric proximity without needing a label!
3. [THEORY] Which machine learning technique becomes impossible if you shuffle the order of your dataset rows? Why?

  • Sequence Mining: (and time-series forecasting).
  • Why: In sequence mining, the temporal order of events carries the primary informational signal (e.g. click A→A \toA→ click B→B \toB→ purchase). Shuffling rows breaks the transition probabilities, making sequential modeling impossible.
4. [PRACTICE] In our customer lab, linear regression scored R2=0.651R^2 = 0.651R2=0.651 while Isolation Forest flagged exactly two rows. Explain the connection.

  • One technique's noise is another technique's answer: The linear regression model was dragged off its fit line by the two extreme spenders (666mo/$95 and 363636mo/$140), depressing R2R^2R2.
  • The exact same extreme spenders were identified by Isolation Forest as statistical outliers. Removing them would restore the linear regression R2R^2R2 to >0.90>0.90>0.90.
5. [THEORY] What does PCA mean when it reports that PC1 captures 75.0% and PC2 captures 22.9% of variance? What was sacrificed?

  • Preserved Variance: The first two principal components together retain 75.0%+22.9%=97.9%75.0\% + 22.9\% = \mathbf{97.9\%}75.0%+22.9%=97.9% of the original 3-dimensional data variance.
  • Sacrificed: We discarded 2.1%2.1\%2.1% of information (noise/minor variation) and sacrificed direct human interpretability, as PC1 and PC2 are abstract linear combinations of the original column names.
