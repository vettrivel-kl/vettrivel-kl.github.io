Overfitting, Underfitting, and Regularization

Topic — A machine learning model fits training data with 100% precision, yet fails catastrophically on unseen customer transactions: overfitting. Another model is so mathematically rigid that it misses real signals entirely: underfitting. Regularization introduces a mathematical constraint into the loss function to penalize excessive complexity. This guide explores the bias-variance tradeoff, contrasts L1 (Lasso), L2 (Ridge), and Elastic Net penalties, and details geometric constraint boundaries.

1. The Core Concept​

The fundamental objective of supervised learning is not resubstitution memorization, but out-of-sample generalization:

E(x,y)∼D[L(y,f^(x))]\mathbb{E}_{(x, y) \sim \mathcal{D}}\left[ \mathcal{L}(y, \hat{f}(x)) \right]E(x,y)∼D​[L(y,f^​(x))]

Every machine learning model balances two competing sources of error captured by the Bias-Variance Decomposition:

Total Expected Error=Bias[f^(x)]2+Var[f^(x)]+σ2\text{Total Expected Error} = \text{Bias}[\hat{f}(x)]^2 + \text{Var}[\hat{f}(x)] + \sigma^2Total Expected Error=Bias[f^​(x)]2+Var[f^​(x)]+σ2

  1. Bias (Underfitting): Error resulting from oversimplified mathematical assumptions. A linear model fitting quadratic data cannot capture true curvature.
  2. Variance (Overfitting): Error resulting from hypersensitivity to random fluctuations in the training set. A high-degree polynomial bends to pass through every noise point.
  3. Irreducible Error (σ2\sigma^2σ2): Intrinsic noise in the data collection process that no algorithm can eliminate.
tip

If you only take one thing from this page

Overfitting means your model has low bias but high variance (memorizing noise). Underfitting means your model has high bias but low variance (too rigid). Regularization adds a penalty term λ⋅Ω(w)\lambda \cdot \Omega(w)λ⋅Ω(w) to shrink weights toward zero, trading a tiny increase in training bias for a massive reduction in test variance.

5. Geometric Intuition: Why Lasso Yields Zeros​

Why does L1L_1L1​ regularization produce exact zeros (sparsity), while L2L_2L2​ regularization never does?

In constrained optimization (Lagrange form), regularized regression solves:

min⁡wLoss(w)subject toΩ(w)≤C\min_{\mathbf{w}} \text{Loss}(\mathbf{w}) \quad \text{subject to} \quad \Omega(\mathbf{w}) \le Cminw​Loss(w)subject toΩ(w)≤C

The optimal solution occurs at the point of tangency where the expanding unconstrained Loss Contours (ellipses) first touch the Regularization Constraint Region.

Why Lasso sets weights to zero: The diamond constraint has sharp vertices sitting directly on the coordinate axes ($(C, 0)$ and $(0, C)$). Because the corners protrude furthest, the expanding loss ellipse almost always makes initial contact at a sharp corner across a wide range of angles ($15°$ to $75°$). Touching a corner forces the orthogonal weight to be identically zero.

7. Common Mistakes​

  • 1. Regularizing the Intercept (Bias)
  • 2. Regularizing Without Feature Standardization
  • 3. Confusing Alpha and C Parameters
  • 4. Believing L2 Performs Feature Selection
  • 5. Assuming Zero Training Error Implies Perfection

  • The Misconception: "The regularization penalty should apply to all parameters including the intercept bbb."
  • Wrong Thinking: Adding λb2\lambda b^2λb2 to the cost function.
  • The Right Principle: The intercept represents the global base rate of the target. Penalizing bbb shifts predictions away from the target mean. Scikit-learn models (fit_intercept=True) never regularize the bias term.

  • The Misconception: "Regularization works identically regardless of whether features are scaled."
  • Wrong Thinking: Applying L1 or L2 penalties to unstandardized features.
  • The Right Principle: The penalty ∑wj2\sum w_j^2∑wj2​ treats all weights identically. Features with large scales naturally have tiny weights, escaping penalization, while features with tiny scales are penalized unfairly. Always standardize features with StandardScaler inside a Pipeline.

  • The Misconception: "Setting C=10 in Logistic Regression means strong regularization."
  • Wrong Thinking: Inverting the meaning of CCC and α\alphaα.
  • The Right Principle: In linear models (Ridge, Lasso), alpha (λ\lambdaλ) represents penalty strength (large α\alphaα = strong regularization). In LogisticRegression and SVC, C is the inverse penalty (C=1λC = \frac{1}{\lambda}C=λ1​). Large CCC means weak regularization!

  • The Misconception: "Ridge regression sets unimportant features to zero if alpha is large enough."
  • Wrong Thinking: Expecting L2 to produce sparse models.
  • The Right Principle: Because the L2 gradient λw\lambda wλw diminishes as w→0w \to 0w→0, L2 coefficients asymptotically approach zero but never reach it. Only L1 (Lasso) produces exact zeros.

  • The Misconception: "Our model achieved 100% training accuracy, so the algorithm is optimal."
  • Wrong Thinking: Evaluating model quality using resubstitution accuracy.
  • The Right Principle: Zero training error is the cardinal diagnostic signature of severe overfitting. True model quality is determined strictly by out-of-sample cross-validation error.

8. Summary​

Error Regimes

  • Underfitting (High Bias): Model too simple. Both training and test errors are high.
  • Overfitting (High Variance): Model too complex. Low training error, exploding test error.
  • The Sweet Spot: Optimal complexity minimizing total out-of-sample expected loss.
  • Regularization Role: Trades a small amount of training bias to massively reduce test variance.

Penalty Selection

  • L2 (Ridge): λ∥w∥22\lambda \|\mathbf{w}\|_2^2λ∥w∥22​. Proportional shrinkage. Retains all features. Tames multicollinearity.
  • L1 (Lasso): λ∥w∥1\lambda \|\mathbf{w}\|_1λ∥w∥1​. Constant shrinkage. Drives weights to exact zero. Sparse feature selection.
  • Elastic Net: Combines L1 and L2. Handles correlated feature clusters.
  • Standardization Mandate: Always scale features before regularized fitting.

info

Key Takeaways

  • Regularization controls variance: Without regularization, complex models memorize sample noise rather than population signal.
  • Corners create sparsity: The diamond geometry of L1 forces loss contours to touch on coordinate axes, performing automated feature selection.
  • Alpha vs C inversion: Never forget that in scikit-learn, alpha increases regularization, while C decreases regularization.

Review Flashcards​

1. [THEORY] Why does L1 regularization produce sparse models (exact zeros) while L2 regularization does not?

  • The Gradient Perspective:
    • L2 penalty is 12λw2\frac{1}{2} \lambda w^221​λw2. Its gradient is λw\lambda wλw. As w→0w \to 0w→0, the gradient diminishes proportionally to zero, shrinking weights slower and slower without reaching zero.
    • L1 penalty is λ∣w∣\lambda |w|λ∣w∣. Its subgradient is a constant ±λ\pm \lambda±λ regardless of magnitude. It continues pushing weights toward zero with full force until snapping to exact zero.
  • The Geometric Perspective: The L1L_1L1​ constraint region is a diamond with sharp corners on the coordinate axes. The unconstrained loss ellipses almost always touch the diamond at a corner where coordinates equal zero.
2. [MATH] In the Bias-Variance decomposition, what represents the theoretical lower bound on model error?

  • Irreducible Error (σ2\sigma^2σ2): E[(y−f^(x))2]=Bias2+Variance+σ2\mathbb{E}[(y - \hat{f}(x))^2] = \text{Bias}^2 + \text{Variance} + \sigma^2E[(y−f^​(x))2]=Bias2+Variance+σ2
  • Even an omniscient Bayes-optimal model with zero bias and infinite training data (zero variance) will still suffer an expected error of σ2\sigma^2σ2.
  • It represents unmeasured confounding variables, physical sensor limits, and intrinsic randomness.
3. [ANALYZE] When should you choose Elastic Net over standard Lasso (L1)?

  • Correlated Feature Groups: When features are strongly collinear (e.g. 10 gene markers that activate together), Lasso arbitrarily selects one and zeroes out the remaining 9. Elastic Net groups them and preserves their collective signal.
  • High Dimensions (p>np > np>n): In datasets where features exceed sample count, Lasso can select at most nnn non-zero features before saturating. Elastic Net can select all ppp features if necessary.
4. [PRACTICE] Why is feature scaling strictly mandatory before applying Ridge or Lasso regression?

  • Scale Asymmetry: The penalty term ∑wj2\sum w_j^2∑wj2​ or ∑∣wj∣\sum |w_j|∑∣wj​∣ does not know what units features are measured in.
  • If Feature 1 is Salary in rupees (10610^6106) and Feature 2 is Age in years (10110^1101), the OLS weight for Salary will naturally be tiny (10−610^{-6}10−6), while the weight for Age will be large (10010^0100).
  • Regularization will aggressively crush the Age weight while completely ignoring Salary! Standardizing with StandardScaler places all coefficients on a level playing field.
5. [THEORY] Why is the bias term (intercept b) excluded from the regularization penalty in scikit-learn?

  • Centering the Output: The intercept bbb captures the unconditional mean of the target variable E[y]\mathbb{E}[y]E[y] when all standardized features are zero.
  • Penalizing bbb toward zero would force the prediction line down toward the origin, destroying accuracy even if the slope is perfectly learned.
  • Regularization is designed to constrain feature interactions (slopes), not the global vertical baseline.
