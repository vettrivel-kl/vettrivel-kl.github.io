# Types of Learning

> **Topic —** The single most consequential architectural decision in machine learning is determined by one question: **Do you have target labels ($y$)?** The presence, absence, or scarcity of ground-truth labels determines your learning paradigm - supervised, unsupervised, semi-supervised, or self-supervised - and dictates which algorithms are mathematically valid.

---

<Heading as="h2" id="features-and-attributes">1. Feature Matrices vs. Target Vectors</Heading>

In machine learning, data is represented by an input matrix $X$ and an optional target vector $y$:

```text
              ┌──────────── Features (X) ────────────┐   ┌─ Target (y) ─┐
              Clump      Uniformity   Marginal            Diagnosis
              thickness  of cell size adhesion
    sample 1      5            1          1               benign
    sample 2      5            4          5               benign
    sample 3      3            1          1               malignant
```

| Mathematical Symbol | Industrial Term | Linear Algebra Shape | Description |
| :--- | :--- | :--- | :--- |
| **$X$** | **Feature Matrix** | 2-D: $(N \times d)$ | All measured predictor variables across $N$ samples and $d$ features. |
| **$y$** | **Target Vector** | 1-D: $(N,)$ | Ground-truth labels or continuous outcomes we wish to predict. |
| **Sample** | Row / Instance | 1-D: $(1 \times d)$ | A single observed entity (e.g. one patient or one transaction). |
| **Feature** | Attribute / Predictor | Column | One measured property of that entity. |

:::tip

**The Whole Paradigm Fork in One Question**

*   **Do you have a target column $y$ for all rows?** $\implies$ **Supervised Learning**.
*   **Do you have NO target column $y$?** $\implies$ **Unsupervised Learning**.
*   **Do you have a target column $y$ for only a small subset of rows?** $\implies$ **Semi-Supervised Learning**.

:::

<Heading as="h3" id="the-rule-worth-memorising">The Target Rule Worth Memorising</Heading>

When setting up your data architecture:

> The data used to make predictions - the **features ($X$)** - can be a mixture of numeric and categorical variables. But the output - the **target ($y$)** - alone dictates the technique: if $y$ is continuous numeric, it is **Regression**; if $y$ is categorical, it is **Classification**.

## 3. The Positive Class Convention in Binary Classification

In binary classification ($y \in \{0, 1\}$), the two classes are mathematically asymmetric:

*   **Positive Class ($1$):** The specific outcome you are **actively searching for** (e.g. presence of disease, fraudulent charge, spam email, customer cancellation).
*   **Negative Class ($0$):** The baseline, ordinary, default "nothing to report" state (e.g. healthy, legitimate, non-spam, retained).

:::danger

**The "Positive != Good" Trap and Library Defaults**

1.  **"Positive" has nothing to do with being socially or clinically good.** In medical oncology, having a malignant tumor is the *positive class* (a positive test result).
2.  **Scikit-Learn defaults to alphanumeric sorting.** In Scikit-Learn's built-in Breast Cancer dataset, label `1` is assigned to **`benign`** (healthy) because "benign" comes before "malignant" alphabetically.
3.  If you compute `recall_score()` without overriding `pos_label`, your model measures *how well it finds healthy patients*, completely missing the clinical question ("how well do we catch cancer?"). Always verify your label mapping.

:::

## 5. The Four Learning Paradigms in Depth

<Tabs>
  <TabItem value="sup" label="1. Supervised Learning" default>
    <br/>
    
    *   **Data Requirement:** Every single training row contains input features $X$ and ground-truth answer $y$.
    *   **The Workflow:** Fits mathematical weights by minimizing the residual loss between predicted $\hat{y}$ and true $y$.
    *   **Key Advantage:** Direct, objective validation on an isolated test set ($R^2$, Accuracy, ROC-AUC).
    *   **Core Branches:**
        1.  **Classification:** Target is categorical ($y \in \{\text{Cat}, \text{Dog}\}$).
        2.  **Regression:** Target is continuous ($y \in \mathbb{R}$).
  </TabItem>
  <TabItem value="unsup" label="2. Unsupervised Learning">
    <br/>
    
    *   **Data Requirement:** Contains only input features $X$. No target vector $y$ exists.
    *   **The Workflow:** Discovers geometric patterns, high-density manifolds, and clusters.
    *   **Core Families:**
        1.  **Clustering:** Grouping rows into unnamed clusters (`KMeans`, `DBSCAN`).
        2.  **Dimensionality Reduction:** Compressing wide feature spaces (`PCA`, `t-SNE`).
        3.  **Density Estimation:** Modeling the probability density $P(X)$ to flag anomalies.
    *   **Evaluation Challenge:** Has no objective accuracy. Groupings require domain expert sign-off.
  </TabItem>
  <TabItem value="semi" label="3. Semi-Supervised Learning">
    <br/>
    
    *   **Data Requirement:** A small subset of labeled data $L$ combined with a massive pool of unlabeled data $U$.
    *   **The Self-Training Loop:**
        1. Train a model on the small labeled set $L$.
        2. Predict on the unlabeled set $U$.
        3. Select the most confident predictions and pseudo-label them.
        4. Retrain on the expanded dataset and repeat.
    *   **The Cluster Assumption:** Assumes data points close to each other in feature space share the same class label. If this fails, self-training amplifies its own errors!
  </TabItem>
  <TabItem value="self" label="4. Self-Supervised Learning (SSL)">
    <br/>
    
    *   **The Modern Paradigm:** The foundation of modern Large Language Models (LLMs) and vision transformers.
    *   **Mechanism (The Data is its own Label):**
        *   **Masked Modeling (e.g. BERT):** Hides tokens in sentences and trains the network to predict the masked word.
        *   **Autoregressive Generation (e.g. GPT):** Predicts the next token in sequence.
    *   **Representational Learning:** Produces high-dimensional embeddings that are subsequently fine-tuned with a tiny supervised dataset.
  </TabItem>
</Tabs>

## 7. Common Mistakes

<Tabs>
  <TabItem value="m1" label="1. Believing Positive Means Good" default>
    <br/>
    
    *   **The Misconception:** *"The positive class in binary classification represents the desirable medical or business outcome."*
    *   **Wrong Thinking:** Designating healthy patients as the positive class.
    *   **The Right Principle:** The **positive class** is the target condition you are actively seeking to detect (cancer, fraud, churn). It is named after a *positive test result*, not moral or medical goodness.
  </TabItem>
  <TabItem value="m2" label="2. Integer Encoding Nominal Categories">
    <br/>
    
    *   **The Misconception:** *"We can encode colors as Red=0, Green=1, Blue=2 for linear regression."*
    *   **Wrong Thinking:** Imposing false ordinal relationships on nominal categories.
    *   **The Right Principle:** Only **Ordinal** variables (Low/Med/High) possess a natural rank. Nominal variables must be One-Hot encoded; otherwise, models assume Blue is twice as large as Green!
  </TabItem>
  <TabItem value="m3" label="3. Measuring Accuracy on Unsupervised Clusters">
    <br/>
    
    *   **The Misconception:** *"Our KMeans clustering model achieved 91% accuracy."*
    *   **Wrong Thinking:** Comparing arbitrary cluster IDs ($0, 1$) directly to true classes with standard classification accuracy.
    *   **The Right Principle:** Clustering has no predefined ground-truth labels. Cluster numbers are arbitrary. Use the **Adjusted Rand Index (ARI)** to evaluate pair-wise clustering alignment while correcting for random chance.
  </TabItem>
  <TabItem value="m4" label="4. Semi-Supervised Learning is Free Accuracy">
    <br/>
    
    *   **The Misconception:** *"Adding unlabeled data to our training set will always improve model score."*
    *   **Wrong Thinking:** Expecting self-training to consistently lift performance.
    *   **The Right Principle:** Semi-supervised learning only succeeds when data conforms to the **cluster assumption**. If early pseudo-labels are incorrect, self-training reinforces its own errors and actively degrades accuracy.
  </TabItem>
</Tabs>

**Key Takeaways**

*   **Target Alone Decides:** Features ($X$) can be a mixture of numeric and categorical data; the target variable ($y$) alone dictates whether the problem is Classification or Regression.
*   **Watch pos_label:** Scikit-Learn defaults to alphabetical label ordering, which frequently maps the negative class to 1. Always set `pos_label` explicitly.
*   **Clustering != Classification:** Clustering proposes unnamed geometric segments; it cannot be evaluated using classification accuracy.

    *   **The Inverted Evaluation:** Scikit-Learn treats label `1` as the default positive class.
    *   Calling `recall_score(y_test, y_pred)` evaluates the model's ability to find **healthy (benign) patients**!
    *   A high score ($96\%$) gives false confidence, while the critical life-or-death clinical question ("how many malignant tumors were caught?") remains completely unmeasured. Always specify `pos_label=0` or re-map labels.
  </div>
</details>

<details>
  <summary><b>3. [THEORY] What is the "cluster assumption" in semi-supervised learning, and what happens when it fails?</b></summary>
  <div className="answer-content">
    <br/>
    
    *   **The Cluster Assumption:** Assumes that data points lying close together in feature space or within the same high-density cluster share the same class label.
    *   **Failure Consequence:** If classes overlap or clusters do not align with target boundaries, self-training assigns pseudo-labels to incorrect points with high confidence, amplifying errors and producing accuracy *worse* than trained on the small labeled set alone.
  </div>
</details>

<details>
  <summary><b>4. [MATH] Why is standard accuracy misleading when evaluating KMeans clustering, and what metric should be used instead?</b></summary>
  <div className="answer-content">
    <br/>
    
    *   **Arbitrary Indexing & Chance Agreement:** Clustering assigns arbitrary IDs (Cluster 0, Cluster 1) with no concept of ground-truth names. Standard accuracy does not account for label permutation or random alignment.
    *   **The Solution:** Use the **Adjusted Rand Index (ARI)**. ARI evaluates whether pairs of samples are placed in the same or different clusters and corrects for chance agreement, ensuring random clustering scores exactly `0.0`.
  </div>
</details>

<details>
  <summary><b>5. [THEORY] How does Self-Supervised Learning (SSL) differ from traditional Unsupervised Learning?</b></summary>
  <div className="answer-content">
    <br/>
    
    *   **Unsupervised Learning:** Seeks to discover flat geometric clusters (KMeans) or low-dimensional projections (PCA) directly from raw features without predictive supervision.
    *   **Self-Supervised Learning:** Automatically constructs predictive pretext tasks from the data itself (e.g. masking words in BERT or predicting the next token in GPT). It trains via supervised backpropagation against internal data structure to learn deep universal representations.
  </div>
</details>
