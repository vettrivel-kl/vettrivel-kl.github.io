# Expressions and Operators

> **Topic —** An expression is any valid combination of values, variables, and operators that Python evaluates to produce a result. While arithmetic symbols look familiar from primary school mathematics, Python's runtime introduces critical computational nuances: **division (`/`) always returns a float**, **floor division (`//`) rounds toward negative infinity**, and **exponentiation (`**`) evaluates right-to-left**. This guide details operator mechanics, order of operations, and five ways to structure the same calculation.

---

## 1. The Core Concept

Python divides arithmetic into seven core operations:

| Operator | Mathematical Name | Expression | Result | Return Type | Operational Behavior |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `+` | Addition | `15 + 25` | `40` | `int` | Sum of operands |
| `-` | Subtraction | `30 - 10` | `20` | `int` | Difference of operands |
| `*` | Multiplication | `10 * 6` | `60` | `int` | Product / repeated scaling |
| `/` | True Division | `30 / 5` | `6.0` | **`float`** | **Always produces a float**, even on exact division |
| `//` | Floor Division | `23 // 5` | `4` | `int` | Rounds toward negative infinity |
| `%` | Modulo | `25 % 4` | `1` | `int` | Remainder of division |
| `**` | Exponentiation | `2 ** 5` | `32` | `int` | Power / repeated multiplication |

:::tip

**If you only take one thing from this page**

In Python 3, single slash **`/` is True Division** and **always returns a `float`** (`10 / 2` evaluates to `5.0`, not `5`). Double slash **`//` is Floor Division** and rounds down toward $-\infty$. Exponentiation **`**` evaluates right-to-left** (`2 ** 3 ** 2 == 512`, not $64$).

:::

## 3. Order of Precedence (PEMDAS Hierarchy)

When an expression contains multiple operators, Python resolves them according to a strict binding hierarchy:

| Level | Operator Category | Operators | Associativity |
| :--- | :--- | :--- | :--- |
| **1 (Highest)** | Parentheses | `( )` | Innermost first |
| **2** | Exponentiation | `**` | **Right-to-Left** |
| **3** | Unary signs | `+x`, `-x`, `~x` | Right-to-Left |
| **4** | Multiplicative | `*`, `/`, `//`, `%` | Left-to-Right |
| **5** | Additive | `+`, `-` | Left-to-Right |
| **6** | Bitwise Shifts | `<<`, `>>` | Left-to-Right |
| **7** | Bitwise AND / OR | `&`, `^`, `\|` | Left-to-Right |
| **8** | Comparisons & Identity | `==`, `!=`, `<`, `<=`, `>`, `>=`, `is`, `in` | Chained |
| **9** | Boolean NOT | `not` | Right-to-Left |
| **10** | Boolean AND | `and` | Left-to-Right |
| **11 (Lowest)** | Boolean OR | `or` | Left-to-Right |

:::info

**The Exponentiation Associativity Exception**

Every binary arithmetic operator (`+`, `-`, `*`, `/`, `//`, `%`) is **left-associative** ($a - b - c$ is evaluated as $(a - b) - c$).

The only exception is **`**` (Exponentiation)**, which is **right-associative**:

$$2^{3^2} = 2^{(3^2)} = 2^9 = 512$$

If you intend $(2^3)^2 = 8^2 = 64$, you must explicitly add parentheses: `(2 ** 3) ** 2`.

:::

## 4. Five Ways to Structure the Same Calculation

Consider calculating the average of three exam scores ($85, 90, 92$):

<Tabs>
  <TabItem value="inline" label="1. Direct Inline Expression" default>
    <br/>
    
    ```python
    # Parentheses strictly required to prevent / from dividing only 92!
    average = (85 + 90 + 92) / 3
    print(f"Average: {average:.2f}")  # 89.00
    ```
    *   **Pros:** Compact one-liner.
    *   **Cons:** Hardcoded values; not reusable.
  </TabItem>
  <TabItem value="variables" label="2. Intermediate Variables">
    <br/>
    
    ```python
    score1, score2, score3 = 85, 90, 92
    total = score1 + score2 + score3
    count = 3
    average = total / count
    print(f"Average: {average:.2f}")
    ```
    *   **Pros:** Self-documenting; easier to debug and step through.
  </TabItem>
  <TabItem value="collection" label="3. Collection Aggregation">
    <br/>
    
    ```python
    scores = [85, 90, 92]
    average = sum(scores) / len(scores)
    print(f"Average: {average:.2f}")
    ```
    *   **Pros:** Scales automatically to any number of scores without changing code.
  </TabItem>
  <TabItem value="function" label="4. Reusable Function">
    <br/>
    
    ```python
    def calculate_average(values: list[float]) -> float:
        if not values:
            return 0.0
        return sum(values) / len(values)

    print(calculate_average([85, 90, 92]))
    ```
    *   **Pros:** Encapsulates business logic with zero-division guardrails.
  </TabItem>
  <TabItem value="dataclass" label="5. Structured Class">
    <br/>
    
    ```python
    from dataclasses import dataclass

    @dataclass
    class StudentRecord:
        name: str
        scores: list[float]

        @property
        def average(self) -> float:
            return sum(self.scores) / len(self.scores) if self.scores else 0.0

    student = StudentRecord("Vettri", [85, 90, 92])
    print(f"{student.name}: {student.average:.2f}")
    ```
    *   **Pros:** Production enterprise architecture binding data to behaviors.
  </TabItem>
</Tabs>

## 6. Common Mistakes

<Tabs>
  <TabItem value="m1" label="🚨 1. Ignoring Precedence in Divisions" default>
    <br/>
    
    *   **The Misconception:** *"Writing `a + b + c / 3` computes the average of three numbers."*
    *   **❌ Wrong Thinking:** Assuming addition happens left-to-right before division.
    *   **✅ The Right Principle:** Division `/` has higher precedence than addition. Python evaluates `a + b + (c / 3)`. You must wrap the sum in parentheses: `(a + b + c) / 3`.
  </TabItem>
  <TabItem value="m2" label="🚨 2. Assuming // Truncates Toward Zero">
    <br/>
    
    *   **The Misconception:** *"Floor division `//` just chops off the decimal part."*
    *   **❌ Wrong Thinking:** Expecting `-10 // 3` to equal `-3`.
    *   **✅ The Right Principle:** `//` rounds down toward **negative infinity** ($\lfloor x \rfloor$). Since $-10 / 3 = -3.333$, rounding down yields **`-4`**. To truncate toward zero, use `int(-10 / 3)`.
  </TabItem>
  <TabItem value="m3" label="🚨 3. Misreading Modulo % as Percentage">
    <br/>
    
    *   **The Misconception:** *"Calling `25 % 4` gives 25% of 4 (1.0)."*
    *   **❌ Wrong Thinking:** Confusing the mathematical modulo operator with percentage calculation.
    *   **✅ The Right Principle:** `%` returns the integer remainder after division ($25 = 4 \times 6 + 1 \implies 1$). To compute percentages, multiply the ratio by 100: `(num / total) * 100`.
  </TabItem>
  <TabItem value="m4" label="🚨 4. Assuming ** is Left-Associative">
    <br/>
    
    *   **The Misconception:** *"2 ** 3 ** 2 evaluates as (2 ** 3) ** 2 = 64."*
    *   **❌ Wrong Thinking:** Reading chained powers left to right.
    *   **✅ The Right Principle:** `**` is right-associative: $2^{(3^2)} = 2^9 = 512$. Use explicit parentheses if you desire left-to-right evaluation.
  </TabItem>
  <TabItem value="m5" label="🚨 5. Implicit String and Integer Addition">
    <br/>
    
    *   **The Misconception:** *"'5' + 5 will evaluate to '55' or 10."*
    *   **❌ Wrong Thinking:** Expecting JavaScript-style type coercion.
    *   **✅ The Right Principle:** Python is strictly typed. Adding string and integer raises `TypeError: can only concatenate str (not "int") to str`. Cast explicitly: `int('5') + 5` $\implies 10$ or `'5' + str(5)` $\implies '55'$.
  </TabItem>
</Tabs>

  <summary>❓ <b>1. [THEORY] Why does Python evaluate `-10 // 3` as `-4` rather than `-3`?</b></summary>
  <div className="answer-content">
    <br/>
    
    *   **Floor Function Definition:** In mathematics and Python, floor division is defined by the mathematical floor operator:
        $$\lfloor x \rfloor = \max \{ m \in \mathbb{Z} \mid m \le x \}$$
    *   Exact quotient: $-10 / 3 = -3.3333\dots$
    *   The largest integer less than or equal to $-3.3333\dots$ is **`-4`**.
    *   Many languages (C/Java) truncate toward zero (yielding `-3`), but Python strictly floors toward negative infinity.
  </div>
</details>

<details>
  <summary>❓ <b>2. [MATH] What is the exact output of `print(2 + 3 * 4 ** 2 - 6 / 3)`? Trace step by step.</b></summary>
  <div className="answer-content">
    <br/>
    
    1.  **Exponentiation:** $4^2 = 16$. Expression becomes: $2 + 3 \times 16 - 6 / 3$.
    2.  **Multiplication & Division:**
        *   $3 \times 16 = 48$
        *   $6 / 3 = 2.0$ (Division produces float!)
        *   Expression becomes: $2 + 48 - 2.0$.
    3.  **Addition & Subtraction (Left-to-Right):**
        *   $2 + 48 = 50$
        *   $50 - 2.0 = \mathbf{48.0}$ (Float due to division operand).
  </div>
</details>

<details>
  <summary>❓ <b>3. [PRACTICE] How do you convert 127 minutes into hours and remaining minutes in two lines of code?</b></summary>
  <div className="answer-content">
    <br/>
    
    ```python
    total_minutes = 127
    hours = total_minutes // 60      # 2 hours (whole units)
    minutes = total_minutes % 60     # 7 minutes (remainder)
    print(f"{hours}h {minutes}m")    # 2h 7m
    ```
    *   Alternatively, use Python's built-in `divmod`:
    ```python
    hours, minutes = divmod(127, 60) # (2, 7)
    ```
  </div>
</details>

<details>
  <summary>❓ <b>4. [ANALYZE] What happens when evaluating `5 > 3 and 2 > 4 or not False`? Trace precedence.</b></summary>
  <div className="answer-content">
    <br/>
    
    1.  **Relational Comparisons:**
        *   `5 > 3` $\implies \text{True}$
        *   `2 > 4` $\implies \text{False}$
        *   Expression: `True and False or not False`.
    2.  **Boolean `not`:** `not False` $\implies \text{True}$.
        *   Expression: `True and False or True`.
    3.  **Boolean `and`:** `True and False` $\implies \text{False}$.
        *   Expression: `False or True`.
    4.  **Boolean `or`:** `False or True` $\implies \mathbf{\text{True}}$.
  </div>
</details>

<details>
  <summary>❓ <b>5. [THEORY] What is the difference between `=` (assignment), `==` (equality), and `is` (identity)?</b></summary>
  <div className="answer-content">
    <br/>
    
    *   `=` **Assignment:** Binds a variable name to an object on the heap (`x = [1, 2]`).
    *   `==` **Equality:** Checks whether two objects hold the same values/contents (`[1, 2] == [1, 2]` is `True`).
    *   `is` **Identity:** Checks whether two variables reference the exact same object at the same memory address (`[1, 2] is [1, 2]` is `False`).
  </div>
</details>
