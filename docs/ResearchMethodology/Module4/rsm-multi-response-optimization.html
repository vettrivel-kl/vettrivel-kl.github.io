RSM: Multi-Response Optimization (MRO)

Topic - In complex industrial systems, optimizing a single process response in isolation is often counter-productive. Improving throughput or chemical yield frequently degrades surface roughness, accelerates machine wear, or elevates operational costs. Multi-Response Optimization (MRO) uses the Derringer-Suich Desirability Function to simultaneously balance multiple competing outputs into a single composite metric.

1. The Multi-Response Dilemma​

When analyzing a system with multiple dependent variables (Y1,Y2,…,YmY_1, Y_2, \dots, Y_mY1​,Y2​,…,Ym​):

  • Single-Response RSM: Maps inputs directly to a single scalar: (X1,X2)⟶Y(X_1, X_2) \longrightarrow Y(X1​,X2​)⟶Y
  • Multi-Response RSM: Simultaneously maps inputs to an array of competing criteria: (X1,X2)⟶{Y1 (maximize yield)Y2 (minimize roughness)Y3 (target thickness)⟶Composite Desirability D(X_1, X_2) \longrightarrow \begin{cases} Y_1 \text{ (maximize yield)} \\ Y_2 \text{ (minimize roughness)} \\ Y_3 \text{ (target thickness)} \end{cases} \longrightarrow \text{Composite Desirability } D(X1​,X2​)⟶⎩⎨⎧​Y1​ (maximize yield)Y2​ (minimize roughness)Y3​ (target thickness)​⟶Composite Desirability D

2. The Desirability Function Approach​

The desirability methodology converts each physical response YiY_iYi​ with different physical units (e.g., %\%%, μm\mu\text{m}μm, MPa\text{MPa}MPa) into a dimensionless scale bounded strictly between 000 and 111:

  • di=0  ⟹  d_i = 0 \impliesdi​=0⟹ Completely undesirable outcome (unacceptable defect).
  • di=1  ⟹  d_i = 1 \impliesdi​=1⟹ Fully desirable or ideal target performance.

Linear Desirability Formulations​

When linear transitions between acceptable boundaries are assumed:

1. Larger-the-Better Response (e.g., Yield, Hardness)​

Given lower threshold Ymin⁡Y_{\min}Ymin​ and upper ideal target Ymax⁡Y_{\max}Ymax​:

dY=Y−Ymin⁡Ymax⁡−Ymin⁡d_Y = \frac{Y - Y_{\min}}{Y_{\max} - Y_{\min}}dY​=Ymax​−Ymin​Y−Ymin​​
  • If Y≤Ymin⁡Y \le Y_{\min}Y≤Ymin​, then dY=0d_Y = 0dY​=0.
  • If Y≥Ymax⁡Y \ge Y_{\max}Y≥Ymax​, then dY=1d_Y = 1dY​=1.

2. Smaller-the-Better Response (e.g., Roughness, Defects)​

Given lower ideal target Rmin⁡R_{\min}Rmin​ and upper intolerable threshold Rmax⁡R_{\max}Rmax​:

dR=Rmax⁡−RRmax⁡−Rmin⁡d_R = \frac{R_{\max} - R}{R_{\max} - R_{\min}}dR​=Rmax​−Rmin​Rmax​−R​
  • If R≤Rmin⁡R \le R_{\min}R≤Rmin​, then dR=1d_R = 1dR​=1.
  • If R≥Rmax⁡R \ge R_{\max}R≥Rmax​, then dR=0d_R = 0dR​=0.

3. The Overall Composite Desirability (DDD)​

To evaluate the overall system performance across all kkk responses, the individual desirability scores are combined using the geometric mean:

D=(d1×d2×⋯×dk)1k=(∏i=1kdi)1k\boxed{D = \left( d_1 \times d_2 \times \dots \times d_k \right)^{\frac{1}{k}} = \left(\prod_{i=1}^k d_i\right)^{\frac{1}{k}}}D=(d1​×d2​×⋯×dk​)k1​=(i=1∏k​di​)k1​​

Or, when responses carry different priority weights (wiw_iwi​):

D=(d1w1×d2w2×⋯×dkwk)1∑wiD = \left( d_1^{w_1} \times d_2^{w_2} \times \dots \times d_k^{w_k} \right)^{\frac{1}{\sum w_i}}D=(d1w1​​×d2w2​​×⋯×dkwk​​)∑wi​1​

The Zero-Product Rule of Desirability

The geometric mean possesses a strict mathematical safeguard: dj=0  ⟹  D=0d_j = 0 \implies D = 0dj​=0⟹D=0 If even a single response violates specifications (dj=0d_j = 0dj​=0), the overall composite desirability collapses to zero regardless of how exceptional the other responses are.

5. Exam Traps & Operational Nuances​

  • 1. The Arithmetic Average Error
  • 2. Misinterpreting Unconstrained Optima

  • The Trap: Averaging desirability scores with an arithmetic mean: dˉ=d1+d22\bar{d} = \frac{d_1 + d_2}{2}dˉ=2d1​+d2​​.
  • The Consequence: If d1=1.0d_1 = 1.0d1​=1.0 (perfect yield) and d2=0.0d_2 = 0.0d2​=0.0 (totally defective roughness), the arithmetic average is 0.500.500.50 (acceptable!). In reality, the product is defective scrap. The geometric mean correctly yields D=1.0×0.0=0.00D = \sqrt{1.0 \times 0.0} = 0.00D=1.0×0.0​=0.00.

  • The Trap: Optimizing each response's regression polynomial separately and attempting to superimpose the optimum setpoints.
  • The Reality: The individual optimum of Response 1 rarely coincides with Response 2. Multi-response optimization must be conducted simultaneously on the composite objective function D(x)D(\mathbf{x})D(x) over the shared factor space.

Key Takeaways

  • Simultaneous Trade-Off: Multi-Response Optimization systematically resolves competing operational criteria that single-response RSM cannot handle.
  • Scale Invariance: Converting physical outputs to dimensionless desirability values (000 to 111) allows apples-to-oranges aggregation of yields, tolerances, and costs.
  • Zero Defect Guarantee: The geometric mean prevents any individual critical parameter violation from being hidden by superior performance elsewhere.
