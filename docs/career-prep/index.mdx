# Continuous Full-Stack Career Preparation


## Strategic Approach

This roadmap is designed for a senior engineer balancing full-time professional responsibilities with an **M.Tech in AI & Data Science**. Because your weekends are occupied with alternating online and offline classes, this plan abandons strict timelines (like a "1-year limit") in favor of **consistent, continuous progress**.

The preparation runs across two parallel tracks:
*   **Track A (The Micro):** Data Structures, Algorithms, Low-Level Design (LLD), Object-Oriented Design (OOD), and Core Language constraints (Java, JavaScript, React).
*   **Track B (The Macro):** High-Level Design (HLD), Distributed Systems, Databases, Cloud Architecture, and Domain Expertise.

**Sustainable Routine (Weekday Focus):**
*   **Target:** 4–6 hours per week total.
*   **Mon–Fri:** Aim for 3 or 4 weekday sessions of 1 to 1.5 hours (e.g., mornings before work or evenings). 
*   **Weekends:** Prioritize your M.Tech classes and rest. Do not force heavy prep blocks on weekends.
*   **Pacing:** Progress is measured in *Sprints*, not calendar weeks. If a Sprint takes 2 or 3 weeks to complete due to work or class load, that is perfectly fine. Consistency > Speed.

## Curriculum Phases

Navigate directly to each phase's tracking board:

### [Phase 1: Foundations (Sprints 1-12)](./milestones/01-phase-1-foundation.mdx)
*Focus: Coding muscle memory, Core JS/Java, RDBMS, and Web Architecture.*
*   Stage 1: Arrays, Hashing, Two Pointers, TCP/IP, DNS, SQL Basics.
*   Stage 2: Linked Lists, Stacks, Queues, Indexes, Query Plans, Transactions.
*   Stage 3: Binary Search, Trees, React Fundamentals, Buffer Catch-up.

### [Phase 2: Mid-Level Complexity (Sprints 13-24)](./milestones/02-phase-2-mid-level.mdx)
*Focus: Graphs, Heaps, Design Patterns, NoSQL, and Caching.*
*   Stage 4: Graphs (BFS/DFS, Topo Sort), SOLID, NoSQL (Redis, Mongo, DynamoDB).
*   Stage 5: Heaps, Tries, Backtracking, Caching Strategies, CDNs, Load Balancing.
*   Stage 6: 1D Dynamic Programming, LLD Case Studies, Capacity Math, Buffer Catch-up.

### [Phase 3: Advanced Topics & Distributed Systems (Sprints 25-36)](./milestones/03-phase-3-advanced.mdx)
*Focus: 2D DP, Distributed Systems, Concurrency, and Event-Driven Architecture.*
*   Stage 7: 2D DP, Dijkstra, Java Concurrency, CAP Theorem, Replication, Sharding.
*   Stage 8: Advanced React, Spring Boot Internals, Kafka, Event-Driven Architecture, Saga.
*   Stage 9: JVM Internals, Spring Security, Machine Coding, Advanced HLD Problems.

### [Phase 4: Execution & Mock Loops (Sprints 37-48)](./milestones/04-phase-4-execution.mdx)
*Focus: Frontend System Design, Cloud/DevOps, Behavioral, and Comprehensive Mocks.*
*   Stage 10: Frontend System Design, Web Vitals, Docker, Kubernetes, AWS Core.
*   Stage 11: Behavioral Stories (STAR), Resume Deep Dives, Targeted Mocks.
*   Stage 12: Full Mock Loop Simulations, CS Fundamentals Review, Final Polish.
