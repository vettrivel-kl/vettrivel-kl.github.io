## Core Problem-Solving Method

When approaching any coding career question, follow this 10-step protocol:

1. **Understand:** Read carefully and rephrase the problem in your own words.
2. **Clarify:** Clarify constraints, input ranges, empty inputs, and expected edge cases.
3. **Brute Force:** State the naive brute-force approach and its complexity.
4. **Identify Pattern:** Map the problem to established patterns (Two Pointers, Sliding Window, Monotonic Stack, Topo Sort, etc.).
5. **Optimize:** Design the optimal algorithm and state its target time and space complexity before writing code.
6. **Dry Run:** Walk through an example trace on a whiteboard or scratchpad.
7. **Implement:** Write clean, modular, and idiomatic code with clear variable names.
8. **Test:** Trace through standard cases, edge cases (empty, single element, negative numbers), and boundary conditions.
9. **Analyze:** Confirm final Big-O time and auxiliary space complexity.
10. **Refactor:** Clean up any redundancy before final submission.
