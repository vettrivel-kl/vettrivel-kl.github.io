01. Intuition & Concept Contrast

Python treats everything as an object in memory. Understanding the distinction between mutable references and immutable values is critical for algorithm safety and memory optimization.

Memory Behavior

Mutable vs Immutable Objects

Mutable Objects (`list`, `dict`, `set`): State can be changed in place without changing memory address (`id()`). Unhashable; cannot be used as dictionary keys.

Immutable Objects (`int`, `float`, `str`, `tuple`): State cannot be modified once instantiated. Any alteration spawns a brand-new object at a new memory address. Hashable.

Data Manipulation

Python Loops vs Vectorized Pandas

Standard Python Loops: Iterates row by row in bytecode; slow for large datasets ($O(n)$ with high interpreter overhead).

Vectorized Pandas/NumPy: Operates on contiguous memory blocks compiled in C; orders of magnitude faster.

02. Mutability & Memory Identity Proof

Nov 2025 (Q1.a) & May 2025 (Q1.i) Core 5-10 Mark Question.

1. Is String a Mutable Data Type?

No, strings in Python are strictly immutable. Attempting in-place item assignment (`s[0] = 'H'`) raises a `TypeError: 'str' object does not support item assignment`.

2. Empirical Code Demonstration for Exam Booklet:

# Mutable Demonstration (List)
numbers = [1, 2, 3]
addr_before = id(numbers)
numbers.append(4)  # Modifies in-place
print(id(numbers) == addr_before)  # True: Memory address remains identical!

# Immutable Demonstration (String)
message = "Hello"
addr_initial = id(message)
message += " World"  # Spawns a brand-new string object
print(id(message) != addr_initial)  # True: Memory address changed!

3. Recursive Factorial Formulation:

$$n! = \begin{cases} 1, & \text{if } n \in \{0, 1\} \quad (\text{Base Case}) \\ n \times (n - 1)!, & \text{if } n > 1 \quad (\text{Recursive Step}) \end{cases}$$ 
def factorial(n: int) -> int:
    """Computes factorial of non-negative integer using recursion."""
    if n < 0:
        raise ValueError("Factorial is undefined for negative integers.")
    if n in (0, 1):
        return 1
    return n * factorial(n - 1)

07. 6 Deadly Exam Traps & Common Student Mistakes

Trap 01: In-Place Mutation of Strings

Writing `s[0] = 'H'`

Strings are immutable in Python. Writing `s[0] = 'H'` raises a `TypeError`. You must create a new slice: `s = 'H' + s[1:]`.

Trap 02: Forgetting Inplace in Pandas

Writing `df.dropna()` Without Saving Result

`df.dropna()` returns a copy by default. You must write `df = df.dropna()` or `df.dropna(inplace=True)`.

Trap 03: Negative Number Factorial

Missing $n < 0$ Guard in Recursion

If a student passes negative numbers, unprotected factorial recurses infinitely until `RecursionError: maximum recursion depth exceeded`. Always raise `ValueError` for $n < 0$.

Trap 04: Strict Inequality Filter

Confusing `> 10000` with `>= 10000`

In May 2025, Laptop has total sales of exactly $10,000$. Strict inequality `> 10000` returns zero rows; `>= 10000` includes Laptop. Explicitly point out this distinction to the examiner.

Trap 05: Categorical vs Numerical Misclassification

Treating `Product_ID` as Numerical

Even though an ID contains numbers, mathematical operations (mean, sum) are meaningless on it. `Product_ID` is **Categorical / Nominal**, not numerical.

Trap 06: Missing Axis Labels in Plotting

Drawing Plots Without Labels

Examiners automatically deduct 3 to 4 marks if `xlabel`, `ylabel`, and `title` are omitted from Matplotlib code.

10. Active Recall Self-Test Quiz

Answer the questions below to evaluate progress (0/4 answered).
1. What happens if you execute `s = "Hello"; s[0] = "h"` in Python?
Correct: (b) Strings in Python are strictly immutable; characters cannot be reassigned in place.
2. Which built-in function reveals the unique memory address identity of a Python object?
Correct: (c) `id(obj)` returns the integer memory address of the object in CPython.
3. In Pandas, what is the default behavior of `df.dropna()` if `inplace=True` is omitted?
Correct: (b) By default, `dropna()` returns a copy. To modify in place, pass `inplace=True` or reassign `df = df.dropna()`.
4. Why is a column like `Product_ID` (e.g. "P001", "P002") classified as categorical rather than numerical?
Correct: (c) IDs are categorical identifiers (nominal scale). Computing an average ID is mathematically meaningless.
