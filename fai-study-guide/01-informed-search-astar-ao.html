Informed Heuristic Search (A* & AO*)

The core foundation of AI pathfinding and problem solving. Step-by-step verified derivations for the 8-Puzzle Problem using Manhattan Distance, Robot Grid Navigation, Priority Queue traces, and AO* search on And-Or trees.

May 2025 (Q3 20M, Q7 20M) Nov 2025 (Q4 20M) 8-Puzzle A* (f=5) Robot Grid (cost=12) AO* Hyper-Edges

01. Intuition & Concept Contrast

Uninformed search (BFS, DFS) blindly explores states without knowing whether a path leads toward the goal. Informed heuristic search uses domain knowledge $h(n)$ to steer search toward promising directions.

Search Paradigm

Uniform-Cost vs Greedy vs A*

Uniform-Cost Search ($f = g$): Looks only backward at cost incurred so far. Optimal and complete, but explores blindly in all directions.

Greedy Best-First ($f = h$): Looks only forward toward the goal. Very fast, but vulnerable to false leads and non-optimal paths.

A* Search ($f = g + h$): Perfectly balances past cost $g(n)$ and estimated future cost $h(n)$. Guaranteed to find the optimal shortest path if $h(n)$ is admissible.

Problem Topology

OR Graph (A*) vs AND-OR Graph (AO*)

Standard OR Graph (A*): A branch represents alternative single choices (e.g., Robot goes Left OR Right). The solution is a single sequential path from Start to Goal.

AND-OR Graph (AO*): Used for problem reduction (divide-and-conquer). An AND branch requires solving all sub-problems simultaneously. The solution is a sub-tree.

02. A* Evaluation Function & Heuristic Properties

The A* Evaluation Function
$$f(n) = g(n) + h(n)$$ $g(n)$: Exact cost from Start to node $n$. $h(n)$: Estimated heuristic cost from $n$ to Goal.

1. Heuristic Admissibility

A heuristic $h(n)$ is **admissible** if it never overestimates the true minimal cost $h^*(n)$ required to reach the goal:

$$0 \le h(n) \le h^*(n), \quad \forall n$$

Theorem: Tree-search A* using an admissible heuristic is guaranteed to be **complete and optimal**.

2. Heuristic Consistency (Monotonicity)

A heuristic is **consistent (monotonic)** if for every node $n$ and every successor $n'$ generated by action $a$ with step cost $c(n, a, n')$:

$$h(n) \le c(n, a, n') + h(n') \implies f(n) \le f(n')$$

This triangle inequality ensures that $f(n)$ never decreases along any path. Graph-search A* with a consistent heuristic never needs to re-open closed nodes.

3. Standard Heuristics for the 8-Puzzle Problem:

  • $h_1(n)$ (Misplaced Tiles): Counts number of numbered tiles not in their goal position. Admissible because each tile must move at least once ($h_1 \le h^*$).
  • $h_2(n)$ (Manhattan Distance): Sum of horizontal and vertical distances of all tiles from their goal slots: $$h_2(n) = \sum_{i=1}^8 \left( |x_i - x_i^{\text{goal}}| + |y_i - y_i^{\text{goal}}| \right)$$ Admissible because tiles move 1 square at a time and cannot hop. $h_2(n)$ dominates $h_1(n)$ ($h_2(n) \ge h_1(n)$), pruning more search space.

03. AO* Algorithm on AND-OR Trees

AO* operates on problem decomposition graphs. It finds the minimal cost solution tree by recursively updating cost estimates backward from leaf nodes.

AO* Branch Cost Propagation Formulas
$$\text{OR Node: } \operatorname{Cost}(n) = \min_{i} \left[ c(n, n_i) + h(n_i) \right]$$ $$\text{AND Node: } \operatorname{Cost}(n) = \sum_{j} \left[ c(n, n_j) + h(n_j) \right]$$ Where $c(n, n_i)$ is edge cost and $h(n_i)$ is sub-tree heuristic.
The AO* Backward Cost Revision Protocol:
1. Expand the most promising leaf node in the current partial tree.
2. Compute costs for its child branches (taking $\min$ for OR branches, and $\sum$ for AND branches).
3. Backtrack up the tree, updating costs of all ancestor nodes until the root is updated.
4. Re-mark the optimal branch pointer at each node based on the newly calculated minimum costs.

05. Repeatable Step-by-Step Solving Protocol

Step 1: Set Up Goal Coordinate Lookup Table

Write down $[r, c]$ coordinates for every numbered tile in the Goal configuration ($0$-indexed or $1$-indexed).

Step 2: Compute Initial Heuristic $h(S_0)$

Calculate Manhattan distance for every tile from $1$ to $8$: $\sum (|r - r_{\text{goal}}| + |c - c_{\text{goal}}|)$. Never calculate distance for the blank space!

Step 3: Evaluate Candidate Blank Swaps

Determine legal blank moves (UP, DOWN, LEFT, RIGHT). For each resulting state, compute $g = g_{\text{parent}} + 1$ and updated $h$.

Step 4: Select State with Lowest $f(n) = g(n) + h(n)$

Expand state with lowest $f(n)$. If tied, pick the state with lower $h(n)$ (closer to goal).

Step 5: Trace Path to Goal & State Invariance

List the sequence of blank moves and verify that $f(n)$ remains constant or monotonic.

06. 6 Deadly Exam Traps & Common Student Mistakes

Trap 01: Counting the Blank Space

Adding Distance for Blank Space (-)

The Manhattan heuristic is the sum of distances for numbered tiles 1 through 8 only. Adding the blank space's distance makes $h(n)$ inadmissible, violating optimality proofs.

Trap 02: Coordinate Index Swapping

Swapping Rows and Columns ($[r, c]$ vs $[x, y]$)

In a 2D matrix, index is $[row, column]$. A tile at Row 2, Column 1 has coords $[2, 1]$. Confusing row with $x$ causes massive arithmetic errors.

Trap 03: Forgetting Past Cost $g(n)$

Running Greedy Best-First Instead of A*

Sorting OPEN list strictly by $h(n)$ turns A* into Greedy Best-First, which is non-optimal. Always sort by $f(n) = g(n) + h(n)$!

Trap 04: Inadmissible Heuristics

Squaring Distances ($\Delta x^2 + \Delta y^2$)

Squared Euclidean distance overestimates true cost when distance $> 1$, breaking admissibility. True Euclidean $\sqrt{\Delta x^2 + \Delta y^2}$ is admissible; squared is not.

Trap 05: AND Node Cost Calculation

Taking Minimum on AND Branches in AO*

In AO*, OR branches take $\min$, but AND branches take the SUM ($\sum$) of all connected children plus edge costs.

Trap 06: Halting at Goal Insertion

Terminating When Goal is Added to OPEN

A* must terminate only when the **Goal node is DEQUEUED / EXPANDED** from the priority queue, not when it is merely generated.

May 2025 · Question 3 The 8-Puzzle Problem Full A* Search Solution (20 Marks)
Question Statement:
Solve the 8-Puzzle Problem using A* Search. Blank tile (-) can move UP, DOWN, LEFT, RIGHT.
$$\text{Initial: } \begin{bmatrix} 2 & 8 & 3 \\ 1 & 6 & 4 \\ 7 & - & 5 \end{bmatrix}, \quad \text{Goal: } \begin{bmatrix} 1 & 2 & 3 \\ 8 & - & 4 \\ 7 & 6 & 5 \end{bmatrix}$$ Blank space is at position $(2, 1)$ (Row 2, Col 1).
1. Using A* search, find optimal path from initial to goal state. (10 Marks)
2. Sequence of moves with $f(n)$ calculation taken by blank tile. (10 Marks)

Solution:

1. Goal Coordinate Mapping ($[r, c]$):

Row 0: $1:[0,0], \ 2:[0,1], \ 3:[0,2]$
Row 1: $8:[1,0], \ -:[1,1], \ 4:[1,2]$
Row 2: $7:[2,0], \ 6:[2,1], \ 5:[2,2]$

2. Initial State $S_0$ Manhattan Distance:
  • Tile 1 at $[1, 0] \to \text{Goal } [0, 0]$: $|1-0| + |0-0| = \mathbf{1}$
  • Tile 2 at $[0, 0] \to \text{Goal } [0, 1]$: $|0-0| + |0-1| = \mathbf{1}$
  • Tile 3 at $[0, 2] \to \text{Goal } [0, 2]$: $\mathbf{0}$
  • Tile 4 at $[1, 2] \to \text{Goal } [1, 2]$: $\mathbf{0}$
  • Tile 5 at $[2, 2] \to \text{Goal } [2, 2]$: $\mathbf{0}$
  • Tile 6 at $[1, 1] \to \text{Goal } [2, 1]$: $|1-2| + |1-1| = \mathbf{1}$
  • Tile 7 at $[2, 0] \to \text{Goal } [2, 0]$: $\mathbf{0}$
  • Tile 8 at $[0, 1] \to \text{Goal } [1, 0]$: $|0-1| + |1-0| = 1 + 1 = \mathbf{2}$
$$h(S_0) = 1 + 1 + 0 + 0 + 0 + 1 + 0 + 2 = \mathbf{5}$$ $$f(S_0) = g(S_0) + h(S_0) = 0 + 5 = \mathbf{5}$$
3. Step-by-Step Sequence of Blank Tile Moves:
Step 1: Blank Moves UP (Swap with Tile 6)

Blank moves from $[2, 1]$ to $[1, 1]$. Tile 6 enters goal position $[2, 1]$!

Tiles misplaced: $1$ (dist 1), $2$ (dist 1), $8$ (dist 2). Total $h = 4$.

$$\mathbf{g(S_1) = 1, \quad h(S_1) = 4 \implies f(S_1) = 1 + 4 = 5}$$
Step 2: Blank Moves UP (Swap with Tile 8)

Blank moves from $[1, 1]$ to $[0, 1]$. Tile 8 moves to $[1, 1]$ (dist to $[1, 0]$ is 1).

Tiles misplaced: $1$ (dist 1), $2$ (dist 1), $8$ (dist 1). Total $h = 3$.

$$\mathbf{g(S_2) = 2, \quad h(S_2) = 3 \implies f(S_2) = 2 + 3 = 5}$$
Step 3: Blank Moves LEFT (Swap with Tile 2)

Blank moves from $[0, 1]$ to $[0, 0]$. Tile 2 enters goal position $[0, 1]$!

Tiles misplaced: $1$ (dist 1), $8$ (dist 1). Total $h = 2$.

$$\mathbf{g(S_3) = 3, \quad h(S_3) = 2 \implies f(S_3) = 3 + 2 = 5}$$
Step 4: Blank Moves DOWN (Swap with Tile 1)

Blank moves from $[0, 0]$ to $[1, 0]$. Tile 1 enters goal position $[0, 0]$!

Tiles misplaced: $8$ (dist 1). Total $h = 1$.

$$\mathbf{g(S_4) = 4, \quad h(S_4) = 1 \implies f(S_4) = 4 + 1 = 5}$$
Step 5: Blank Moves RIGHT (Swap with Tile 8)

Blank moves from $[1, 0]$ to $[1, 1]$. Tile 8 enters goal position $[1, 0]$!

All 8 tiles are in their exact goal slots ($h = 0$).

$$\mathbf{g(S_{\text{Goal}}) = 5, \quad h(S_{\text{Goal}}) = 0 \implies f(S_{\text{Goal}}) = 5 + 0 = 5}$$
Summary of Optimal Solution:
$$\mathbf{\text{Start} \xrightarrow{\text{UP}} S_1 \xrightarrow{\text{UP}} S_2 \xrightarrow{\text{LEFT}} S_3 \xrightarrow{\text{DOWN}} S_4 \xrightarrow{\text{RIGHT}} \text{Goal}}$$
  • Optimal Path Cost: $5$ moves.
  • Heuristic Consistency Invariant: Notice that $f(n) = 5$ at every step. This proves the Manhattan heuristic is monotonically consistent.

May 2025 · Question 7.b AO* Algorithm on AND-OR Tree (10 Marks)
Question Statement:
Root A has AND branch to (B AND C) with edge costs 1, 1, and OR branch to D with edge cost 1.
Node B has OR branches to E (cost 1) and F (cost 1).
Node D has AND branch to (G AND H) with edge costs 1, 1.
Heuristics: $h(B)=3, h(C)=4, h(D)=5, h(E)=5, h(F)=7, h(G)=4, h(H)=4$.
Apply AO* search to find the optimal solution path. (10 Marks)

Solution:

1. Initial Root Evaluation:
  • Branch 1 (AND branch to B and C): $$\text{Cost}(A \to BC) = c(A, B) + h(B) + c(A, C) + h(C) = 1 + 3 + 1 + 4 = \mathbf{9}$$
  • Branch 2 (OR branch to D): $$\text{Cost}(A \to D) = c(A, D) + h(D) = 1 + 5 = \mathbf{6}$$

Since $6 < 9$, the initial best branch is $A \to D$. Expand $D$.

2. Expanding Node D (AND branch to G and H):
$$\text{Cost}(D) = c(D, G) + h(G) + c(D, H) + h(H) = 1 + 4 + 1 + 4 = \mathbf{10}$$

Update ancestor node $A$: $\text{Cost}(A \to D) = c(A, D) + \text{Cost}(D) = 1 + 10 = \mathbf{11}$.

Now re-compare at Root $A$: Branch $A \to BC$ cost is $9$, whereas updated $A \to D$ is $11$.
Branch pointer switches to $(A \to BC)$! Expand $B$.

3. Expanding Node B (OR branches to E and F):
  • $\text{Cost}(B \to E) = c(B, E) + h(E) = 1 + 5 = \mathbf{6}$
  • $\text{Cost}(B \to F) = c(B, F) + h(F) = 1 + 7 = \mathbf{8}$

Best choice for $B$ is $E$ with cost $6$. Update $B$: $\text{Cost}(B) = \mathbf{6}$.

Update Root $A$ via $(A \to BC)$:

$$\text{Cost}(A \to BC) = c(A, B) + \text{Cost}(B) + c(A, C) + h(C) = 1 + 6 + 1 + 4 = \mathbf{12}$$
4. Final Comparison & Optimal Subtree:

Comparing Root $A$ alternatives: $\text{Cost}(A \to D) = \mathbf{11}$ vs $\text{Cost}(A \to BC) = \mathbf{12}$.
The optimal solution subtree is $\mathbf{A \to D \to (G \text{ AND } H)}$ with total cost $\mathbf{11}$.

09. Active Recall Self-Test Quiz

Answer the questions below to evaluate progress (0/4 answered).
1. What does it mean for an A* heuristic $h(n)$ to be admissible?
Correct: (a) Admissibility ($h(n) \le h^*(n)$) guarantees that A* never overlooks an optimal path.
2. Why is the Manhattan Distance heuristic preferred over the Misplaced Tiles heuristic in the 8-puzzle?
Correct: (b) A dominating admissible heuristic gives higher, more accurate bounds without overestimating, visiting fewer nodes.
3. Along the optimal path in the May 2025 8-puzzle problem, what is the value of $f(n) = g(n) + h(n)$ at each step?
Correct: (c) Because every move reduces remaining Manhattan distance by exactly 1 while increasing $g$ by 1, $f(n) = 5$ is perfectly invariant.
4. In an AND-OR tree (AO* algorithm), how is the cost of an AND branch calculated?
Correct: (a) An AND branch requires solving all sub-problems, so their total costs must be summed together.

2. Prove Admissibility of the Chosen Heuristic

Write: "$h(n)$ is admissible because a tile must move at least its grid distance to reach goal, so $h(n) \le h^*(n)$."
