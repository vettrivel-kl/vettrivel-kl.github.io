Tier 3: Advanced Systems (Sprints 25-36)

Back to Master Dashboard

info

Tier 3 Strategic Goal

Operate at the highest level of technical and architectural ambiguity:

  • DSA: Dynamic Programming (1D/2D, state space minimization) and Backtracking pruning.
  • Backend HLD: Multi-region active-active architectures, consensus protocols, and extreme flash-sale contention.
  • Frontend HLD: Multi-team design systems, WebAssembly off-main-thread processing, and client telemetry.
  • LLD: Advanced machine coding under high concurrency and strict latency constraints.
  • Leadership: Formal RFC governance, 1-page executive proposals to VPs/CTOs, and organizational architecture.

Sprints 25-27: Dynamic Programming, Multi-Region & Design Systems​

Track 01 — DSA & Computational Reasoning​

  • Pattern: 1D Dynamic Programming (Climbing stairs, House robber, Coin change, Longest Increasing Subsequence)
  • Rigorous DP Invariants: Formulating State, Meaning, Recurrence, Base Cases, Transition, Order, and Space Optimization
  • Space Optimization: Compressing O(N)O(N)O(N) auxiliary state arrays to O(1)O(1)O(1) rolling variables

Track 02 — Backend System Design​

  • Multi-Region Distributed Architecture: Active-Passive vs Active-Active multi-datacenter deployments
  • Conflict Resolution: Dynamo-style vector clocks vs Last-Write-Wins (LWW) vs CRDT datastores
  • Problem: Design a Multi-Region Global Data Store with Sub-100ms Writes and Partition Tolerance

Track 03 — Frontend System Design​

  • Design System as an Infrastructure Platform: Design tokens (JSON/CSS variables), headless UI logic
  • Multi-Team Governance: Backward-compatible versioning, automated visual regression tests, accessibility (WCAG)
  • Problem: Design an Enterprise Design System & Component Platform for 50+ Product Teams

Track 04 — Low-Level Design & Concurrency​

  • Contention Management: Optimistic locking with version fields vs pessimistic locks
  • Lease Expiration: Automatic rollback of uncommitted inventory reservations via delayed queues
  • Problem: Build an E-Commerce Flash Sale Inventory Reservation Engine in Java

Track 05 — Leadership & Written Artifacts​

  • Written Deliverable: Draft a formal Request for Comments (RFC) on establishing cross-team API contracts
  • Multi-Team Alignment: Simulating an RFC review meeting with conflicting feedback from 3 lead engineers
  • Competency Focus: Written Architectural Leadership & RFC Governance

Sprints 28-30: 2D DP, Consensus Protocols & Telemetry​

Track 01 — DSA & Computational Reasoning​

  • Pattern: 2D Dynamic Programming (0/1 Knapsack, Unbounded Knapsack, Longest Common Subsequence, Edit Distance)
  • Grid DP: Unique paths, Minimum path sum, Matrix chain multiplication
  • Space Optimization: Reducing O(M×N)O(M \times N)O(M×N) matrices to O(N)O(N)O(N) rolling row buffers

Track 02 — Backend System Design​

  • Distributed Consensus: Understanding Raft and Paxos fundamentals (Leader election, Log replication, Quorum)
  • Distributed Coordination: ZooKeeper / etcd, Distributed locking flaws (Redlock critique, fencing tokens)
  • Problem: Design a High-Volume Distributed Time-Series Metrics Platform (Datadog / Prometheus TSDB)

Track 03 — Frontend System Design​

  • Client Observability & Telemetry: Real User Monitoring (RUM), Core Web Vitals beaconing
  • Telemetry Ingestion: Event batching, sampling strategies, navigator.sendBeacon for zero-loss page unload
  • Problem: Design a Client-Side Telemetry, Error Tracking & Crash Reporting SDK

Track 04 — Low-Level Design & Concurrency​

  • Spatial Indexing in Memory: Implementing QuadTree or GeoHash grid cell partitioning
  • Matchmaking Engine: Multi-threaded rider/driver proximity matching with surge pricing state
  • Problem: Build a Low-Level Cab Booking Dispatcher (Uber / Grab LLD)

Track 05 — Leadership & Written Artifacts​

  • Executive Pitch: Drafting a 1-Page Proposal to a CTO justifying a multi-million-dollar cloud migration
  • Cost-Benefit Modeling: Calculating 24-month ROI and infrastructure savings
  • Competency Focus: Executive Communication & Business / Technical Alignment

Sprints 31-33: Backtracking, Contention & Video Players​

Track 01 — DSA & Computational Reasoning​

  • Pattern: Backtracking & Branch-and-Bound (Search space formulation, State restoration)
  • Pruning Techniques: N-Queens, Sudoku solver, Word search II with Trie integration
  • Distributed Bridge: How backtracking branch-and-bound maps to distributed route optimization

Track 02 — Backend System Design​

  • Extreme Contention: Virtual waiting rooms (Ticketmaster model), queue buffering, atomic Redis counters
  • High-Availability Degradation: Load shedding, circuit breakers, fallback static caches
  • Problem: Design an E-Commerce Flash Sale & Ticket Booking Platform under 100,000 QPS Contention

Track 03 — Frontend System Design​

  • Video Architecture: Media Source Extensions (MSE), Encrypted Media Extensions (DRM/EME)
  • Adaptive Bitrate Streaming: Client-side HLS/DASH buffer management and bandwidth heuristics
  • Problem: Design a High-Performance Web Video Player Platform (YouTube / Netflix Web)

Track 04 — Low-Level Design & Concurrency​

  • Complex Graph Minimization: Debt simplification algorithms in expense sharing
  • Domain Invariants: Split calculations (Equal, Exact, Percentage) with rounding error protection
  • Problem: Build an Expense Sharing System (Splitwise LLD) with minimum cash flow settlement

Track 05 — Leadership & Written Artifacts​

  • Organizational Architecture: Applying Conway's Law to realign engineering teams and service boundaries
  • Retrospective: Documenting an authentic architectural miscalculation and post-incident recovery
  • Competency Focus: Organizational Strategy & Long-Term Technical Direction

Sprints 34-36: Capstone Prep, Advanced Mocks & Tier 3 Review​

Track 01 — DSA & Computational Reasoning​

  • Advanced Diagnostic Mock: 45-minute timed interview simulation on Hard DP or Backtracking
  • Complexity Mastery: Mathematical derivation of recursive branching factors and memoized states

Track 02 — Backend System Design​

  • Full Whiteboard Mock: 60-minute multi-region distributed system design simulation
  • Timed ADR Delivery: Producing a complete Architecture Decision Record in 15 minutes

Track 03 — Frontend System Design​

  • Full Whiteboard Mock: 60-minute complex frontend system design simulation
  • Core Web Vitals Defense: Defending frame budgets, memory profiling, and edge deployment

Track 04 — Low-Level Design & Concurrency​

  • 90-Minute Timed Machine Coding: Build an end-to-end flash sale inventory engine or task scheduler
  • Surprise Twist Defense: Adapting the codebase within 15 minutes to support priority lease overrides

Track 05 — Leadership & Written Artifacts​

  • Staff Mock Loop: 45-minute interview testing Scope, Ambiguity, and Multiplier effect
  • Full Artifact Audit: Verifying 10 STAR+ stories, 2 ADRs, 1 RFC, and 1 Executive Pitch
